# Flattening Core X-Ray Layers in Photoshop (`Picture03.png`)

## Overview
A screenshot of **Adobe Photoshop CS** on Mac OS X showing the **Layers** palette and its flyout options menu with **Flatten Image** highlighted, merging the individual aligned X-ray plate layers into a single background layer to save memory and discard unused off-canvas overlay areas.

## Document Window (Left)
- The narrow document window `bp04-5g...` is partially visible on the left, showing the upper portion of the assembled grayscale core X-ray from `y = 0` to `y ≈ 4500` pixels on the vertical ruler and `0` to `1000`+ pixels on the horizontal ruler.
- A dashed rectangular marquee selection outlines the core and its left margin, and a bright cyan horizontal guide line crosses the canvas around `y = 3350`.
