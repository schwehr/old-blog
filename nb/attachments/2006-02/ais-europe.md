# Live AIS Ship Tracking Map of Liverpool Bay (`ais-europe.png`)

## Overview
A screenshot of a live Automatic Identification System (AIS) web map (`emit.demon.co.uk/webcam/map.php`) displaying real-time vessel positions, coastal landmarks, and offshore infrastructure in Liverpool Bay, the River Mersey estuary, and the North Wales / Wirral / Lancashire coast on February 4, 2006.
