# Google Earth Add Image Overlay Menu Selection (`ge-sb-4.png`)

## Overview
The fourth screenshot in the Fledermaus-to-Google-Earth overlay tutorial series, showing the **Google Earth** Mac OS X application menu bar with the **`Add`** menu open and **`Image Overlay...`** (`⇧⌘O`) selected.

- **`Add` Pull-Down Menu**:
  - **`Folder...`** (`⇧⌘N`)
  - **`Placemark...`** (`⇧⌘P`)
  - *(Horizontal separator line)*
  - **`Path...`** (`⇧⌘T`)
  - **`Polygon...`** (`⇧⌘G`)

  - **`Network Link...`** (no keyboard shortcut)
- **Background Google Earth Window**:
  - **Window Title Bar**: Shows the red, yellow, and green Mac OS X window control buttons on the left.
