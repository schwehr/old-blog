# Google Earth New Image Overlay Location Coordinates Dialog (`ge-sb-5.png`)

## Overview
The fifth screenshot in the Fledermaus-to-Google-Earth overlay tutorial series, showing the **Google Earth** `New Image Overlay` properties dialog on Mac OS X with the **`Location`** tab selected and populated with the north, south, east, and west bounding-box coordinates for the Santa Barbara Basin bathymetry GeoTIFF.

## Dialog Controls & Visible Text
- **`Name:`**: A text input field highlighted with a blue focus ring containing the default name **`Untitled Image Overlay`** (with the vertical text cursor at the end of `Overlay`).
- **`Link:`**: An empty white text input field for the image file path or URL, accompanied by a rounded **`Browse...`** button on the right.
- **`Transparency:`**: A full-width horizontal slider bar labeled **`Clear`** on the left and **`Opaque`** on the right, with the blue Aqua slider thumb positioned all the way to the right at **`Opaque`**.
- **Tab Bar**: Four segmented tab buttons in the center of the dialog:
  - `Description`
  - `View`
  - `Refresh`
  - **`Location`** (selected/highlighted in blue Aqua)
- **`Location` Tab Bounding-Box Fields**:
  - Arranged in a 2 × 2 grid of text input boxes containing geographic coordinates in degrees, minutes, and seconds (`DMS`), converted from the decimal degree coordinates displayed in IVS `imageviewer`:
    - **`North:`** `34°31'12.41"N`
    - **`East:`** `120° 2'59.97"W`
    - **`South:`** `34°21'31.92"N`
    - **`West:`** `120°14'43.83"W`
