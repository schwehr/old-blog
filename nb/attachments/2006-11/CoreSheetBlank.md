# Unofficial Gravity Core Collection Sheet (`CoreSheetBlank.png`)

## Overview
An image of a blank, custom-made **Gravity Core Collection Sheet** created by Kurt Schwehr during the November 2006 R/V *Roger Revelle* cruise (`CA0606RR`) in the Santa Barbara Basin, stamped diagonally with a large lavender `UNOFFICAL` watermark.

## Form Structure & Visible Text
- **Title**: `Gravity Core Collection Sheet` centered at the top.
- **Header Fields**:
  - Left column:
    - `CRUISE: CA0606RR`
    - `LOCATION: Santa Barbara Basin`
    - `CORE NUMBER: ____________________`
    - `STATION NAME: ____________________`
  - Right column:
    - `OBSERVER: ____________________`
    - `DATE (GMT): ____________________`
- **Main Data Grid (4 rows × 6 columns)**:
  - **Column Headers**: `TIME (GMT)`, `Ship's GPS Location`, `COG (deg)`, `SOG (knots)`, `Depth (m)`, `Wire tension`
  - **Row Labels (left margin)**:
    1. `In Water`
    2. `100m off Bottom`
    3. `Bottom`
    4. `Out of Water`
- **Watermark**: Large diagonal purple/lavender sans-serif text across the center of the grid reading `UNOFFICAL` (spelled without the second 'I').
- **Footer Fields**:
  - Left side:
    - `SPEED UP: ____________________`
    - `SPEED DOWN: ____________________`
    - `CORE LENGTH (cm): ____________________`
    - `WHAT ABOUT THE CORE CATCHER?`
  - Right side:
    - `NOTES:` above a large blank rectangular box for handwritten observations.
