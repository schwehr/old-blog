# Google Earth New Network Link Dialog Box (`kmzimage-ge-url.png`)

## Overview
A cropped screenshot of the **`Google Earth - New`** Network Link configuration dialog window on Mac OS X, showing the name and URL entered to load the georeferenced `CCOM_JHC_Logo.kmz` file into Google Earth.

## Dialog Controls & Text
- **Window Title Bar**: Standard Mac OS X brushed-metal/gray title bar reading **`Google Earth - New`** with three disabled window control buttons on the left.
- **Input Fields**:
  - **`Name:`** text field containing **`CCOM Logo`**.
  - **`Link:`** text field (outlined with a blue focus ring) containing **`vislab-ccom.unh.edu/~schwehr/GoogleEarth/CCOM_JHC_Logo.kmz`** (with the leading `http://` scrolled slightly off the left edge of the box), followed by a rounded **`Browse...`** button on the right.
- **Tabbed Pane**:
  - Three segmented tab buttons in the center: **`Description`** (selected in blue Aqua highlight), `View`, and `Refresh`.
  - Below the tabs is a **`Description:`** label above a blank multi-line text input area.
