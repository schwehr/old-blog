# DMagic File Menu: Import From SD/Scene (`utm2ll01.png`)

## Overview
A cropped screenshot of the **DMagic** (Fledermaus Data Magic) application menu bar and main window on Mac OS X, demonstrating the first step in importing a UTM-projected Fledermaus `.sd` file by selecting `File -> Import From SD/Scene...`.

## Interface & Menu Details
- **Mac OS X Menu Bar**: At the top, featuring the blue Apple logo, bold `dmagic` application menu, highlighted **`File`** menu (in white text on a blue background), `View`, `Tools`, and `Help`.
- **Open `File` Dropdown Menu**:
  - `Open Project...` (shortcut `⌘O`)
  - `Import Gridded Data...`
  - `Import Ungridded Data...`
  - **`Import From SD/Scene...`** (highlighted in blue as the active selection)
  - `Import Imagery` (with a right-facing submenu arrow `►`)
  - `Export Surface...`
  - `Screen Capture` (with a right-facing submenu arrow `►`)
  - `Recent Projects` (with a right-facing submenu arrow `►`)
- **Background Application Window**: Partially visible behind the menu, showing the red, yellow, and green Mac window buttons, the `Data Components` section header, a table with columns `Type` and `File Name`, a `<<` button at the bottom right of the list, and a partial `Reset View` button on the right.
