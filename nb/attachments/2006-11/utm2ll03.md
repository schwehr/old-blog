# DMagic Data Components List After Importing `gutmtest.sd` (`utm2ll03.png`)

## Overview
A cropped screenshot of the `Data Components` table inside DMagic on Mac OS X, showing the three component files extracted from `gutmtest.sd`.

## Table & Control Details
- **Columns**: Two columns headed `Type` and `File Name`.
- **Listed Rows**:
  1. `Hgt` | `gutmtest.dtm` (highlighted in light blue as the currently selected row, representing the digital terrain model / elevation grid).
  2. `Geo` | `gutmtest.geo` (representing the georeferencing information).
  3. `Col` | `gutmtest.shade` (representing the color/shaded relief layer).
- **Transfer Buttons**: To the right of the table are two square bevel buttons labeled `>` (move selected component to the display view) and `>>` (move all components to the display view).
