# DMagic Export Surface Dialog: Export XYZ Value (`utm2ll06.png`)

## Overview
A screenshot of the **Export Surface** dialog box in **DMagic** on Mac OS X, configured to export the `gutmtest.dtm` digital terrain model as ASCII `XYZ` coordinate triples (`Export XYZ Value`).

## Dialog Controls & Layout
- **Window Title Bar**: Standard Mac OS X dialog header titled `Export Surface` with three disabled (gray) window buttons on the left.
- **`Active Dataset` Selector**: Near the top, labeled `Active Dataset` next to a focused blue-outlined dropdown menu showing `gutmtest.dtm`.
- **`Format` Group Box (Left)**: Contains five radio button options:
  - `Export Z Value` (unselected)
  - **`Export XYZ Value`** (selected with a blue radio button dot)
  - `Export ArcView Grid` (unselected)
  - `Export Binary Heights` (unselected)
  - `Export GMT Grid` (unselected)
- **`Options` Group Box (Right, partially cropped at right edge)**:All controls inside are disabled (grayed out) for the `Export XYZ Value` format:
  - Checked checkbox: `Include Mi...`
  - Label: `No Data Value`
  - Horizontal divider line
  - Radio buttons: `8-bit` (selected), `16-bit`, `32-bit`.
- **Action Button**: At the bottom right is a rounded Mac OS X button labeled `Save...`.
