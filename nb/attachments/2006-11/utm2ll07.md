# DMagic Save As Dialog (`utm2ll07.png`)

## Overview
A cropped Mac OS X interface screenshot showing the "Save As" filename field inside the IVS 3D DMagic file export dialog during a workflow converting a UTM Fledermaus `.sd` file to geographic (longitude/latitude) coordinates.

## Interface & Controls
- **Background**: Light gray brushed/striped Mac OS X Tiger dialog background.
- **Label**: Black text on the left reading `Save As:`.
- **Text Input Field**: A white rectangular input box with a glowing blue focus ring around its border, containing the text `gutmtest.xyz` with a vertical text cursor positioned immediately after the `z`.
- **Disclosure Button**: To the right of the text box is a square, glossy Aqua-style blue button containing a downward-pointing black triangle used to expand or collapse the full file browser sheet.
