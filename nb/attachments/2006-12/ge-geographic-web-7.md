# Google Earth Edit Network Link Dialog for Panoramio KML (`ge-geographic-web-7.png`)

## Overview
A close-up screenshot of the **Google Earth – Edit Network Link** modal dialog box on Mac OS X, showing the configuration used to load live user photos from `panoramio.kml` into Google Earth.

## Dialog Controls & Visible Text
- **Window Title Bar:** Standard Mac OS X window controls (three greyed-out traffic light buttons on the left) and the centered title `Google Earth - Edit Network Link`.
- **Input Fields:**
  - `Name:` text field highlighted with a blue focus ring and light-blue text selection, containing `Panoramio images` with a vertical text cursor at the end.
  - `Link:` text field containing `http://www.panoramio.com/panoramio.kml`.
- **Tab Bar:**
  - Three segmented Aqua tabs: `Description` (active, highlighted in blue), `View`, and `Refresh`.
- **Tab Content:**
  - A `Description:` label above a large blank multi-line text box.
