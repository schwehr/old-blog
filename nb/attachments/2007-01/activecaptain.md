# ActiveCaptain Web Application Screenshot (`activecaptain.png`)

## Overview
A screenshot of the **ActiveCaptain** (`activecaptain.com`) web-based interactive marine charting and cruising guidebook application, captured in January 2007. The interface displays a satellite/hybrid map view of the Little Bay and Piscataqua River region near Newington, New Hampshire, with details for **Great Bay Marine**.

## Interface & Navigation Controls
- **Top Header Bar**: A blue banner with the stylized **activecaptain** logo in the upper left and three navigation tabs along the top:
  - **Home** (dark blue tab)
  - **On The Water** (active light-blue tab)
  - **Going Mobile** (dark blue tab)
- **Left Sidebar**: A vertical list with alternating light and medium gray horizontal rows showing numbered marine facilities in the current view:
  - **1. Great Bay Marine** with links below for `Rate It` and `Center / Details`
  - **2. Little Bay Marina** with links below for `Rate It` and `Center / Details`
- **Map View Controls (Upper Left of Map Pane)**: Black rectangular buttons stacked vertically:
  - `Map`
  - `Hybrid`

  - Coordinate readout box displaying:
    - `43°07.017'N`
    - `070°50.004'W`
