# NOTAM Ace Map View (`notamace-1.png`)

## Overview
A Mac OS X web browser screenshot of the **NOTAM Ace** website (`http://www.notamace.com/notam.aspx?search=pease&radius=20`), a Google Maps API mashup for viewing aviation Notices to Airmen (NOTAMs) and Temporary Flight Restrictions (TFRs) around Portsmouth International Airport at Pease (`PSM`) in New Hampshire.
