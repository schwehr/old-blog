# Google Earth KML Pop-up for NOAA Water Level AIS Binary Message (`wl-8632200-kml.png`)

## Overview
A screenshot of Google Earth displaying a decoded AIS binary water level message (`wl-8632200.kml`) as a KML placemark and HTML data table balloon for NOAA tide gauge station `8632200` (Kiptopeke, Virginia) at the mouth of the Chesapeake Bay. The KML file was generated by Kurt Schwehr's `noaadata` Python package (`waterlevel.py`) from an AIS Message 8 binary broadcast.
