# Fledermaus 6.4: Export Map Sheet as GeoTIFF Dialog (`fleder2ge-3-geotiff.png`)

## Overview
Third in an eight-part screenshot series demonstrating how to export a bathymetric/topographic scene from **IVS Fledermaus 6.4** on Mac OS X to Google Earth. This screenshot shows the **`Export Map Sheet`** modal dialog over the `Map Sheet` window, configuring the export as a GeoTIFF in geographic coordinates.

## Dialog Controls & Settings
- **Window Title**: `Export Map Sheet`
- **`Filename`**: Text input field set to `/Users/schwehr/Desktop/capture.tif`, with a **`Browse...`** button to its right.
- **`Image Type:`**: Dropdown selector set to **`GeoTIFF`**.
- **`Resolution:`**:
  - Numeric input box set to `1`.
  - Horizontal slider ranging from `1` to `10` with the blue slider thumb at the far left (`1`).
  - Read-only output dimensions box to the right reading **`701x362 ( 1.0 MB )`**.
- **`Type of Map`** (grouped box):
  - Radio button (selected, blue dot): **`Map Imagery - Geographic Coordinates`**
  - Radio button (unselected): `Map Imagery - Projected Coordinates`
  - Radio button (disabled/grayed out): `Annotated Map - Projected Coordinates`, alongside a disabled `Title:` text box and a disabled `[ ] Draw North Arrow` checkbox.
- **Bottom Action Buttons**:
  - **`Save`** and **`Cancel`** buttons in the lower-right corner.

## Background Context
- Behind the dialog, the upper portion of the `Map Sheet` preview is visible, showing the purple, blue, green, and orange/red shaded-relief topography of the Santa Barbara coastline and Transverse Ranges, along with the `Annotated Map Size (inches)` fields (`Width 420.913`, `Height 268.604`), `Convert to Me...` button, and `Export Map Sheet` button on the left.
