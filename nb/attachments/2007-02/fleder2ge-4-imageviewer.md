# Fledermaus ImageViewer: Opening the GeoTIFF (`fleder2ge-4-imageviewer.png`)

## Overview
Fourth in an eight-part screenshot series demonstrating how to export a bathymetric/topographic scene from **IVS Fledermaus 6.4** on Mac OS X to Google Earth. This cropped screenshot shows the **`imageviewer`** companion application with the **`File`** menu open to **`Open...`** for loading the exported GeoTIFF file.

## Menu Bar & File Dropdown
- **Top Menu Bar**: Shows the Apple menu, **`imageviewer`** (bold application title), **`File`** (highlighted in blue), `Edit`, `Image`, `Tools`, and `Geor...` (`Georeferencing`).
- **File Dropdown Menu**:
  - **`Open...`** (`⌘O`, highlighted in blue)
  - `Save` (`⌘S`)
  - `Save As...` (`⇧⌘S`)
  - `Export` (with submenu arrow `▶`)
  - `Write TFW` (with submenu arrow `▶`)
  - Horizontal divider line
  - `Recent Images` (with submenu arrow `▶`)
