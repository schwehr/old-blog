# Fledermaus ImageViewer: Alpha Mask Dialog (`fleder2ge-6-transparency.png`)

## Overview
Sixth in an eight-part screenshot series demonstrating how to export a bathymetric/topographic scene from **IVS Fledermaus 6.4** on Mac OS X to Google Earth. This screenshot shows the **`Alpha Mask`** dialog window in **`imageviewer`**, configured to make pure white pixels (`RGB 255, 255, 255`) completely transparent (`Alpha 0`) with zero fuzziness.

## Dialog Layout & Controls
- **Window Title**: `Alpha Mask`
- **Instructional Text**: `Set the alpha level for the specified colour.`
- **Top Buttons**:
  - **`Select Colour`** (enabled pill-shaped button on the left)
  - **`Use Picked Colour`** (disabled/grayed-out pill-shaped button on the right)
- **`Fuzziness` Control**:
  - Text input box set to **`0`**.
  - Horizontal slider with tick marks ranging from `0` to `255`, with the blue slider thumb positioned at **`0`**.
- **Color Readout & Swatch (Center)**:
  - `Red:` **`255`**
  - `Green:` **`255`**
  - `Blue:` **`255`**
  - To the right of the RGB values is a rectangular pure-white color swatch outlined in black.
- **`Alpha` Control**:
  - Text input box set to **`0`**.
  - Horizontal slider with tick marks ranging from `0` to `255`, with the blue slider thumb positioned at **`0`**.
- **Bottom Action Buttons**:
  - **`OK`** (default pulsing blue Aqua button) and **`Cancel`** button.
