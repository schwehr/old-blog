# Fledermaus ImageViewer: Exporting to Google Earth (`fleder2ge-7-start-googleearth.png`)

## Overview
Seventh in an eight-part screenshot series demonstrating how to export a bathymetric/topographic scene from **IVS Fledermaus 6.4** on Mac OS X to Google Earth. This cropped screenshot shows selecting **`File` -> `Export` -> `Google Earth (Startup)`** in **`imageviewer`**, which automatically generates a KML ground overlay package and launches Google Earth.
