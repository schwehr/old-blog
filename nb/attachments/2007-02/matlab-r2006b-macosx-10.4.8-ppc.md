# MATLAB R2006b Running on Mac OS X PowerPC (`matlab-r2006b-macosx-10.4.8-ppc.png`)

## Overview
A screenshot of the MATLAB 7.3.0 (R2006b) desktop environment running inside an X11 window on Mac OS X 10.4.8 (PowerPC), displaying the MATLAB splash screen alongside a simple arithmetic test (`1+2`) in the Command Window.

  - Main toolbar: Icons for New M-File, Open File, Cut, Copy, Paste, Undo, Redo, Workspace/Simulink/Guide/Profiler shortcuts, Help (`?`), and a `Current Directory:` path dropdown set to `/Applications/MATLAB73`.
