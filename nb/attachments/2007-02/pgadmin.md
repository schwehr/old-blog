# pgAdmin III Connected to Local PostgreSQL 8.2 Server (`pgadmin.png`)

## Overview
A Mac OS X screenshot of the `pgAdmin III` database administration GUI connected to a local PostgreSQL 8.2.3 database server named `eel (localhost:5432)`.

## Interface & Controls
- **Window Header & Toolbar**:
  - Standard Mac OS X window title bar labeled `pgAdmin III`.
  - Top icon toolbar containing 10 icons: Add connection (power plug), Refresh (circular orange arrows), Open/Folder, Copy/Export, Delete (green recycling trash bin), Execute SQL query (disabled), View data grid (disabled), View filtered data (disabled), Maintenance/Wrench (disabled), Help (`?`), and Guru hints (bearded wizard face).
- **Object Browser (Left Pane)**:
  - Tree view showing `Servers (1)` expanded to reveal the selected server node `eel (localhost:5432)`.
- **Right Pane Tabs**:
  - Four tabs across the top: `Properties` (active, highlighted in blue), `Statistics`, `Dependencies`, and `Dependents`.
