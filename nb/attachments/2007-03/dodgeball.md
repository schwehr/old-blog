# Dodgeball Mobile Social Networking Diagram (`dodgeball.png`)

## Overview
An illustrated explanatory graphic from Google's **Dodgeball** (`dodgeball.com`) website titled **"Your Friends"**, demonstrating how the location-based mobile social network connects users with friends, friends of friends, and crushes via text messages.
