# Adobe Photoshop CS3 Beta License Expired Dialog (`ps3-expired.png`)

## Overview

A screenshot of a macOS modal dialog window from Adobe Photoshop CS3 Beta notifying the user that the product trial/beta license has expired. The image was included in a May 6, 2007 blog post titled "Photoshop 3 beta expired."

## Interface & Dialog Details

- **Window Style**: Standard Mac OS X Aqua light-gray dialog sheet with a horizontal divider line near the top.
- **Application Icon**: On the left side is the blue square Adobe Photoshop CS3 icon featuring a subtle radial gradient and the white letters **`Ps`** in a clean sans-serif font.
- **Message Text**:
  - Bold header: **`License Expired`**
  - Body text below: **`Product license has expired.`**
- **Controls**: In the bottom right corner is a glossy blue pulsating default Mac OS X Aqua pill button labeled **`OK`**.
