# Eclipse New Project Wizard Selecting Pydev Project (`eclipse-pydev.png`)

## Overview
A cropped screenshot of the Eclipse 3.3.0 "New Project" wizard dialog on Mac OS X, illustrating the selection of `Pydev Project` when checking out a Python codebase from Subversion (from the August 20, 2007 post *"How to check out a svn project from Eclipse"*).

## Interface & Visible Elements
- **Header Label**: `Wizards:` at the top left.
- **Filter Box**: A rounded Mac OS X search/filter text input containing the placeholder text `type filter text`.
- **Wizard Tree List**:
  - Collapsed folder categories with disclosure triangles (`►`):
    - `General`
    - `CVS`
    - `Java`
    - `PHP`
    - `Plug-in Development`
  - Expanded folder category (`▼`):
    - `Pydev`
      - `Pydev Project` (selected with a light blue highlight bar and preceded by a blue-and-yellow intertwined Python logo icon).
  - Below `Pydev`:
    - `SVN` (collapsed folder).
- **Bottom Graphic**: Below the tree view box on the lower left is a larger square graphic of the official two-snake (blue and yellow) Python logo.
