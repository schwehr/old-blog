# Selecting the Elliptical Marquee Tool in Adobe Photoshop (`ps-ellipse-2.png`)

## Overview
A Mac OS X screenshot showing the top-left corner of Adobe Photoshop with the Marquee Tool flyout menu open in the Tools palette to select the **Elliptical Marquee Tool**.

## Interface & Controls
- **Mac Menu Bar**: At the very top, the Apple logo is followed by **`Photoshop`**, **`File`**, **`Edit`**, **`Image`**, **`Layer`**, and **`S...`** (Select).
- **Options Bar**: Below the menu bar, shows the Marquee tool icon dropdown, four selection mode icons (New selection active, Add to, Subtract from, Intersect with), **`Feather:`** set to **`0 px`**, a grayed-out **`Anti-alias`** checkbox, and **`Style:`** set to **`No...`** (Normal).
- **Tools Palette (Left Dock)**:
  - Top header with the Adobe Photoshop feather logo.
  - Tool icons arranged in two columns, with the top-left Marquee tool slot clicked to open a flyout menu containing four options:
    1. **`Rectangular Marquee Tool`** (with a black square indicator next to it and shortcut **`M`**)
    2. **`Elliptical Marquee Tool`** (highlighted in blue under the cursor, shortcut **`M`**)
    3. **`Single Row Marquee Tool`**
    4. **`Single Column Marquee Tool`**
  - Below the flyout menu, other visible tools in the palette include the Move tool, Lasso tool, Crop tool, Healing Brush / Brush tools, Clone Stamp / History Brush, Eraser / Gradient, Blur / Dodge, and Path Selection / Type (`T`) tools.
- **Document Window**: In the main workspace to the right, a photo window titled **`DSCN8041.JPG`** shows the upper right portion of a single-story brick house in Tucson with a rooftop AC/swamp cooler unit against a bright sky.
