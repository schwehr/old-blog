# Adobe Photoshop Stroke Dialog Box (`ps-ellipse-5.png`)

## Overview
A screenshot of the **Stroke** dialog window in Adobe Photoshop on Mac OS X, illustrating the configuration of a yellow circular outline around an elliptical marquee selection in a tutorial from October 5, 2007.

## Interface & Controls
- **Dialog Title**: `Stroke` centered in the Mac OS X Aqua window title bar.
- **Stroke Panel**:
  - `Width:` text input field set to `5 px`.
  - `Color:` swatch displaying a bright solid yellow rectangle.
- **Location Panel**: Radio buttons for stroke placement relative to the selection marquee:
  - `Inside` (unselected)
  - `Center` (unselected)
  - `Outside` (selected with a blue Aqua radio button)
- **Blending Panel**:
  - `Mode:` drop-down menu set to `Normal`.
  - `Opacity:` text input field set to `100` `%`.
  - `Preserve Transparency` checkbox (unchecked and grayed out/disabled).
- **Action Buttons**: Located in the upper right of the dialog:
  - `OK` (pulsing blue default Aqua button)
  - `Cancel` (standard white Aqua button)

## Background Image Details
- To the left of the dialog box, the underlying photograph (`DSCN8041.JPG`) shows the front facade of a red-brick house in Tucson with a chain-link fence in the foreground and a boxy evaporative cooler / air conditioning unit mounted on the flat roof, encircled by a dashed black-and-white "marching ants" elliptical marquee selection.
