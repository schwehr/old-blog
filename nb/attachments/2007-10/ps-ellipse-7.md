# Adobe Photoshop Fill and Color Picker Dialogs (`ps-ellipse-7.png`)

## Overview
A screenshot of Adobe Photoshop on Mac OS X showing both the **Fill** dialog box and the foreground **Color Picker** dialog box, demonstrating how to add a 20% opacity red fill inside a yellow-stroked circular highlight (October 5, 2007).

## Interface & Controls
- **Fill Dialog Window (Upper Right)**:
  - **Contents**: `Use:` drop-down menu set to `Color...`, with `Custom Pattern:` grayed out below it.
  - **Blending**: `Mode:` drop-down set to `Normal`, and `Opacity:` text field set to `20` `%`.
  - **Buttons**: `OK` (blue default button) and `Cancel` on the right.
- **Color Picker Dialog Window (Lower Foreground)**:
  - **Color Field & Spectrum Slider**: Large 2D color gradient square showing shades of red, white, and black (with the circular selector in the upper-right corner for pure red), paired with a vertical hue slider bar set to the bottom/top red position (`0°`).
  - **Color Swatch & Warnings**: A solid bright red preview rectangle next to an out-of-gamut warning triangle (`!`) with a small red correction square below it.
  - **Color Values**:
    - **HSB**: `H:` `0` `°` (radio button selected), `S:` `100` `%`, `B:` `100` `%`.
    - **RGB**: `R:` `255` (highlighted), `G:` `0`, `B:` `0`.
    - **Lab**: `L:` `56`, `a:` `77`, `b:` `72`.
    - **CMYK**: `C:` `0` `%`, `M:` `94` `%`, `Y:` `100` `%`, `K:` `0` `%`.
    - **Hexadecimal**: `#` `ff0000`.
  - **Checkbox & Buttons**: `Only Web Colors` (unchecked) at the bottom left; `OK`, `Cancel`, and `Color Libraries` buttons stacked on the right.

## Background Image Details
- In the upper-left background, the brick house photograph is visible with the yellow circular outline and dashed selection marquee surrounding the rooftop air conditioning unit.
