# Mac OS X Bluetooth Device Set Up Assistant — Device Discovery (`i.trek-z1-gps-1.png`)

## Overview
A screenshot of the Mac OS X **Bluetooth Setup Assistant** window (`Bluetooth Device Set Up`) discovering an **i.Trek Z1 Solar Bluetooth Data Logger GPS** (`iBT-GPS`) during initial pairing.

- **Header & Instructions**:
  - Top header in bold: **`Bluetooth Device Set Up`**
  - Subheading inside the main pane: **`Searching for your device`**

See the documentation that came with your Bluetooth device to determine if you need a specific passkey option. Otherwise, select it and click Continue."`
- **Device List Table**:
  - A two-column table with headers **`Devices`** and **`Type`**.
  - A single row is highlighted in blue with white text: **`iBT-GPS`** under `Devices` and **`Device`** under `Type`.
- **Status & Action Buttons**:
  - Below the table is a spinning Mac OS X progress indicator next to the status text: `"Searching for devices - 1 found."`
  - Along the bottom of the dialog are three Aqua-style rounded buttons: **`Passkey Options...`** (on the left), **`Go Back`**, and **`Continue`** (highlighted in blue on the right).
