# Mac OS X Bluetooth Setup Assistant — Passkey Options Sheet (`i.trek-z1-gps-2.png`)

## Overview
A screenshot of the modal **Passkey Options** sheet in the Mac OS X Bluetooth Setup Assistant, showing the radio button selection `"Use a specific passkey"` required to pair the i.Trek Z1 Bluetooth GPS receiver (which uses the fixed passkey `0000`).

## Interface & Visible Text
- **Introductory Text**:
  - `"Most Bluetooth devices use an automatically generated passkey. Some may use other passkey options. See the documentation that came with your Bluetooth device."`
  - `"A passkey is used only once to establish a secure connection between Bluetooth devices."`
- **Radio Button Options**:
  1. **Unselected**: **`Automatically generate a passkey`**
     - Subtext: `"Some Bluetooth devices use a passkey that is created automatically."`
  2. **Unselected**: **`Use an "empty" passkey`**
     - Subtext: `"Some Bluetooth devices don't require a passkey. Your Bluetooth mouse, for example, may use an "empty" passkey."`
  3. **Selected (blue Aqua radio button with black center dot)**: **`Use a specific passkey`**
     - Subtext: `"Use this option if your Bluetooth device requires a specific passkey."`
  4. **Unselected**: **`Do not use a passkey with this device`**
     - Subtext: `"Most Bluetooth devices require that you use a passkey. Some Bluetooth devices, such as certain Bluetooth printers, do not require a passkey."`
- **Bottom Buttons**:
  - Two Aqua buttons in the bottom-right corner: **`Cancel`** and **`OK`** (default pulsing blue button).
  - The underlying `Bluetooth Device Set Up` window is faintly visible through the translucent white sheet background.
