# Mac OS X Bluetooth System Preferences — Configured iBT-GPS Device (`i.trek-z1-gps-3.png`)

## Overview
A screenshot of the **Bluetooth** pane in Mac OS X System Preferences (`Devices` tab), showing the successfully paired and configured **i.Trek Z1 Bluetooth GPS** (`iBT-GPS`) with Serial Port Profile (`SPP slave`) enabled.

  - Toolbar below with back/forward navigation arrows, a **`Show All`** button, and a rounded search field with a magnifying glass icon on the right.
- **Tab Bar**:
  - Three segmented tabs centered at the top of the pane: **`Settings`**, **`Devices`** (selected in blue), and **`Sharing`**.
- **Left Column (Device List & Details)**:
  - **Bluetooth Devices:**: A list box with **`iBT-GPS`** highlighted in blue, accompanied by a red heart icon (indicating a Favorite device) and a small silver key icon (indicating paired/authenticated status).

    - `Device Address:` *(blank)*
    - `Device Type: Unclassified`
    - `Device Services: SPP slave`
    - `Paired: Yes`
    - `Configured: Yes`
    - `Favorite: Yes`
    - `Connected: No`
    - `Serial Port: Yes`
- **Right Column (Action Buttons)**:

    - **`Delete...`** (active)
