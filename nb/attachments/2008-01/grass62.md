# GRASS GIS 6.2.3 Startup Dialog on Mac OS X X11 (`grass62.png`)

## Overview
A screenshot of the **GRASS 6.2.3 Startup** X11/TclTk graphical dialog window running on Mac OS X 10.5 (Leopard), packaged via Fink (`grass62`).

## Interface & Controls
- **Window Title Bar**:
  - Mac OS X Aqua window controls (red, yellow, green buttons) on the left and the X11 icon with title **`GRASS 6.2.3 Startup`** in the center.
- **Top Graphic Banner**:
  - Left side: The classic **GRASS GIS** logo featuring green Stylized grass blades inside a diamond above a black V-shaped base, next to large green serif text reading **`GRASS`** / **`GIS`** on a cream background.
  - Right side: A composite geospatial graphic showing 3D shaded-relief terrain models, vector road networks on a black background, soil/geology polygons, and a global bathymetry/topography globe.
- **Welcome & Instructions**:
  - Centered green bold text:
    - **`Welcome to GRASS GIS Version 6.2.3`**
    - **`The world's leading open source GIS`**
    - **`Select an existing project location and mapset`**
    - **`or define a new location`**
- **Directory & Location Selection Controls**:
  - **`GIS Data Directory:`** text input field containing `/Users/schwehr/Images` with a horizontal scrollbar underneath and a **`Browse...`** button to the right.
  - **Left Listbox**: Labeled **`Project Location`** / **`(projection/coordinate system)`** (empty white scrollable box).
  - **Center Listbox**: Labeled **`Accessible Mapsets`** / **`(directories of GIS files)`** (empty white scrollable box).
  - **Right Column Controls**:
    - **`Create new mapset`** / **`in selected location`**: Text input box followed by a disabled **`Create new mapset`** button.
    - **`Define new location with...`**: Three stacked action buttons:
      1. **`Georeferenced file`**
      2. **`EPSG codes`**
      3. **`Projection values`**
- **Bottom Action Bar**:
  - Three buttons aligned on the bottom left: **`Enter GRASS`** (disabled/grayed out), **`Exit`**, and **`Help`**.
