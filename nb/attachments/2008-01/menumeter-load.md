# MenuMeters Dual-Core CPU Load Display on Mac OS X (`menumeter-load.png`)

## Overview
A small cropped screenshot of the **MenuMeters** CPU load monitor widget in the Mac OS X 10.5 (Leopard) menu bar, showing both cores of an Intel Core 2 Duo processor running near maximum capacity.

## Interface Details
- **Layout**: Set against the translucent light-gray gradient of the Mac OS X menu bar, two side-by-side CPU core monitors are displayed:
  - **Core 1 (Left)**: A miniature scrolling history graph filled nearly to the top with a lower red band (system CPU usage, roughly 45%) and an upper dark blue band (user CPU usage, roughly 51%), followed by the black numeric readout **`96%`**.
  - **Core 2 (Right)**: A matching miniature scrolling history graph with a lower red band (system usage) and an upper dark blue band (user usage) reaching nearly 100% height, followed by the black numeric readout **`95%`**.
