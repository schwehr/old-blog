# SCPlugin Subversion Contextual Menu in Mac OS X Finder (`scplugin-2.png`)

## Overview
A screenshot of Mac OS X 10.5 Finder showing the nested contextual (right-click) menu provided by **SCPlugin** on a version-controlled folder (`worklogs`), highlighting the `More -> Subversion -> Refresh Icons` command.

  - Behind the menus is a web browser window displaying documentation text about SCPlugin contextual menus, URLs beginning with `"http"`, `"https"`, or `"svn"`, and `"Check out"` credentials.
