# SCPlugin Subversion Status Icon Overlays in Mac OS X Finder (`scplugin.png`)

## Overview
A screenshot of a Mac OS X Finder window in icon view illustrating **SCPlugin** (Subversion integration for Mac OS X Finder, similar to TortoiseSVN), which overlays green checkmark badges onto version-controlled folders.
