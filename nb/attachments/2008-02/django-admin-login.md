# Django Administration Login Screen (`django-admin-login.png`)

## Overview
A screenshot of the standard Django administration login dialog box showing the header bar, username and password fields, and login button.

## Interface & Controls
- **Dialog Box**:
  - A centered rectangular box with a thin gray border and white background.
  - **Top Banner**: A slate-blue header bar displaying `Django administration` in pale yellow sans-serif text on the left.
  - **Form Inputs**:
    - `Username:` right-aligned label next to a blank text input box with a vertical text cursor (`|`) focused at the start of the field.
    - `Password:` right-aligned label next to a blank password input box.
  - **Submit Button**:
    - A centered light-gray rectangular button below the fields labeled `Log in`.
