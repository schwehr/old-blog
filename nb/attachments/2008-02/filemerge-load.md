# Apple FileMerge Compare Files Dialog (`filemerge-load.png`)

## Overview
A macOS Aqua screenshot of the **Compare Files** startup dialog from Apple's **FileMerge** utility (`/Developer/Applications/Utilities/FileMerge.app`, part of Xcode on Mac OS X 10.5 Leopard), configured to compare two Python template scripts on the user's Desktop.

## Interface & Controls
- **Window Frame**: A compact Mac OS X Leopard dialog window titled **Compare Files** in the center of the brushed-metal/gray title bar, with standard red (close), yellow (minimize), and green (zoom) traffic-light window controls in the upper-left corner and a diagonal resize grip in the lower-right corner.
- **File Selection Rows**:
  - **Left File Row**: An Aqua rounded push button labeled **Left...** on the left, paired with a text input field highlighted with a blue focus ring containing the path `/Users/schwehr/Desktop/template-1.py`.
  - **Right File Row**: An Aqua rounded push button labeled **Right...** on the left, paired with a text input field containing the path `/Users/schwehr/Desktop/template-2.py`.
- **Drag-and-Drop Wells**: To the right of the path fields are two square recessed drop wells labeled **Left** and **Right** above their top edges, each displaying a white generic document icon with a folded top-right corner.
- **Action Button & Status Note**:
  - In the lower-right corner is a pulsing blue default Aqua button labeled **Compare**.
  - Along the bottom-left edge in small dark-gray text is the hint: `Enlarge window to specify ancestor and/or merge paths.`
