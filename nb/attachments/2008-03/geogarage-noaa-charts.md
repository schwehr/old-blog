# GeoGarage NOAA Raster Nautical Chart Overlay of St. Lawrence Island (`geogarage-noaa-charts.png`)

## Overview
A web browser screenshot showing the GeoGarage online map viewer (`http://demo.geogarage.com/noaa/`) displaying a semi-transparent NOAA BSB Raster Nautical Chart (RNC) overlaid on Google Maps satellite imagery of Northeast Cape on St. Lawrence Island, Alaska.

## Browser & Map Interface Controls
- **Browser Toolbar (Top)**:
  - Standard navigation buttons on the left: green back arrow, disabled forward arrow, blue reload icon, disabled stop icon, and a home icon.
  - Address bar showing the URL: `http://demo.geogarage.com/noaa/?lat=63.3388` with a green go arrow to the right.
  - Google search bar on the far right with the Google "G" icon and magnifying glass.
- **Map Navigation Controls (Left)**:
  - Four directional pan buttons (up, down, left, right arrows) with a center return button.
  - Vertical zoom slider bar with `+` (top) and `-` (bottom) buttons.
- **Layer & Opacity Controls (Top Right)**:
  - Map type toggle buttons: `Map` and `Satellite` (with `Satellite` selected in a blue border).
  - Opacity slider labeled `NOAA` (set near the middle) controlling the transparency of the NOAA nautical chart overlay.
  - Opacity slider labeled `labels` (set all the way to the right).
- **Bottom Overlays**:
  - **Bottom Left**: Dual distance scale bars for `5 mi` and `5 km`, coordinate readout `63° 16.0203'N, 169° 6.7529'W (link)`, and a Google logo with a text input box and `Search` button.
  - **Bottom Center**: Copyright text reading `Imagery ©2008 TerraMetrics, Map data ©2008 Tele Atlas - Terms of Use`.
  - **Bottom Right**: Inset overview map showing the eastern portion of St. Lawrence Island in light gray/blue with a blue rectangle outlining the current view extent.

## Map & Nautical Chart Details
- **Satellite Base Layer**: Shows the rugged tundra, green lowlands, scattered white clouds with dark shadows, snow/ice patches on higher terrain, and dark blue Bering Sea waters around eastern St. Lawrence Island.
- **NOAA Chart Overlay**: Covers the upper-right quadrant of the view over **Northeast Cape**:
  - Labels on land include `ST LAWRENCE ISLAND`, `Seepanpak Lagoon`, `Seevoo Pt.`, `PARABOLIC ANTENNA` (marking the former White Alice communications site), `Northeast Cape`, and elevation contours labeled `1822`, `1000`, `500`, and `1446`.
  - Offshore hydrographic features include depth soundings in fathoms (`15`, `16`, `14`, `13`, `11`, `8_4`, `6_2`, `3_4`, `7`, `0_4`, `6_4`, `7_3`, `2_2`, `1_3`, `9`, `3`, `20`, `8_3`, `6_3`, `7_4`, `2_4`, `4_1`), bottom characteristics (`G`, `S`, `rky`), a note reading `TERRITORIAL SEA (see note X)`, and magenta Loran-C lines (`48050`, `Z-48000`).
