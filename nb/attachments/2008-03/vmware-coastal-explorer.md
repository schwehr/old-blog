# Rose Point Coastal Explorer Running in Windows XP on VMware Fusion (`vmware-coastal-explorer.png`)

## Overview
- **Image Type:** Desktop screenshot (Mac OS X 10.5 running VMware Fusion)
- **Subject / Context:** A screenshot taken on March 10, 2008, showing Rose Point **Coastal Explorer** navigation software running inside a **Windows XP Professional** virtual machine via **VMware Fusion** on an Intel Mac laptop, used to plan a research cruise around Scituate and Stellwagen Bank, Massachusetts.
