# Running Windows XP Professional and Ubuntu 7.10 Simultaneously in VMware Fusion (`vmware-multi-os.png`)

## Overview
- **Image Type:** Desktop screenshot (Mac OS X 10.5 running two VMware Fusion virtual machines concurrently)
- **Subject / Context:** A screenshot taken on March 8, 2008, demonstrating **Ubuntu 7.10** Linux and **Windows XP Professional** running simultaneously in separate VMware Fusion windows on a Mac OS X Leopard laptop, along with the Mac `Virtual Machine Library` window.

## Interface & Window Details
- **Mac OS X Menu Bar (Top):** Shows the Apple icon, `VMware Fusion`, `File`, `Edit`, `View`, `Virtual Machine`, `Applications`, `Window`, `Help`, and MenuMeters CPU/RAM usage graphs (`19%`, `19%`) and network throughput (`Tx: 0B/s`, `Rx: 0B/s`).
- **Background Left Window (`Ubuntu 7.10 En`):**
  - A VMware Fusion window titled `Ubuntu 7.10 En` with toolbar icons (`Suspend`, `Take Snapshot`, `Revert to Snapshot`, `Settings`).
  - Inside the guest OS, the top GNOME panel is visible with the Ubuntu logo, `Applications`, `Places`, `System`, and quick-launch icons for Firefox, Evolution mail, and Help, above a dark brown desktop background and a bottom panel bar.
  - The bottom VMware status bar states: `VMware Tools is out of date. Choose the Virtual Machine > Install VMware Tools menu.`
- **Middle Left Window (`Virtual Machine Library`):**
  - The Mac OS X `Virtual Machine Library` floating window displays the interlocking gray-and-red `VMware Fusion™` icon on the left and a `Virtual Machines:` list on the right showing both `Ubuntu.vmx` and `Windows XP Professional`, with `New...` and `Download...` buttons below.
- **Foreground Right Window (`Windows XP Professional`):**
  - A second VMware Fusion window titled `Windows XP Professional` displays the classic green hill and blue sky ("Bliss") wallpaper and green `start` button at the bottom (`To return to your computer, press Control-⌘`).
  - Centered inside the Windows XP desktop is the **`Disk Cleanup for Local Disk (C:)`** dialog box:
    - Shows the `Disk Cleanup` tab active (next to `More Options`), stating: `You can use Disk Cleanup to free up to 1,784,238 KB of disk space on Local Disk (C:).`
    - In the `Files to delete:` list, `Offline Files` (`0 KB`) and `Compress old files` (`1,784,206` KB, highlighted in blue) are checked, while `WebClient/Publisher Temporary Files` (`32 KB`), `Temporary Offline Files` (`0 KB`), and `Catalog files for the Content Indexer` (`0 KB`) are unchecked.
    - Below, `Total amount of disk space you gain:` shows `1,784,206`, followed by a `Description` box explaining file compression and buttons for `Options...`, `OK`, and `Cancel`.
