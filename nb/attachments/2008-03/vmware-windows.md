# Windows XP Professional Running in VMware Fusion (`vmware-windows.png`)

## Overview
A screenshot of Microsoft Windows XP Professional running inside a VMware Fusion virtual machine window on Mac OS X, displaying the classic "Bliss" green hill and blue sky wallpaper, desktop application shortcuts, and a system tray notification balloon.

## VMware Fusion Window Chrome
- **Title Bar:** Displays the Mac OS X red, yellow, and green window buttons on the left and the title **Windows XP Professional** in the center.
- **Toolbar:** Features large metallic buttons on the left for **Suspend**, **Take Snapshot**, **Revert to Snapshot** (disabled/grayed out), and **Settings**, and buttons on the right for **Unity** and **Full Screen**.
- **Bottom Status Bar:** Displays the message `VMware Tools is out of date. Choose the Virtual Machine > Install VMware Tools menu.` on the left, and virtual hardware indicator icons on the right (three USB ports, optical drive, hard drive, floppy/shared folder, network adapter, and audio).

## Windows XP Desktop & Interface
- **Wallpaper:** The default Windows XP "Bliss" landscape photograph featuring a vibrant green rolling hillside beneath a bright blue sky with scattered white cumulus and cirrus clouds.
- **Desktop Shortcuts (arranged vertically along the left edge):**
  - **Recycle Bin**
  - **My Bluetooth Places**
  - **3Dconnexion Control Panel**
  - **Adobe Reader 7.0**
  - **Cygwin**
  - **DataLog**
  - **ME70**
  - **Mozilla Firefox**
- **Taskbar & System Tray (Bottom):**
  - Green **start** button on the left with the Windows logo.
  - Blue taskbar bar spanning the bottom.
  - Notification pop-up balloon pointing to the system tray: titled **Take a tour of Windows XP** with an information icon (`i`) and close button (`x`), reading: *"To learn about the exciting new features in XP now, click here. To take the tour later, click All Programs on the Start menu, and then click Accessories."*
  - System tray icons include network disconnected/status icons, Windows Security Alerts shield (red with white cross), VMware Tools icon, Windows XP Tour icon, Bluetooth icon, Safely Remove Hardware icon, volume control, and the clock reading `2:16 PM`.
