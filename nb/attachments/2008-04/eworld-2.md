# eWorld Traffic Simulation Screenshot (`eworld-2.jpg`)

## Overview
A Mac OS X application window screenshot of **eWorld** (`eWorld - berlin2.xml`), an open-source Java tool for importing OpenStreetMap road networks and configuring traffic simulations and environmental events.

## Interface & Controls

### Window Header & Simulation Timeline (Top)
- **Title Bar:** Standard Mac OS X window title bar displaying a small globe icon and the title `eWorld - berlin2.xml`.
- **Simulation Controls:**
  - Left input field: `Simulation Start Time` set to `0` `s`.
  - Center progress bar: A wide horizontal gray bar.
  - Right input field: `Simulation End Time` set to `10000` `s`.

### Main Map Canvas (Center-Left)
- **Road Network:** Gray double-line street segments depict a road network in Berlin, Germany, with a major multi-lane avenue running diagonally from the bottom center to the upper right.
- **Weather & Hazard Zones (Blue Polygons):**
  - A large circular lavender-blue shaded zone covers the left side of the map, containing a raincloud icon.
  - A five-sided translucent lavender-blue polygon overlays the central road intersection, containing a triangular red-bordered **slippery road** warning sign.
- **Map Markers & Icons:**
  - Four pairs of crossed checkered flags mark points of interest or route waypoints across the network (one near the left edge, one with a red `X` next to it inside the circular zone, one in the upper-left center, and one near the bottom right).
  - A yellow diamond **road work / construction** sign sits on the main diagonal avenue near the center.
  - A triangular red-bordered hazard sign sits along a side street on the right.
- **Status Bar Coordinates (Bottom Left):** Displays the cursor's geographic coordinates: `52.5184165135129 N / 13.408635808002064 E`.

### Right Sidebar Panels
- **Information Panel (Top Right):** Headed `Information` (with minimize and close buttons), displaying:
  - `point of interest:`
  - `Rotes Rathaus`
- **Toolbar Panel (Bottom Right):** Headed `Toolbar` with a vertical scroll bar, showing draggable event/weather icons including polygon tools for fog (`FOG`), snow, raincloud, and slippery road hazards, plus a crossed-checkered-flag waypoint icon at the bottom.
