# Firefox Preferences Window Showing Multiple Home Pages (`firefox-multihomepage.png`)

## Overview
A screenshot of the Mozilla Firefox Preferences dialog on Mac OS X (in the **Main** tab), demonstrating how to configure multiple startup tabs by separating URLs with a vertical pipe (`|`) character in the **Home Page** text field.

## Interface & Controls
- **Window Title & Toolbar:** A Mac OS X utility window titled `Main`. Below the title bar is a horizontal icon toolbar with seven sections:
  - **Main** (selected, highlighted in gray with a slider switch icon)
  - **Tabs** (tabbed window icon)
  - **Content** (blue globe icon)
  - **Feeds** (orange RSS icon)
  - **Privacy** (padlock with red minus sign)
  - **Security** (silver padlock icon)
  - **Advanced** (gear icon)
- **Startup Group:** Under the section heading `Startup`:
  - **When Firefox starts:** A drop-down menu currently set to `Show my home page`.
  - **Home Page:** A text input box containing two pipe-separated URLs with the text cursor positioned immediately after the pipe character:
    `google.com|http://vislab-ccom.unh.edu/~schwehr/`
  - **Action Buttons:** Three rounded Aqua-style buttons arranged horizontally beneath the text box:
    - `Use Current Page`
    - `Use Bookmark`
    - `Restore to Default`
- **Downloads Group:** At the bottom of the cropped window, the `Downloads` section heading and horizontal divider line are visible.
