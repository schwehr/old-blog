# DiskWarrior Directory Rebuild Progress Dialog (`diskwarrior-1.png`)

## Overview
A Mac OS X screenshot of Alsoft's DiskWarrior 4 utility rebuilding the corrupted HFS+ directory of a laptop hard drive named `CatBoxIII`, which is mounted via FireWire Target Disk Mode.

## Progress Sheet (Top)
A modal sheet drops down from the top of the DiskWarrior window showing two blue-and-white Aqua progress bars:
- **Primary Status**: `Comparing directories...` with a horizontal blue Aqua progress bar roughly 75% filled.
- **Secondary Step Status**: `Step 9: Waiting for Mac OS X system services to complete...` with a second horizontal blue Aqua progress bar nearly 98% filled.
- **Action Buttons**: Two rounded Mac OS X Aqua buttons in the bottom-right corner of the sheet: `Skip` and `Cancel`.

## Main Window & Disk Details (Bottom)
Below the modal sheet is the main DiskWarrior interface:
- **Disk Selector Dropdown**: A pop-up menu displaying `CatBoxIII` with a blue double-arrow selector on the right.
- **Status Banner**: A green checkmark icon (`✔`) followed by `Directory is currently being rebuilt.`
- **Drive Icon**: On the left side of the info panel is a gold/orange external FireWire hard drive icon bearing the white three-pronged FireWire (IEEE 1394) symbol on its top surface.
- **Disk Information & Advanced Specs**:
  - `• This disk appears to be a Mac OS Extended disk.`
  - `• This disk does not appear on the desktop.`
  - `• This disk is 148.73 GB in size.`
  - Expanded disclosure triangle `▼ Advanced`:
    - `• Disk ID: disk2s2`
    - `• Sectors: 311,909,984 (512 Bytes each)`
    - `• Drive Format: GUID Partition Table`
    - `• File System: HFS (Extended, No wrapper)`
    - `• Model: AAPL Target Disk Mode`
- **Bottom Window Buttons**: Two disabled (grayed-out) buttons in the lower right corner: `Graph` and `Rebuild`.
