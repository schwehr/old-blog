# Firefox Print Dialog Showing Background Options (`firefox-print.png`)

## Overview
A Mac OS X screenshot showing the Firefox print dialog sheet pulled down over a webpage titled "Cue Sheet - 2008-05-28 Sol 3 @...", highlighting the checkboxes for printing background colors and images.

## Interface & Controls
- **Background Webpage**: Behind the print sheet, a webpage header reads `Cue Sheet - 2008-05-28 Sol 3 @` in bold black text with a black-to-white horizontal gradient box on the left. Below it is a yellow table cell reading `Presenter 1:` and a black rectangle with a white top border on the right.
- **Print Dialog Header**: Standard Mac OS X Leopard sheet titled `Print` at the top.
- **Top Print Settings**:
  - `Printer:` dropdown (redacted with a black-to-white horizontal gradient) and a blue collapse/expand disclosure button (`▲`).
  - `Presets:` dropdown set to `Standard`.
  - `Copies:` text input set to `1` (highlighted with a blue focus ring), followed by unchecked checkboxes for `Collated` and `Two-Sided`.
  - `Pages:` radio buttons with `All` selected, and `From: 1 to: 1` unselected below.
- **Application-Specific Section (`Firefox` selected in dropdown)**:
  - `Options:`: `Print Selection Only` (disabled/grayed out, unchecked) and `Shrink To Fit Page Width` (checked).
  - `Appearance:` (circled with a bright magenta/purple hand-drawn oval annotation):
    - `Print Background Colors` (checked).
    - `Print Background Images` (unchecked).
  - `Frames:` (all disabled/grayed out): radio buttons for `As laid out on the screen`, `The selected frame`, and `Each frame separately`.
  - `Page Headers:`: three dropdowns for `Left`, `Center`, and `Right` set to `Title`, `(Blank)`, and `URL`.
  - `Page Footers:`: three dropdowns set to `Page # of #`, `(Blank)`, and `Date/Time`.
- **Bottom Action Bar**:
  - Purple circular help button (`?`), `PDF ▼` dropdown button, `Preview` button, yellow-tinted `Supplies...` button next to a yellow warning triangle with `!` and the label `Low`, `Cancel` button, and default blue `Print` button.
