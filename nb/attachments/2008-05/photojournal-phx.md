# NASA JPL Photojournal Search Results for the Phoenix Mars Mission (`photojournal-phx.png`)

## Overview
A screenshot of NASA Jet Propulsion Laboratory's **Photojournal** web interface (`http://photojournal.jpl.nasa.gov/mission/Phoenix`) taken prior to landing, displaying 26 pre-landing instrument images for the Phoenix Mars Lander mission.

## Header & Search Controls
- **Banner**: A dark reddish-brown banner featuring a glowing solar flare/sun graphic on the left, large white serif text `PHOTOJOURNAL`, and `Select An Image Gallery ▶` on the right.
- **Query Summary & Quick Lookup**:
  - Left text: `Your Search Criteria found 26 images` / `Mission` (bold).
  - Right controls: `Go directly to image (PIxxxxxx):` text input box and a link for `Other Query Options`.
  - Center links and instructions: `Refine results further` above `Click on a column heading to sort the list. Click on an image for detailed information.`
