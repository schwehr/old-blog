# QuickTime Standard Video Compression Settings (`animatedgif2hd-1.png`)

## Overview
A cropped macOS screenshot showing the top portion of QuickTime Pro's "Standard Video Compression Settings" dialog window, illustrating the first step in converting an animated GIF into a high-definition DVCPRO HD video file when Final Cut Pro codecs are installed.

## Interface & Controls
- **Window Header**: A standard Mac OS X brushed/gradient gray title bar labeled `Standard Video Compression Settings`.
- **Compression Type**: At the top center, a dropdown menu labeled `Compression Type:` is set to `DVCPRO HD 1080i60` with a blue double-arrow selector button on the right.
- **Motion Panel (Left)**:
  - **Frame Rate**: A dropdown menu labeled `Frame Rate:` is set to `29.97` with `fps` to the right.
  - **Key Frames**: Three radio buttons below `Key Frames:` are disabled (grayed out):
    - `Automatic` (unselected)
    - `Every` (unselected, accompanied by an empty text input box followed by `frames`)
    - `All` (selected with a gray dot, indicating all frames are key frames for DVCPRO HD)
- **Data Rate Panel (Right)**:
  - **Data Rate**: Two disabled radio buttons labeled `Data Rate:`:
    - `Automatic` (selected with a gray dot)
    - `Restrict to` (unselected, accompanied by a partially visible empty text input box on the right edge)
  - **Optimized for**: A disabled dropdown menu labeled `Optimized for:` set to `Download`.
