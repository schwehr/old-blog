# QuickTime Export Size Settings (`animatedgif2hd-2.png`)

## Overview
A macOS screenshot of the "Export Size Settings" dialog window in QuickTime Pro, illustrating how to configure 1080p HD dimensions and aspect ratio preservation when exporting an animated GIF to a high-definition movie.

## Interface & Controls
- **Window Header**: A standard Mac OS X gray gradient title bar reading `Export Size Settings`.
- **Dimensions**: A dropdown menu labeled `Dimensions:` set to `HD 1920 x 1080 16:9` with a blue up/down selector button.
- **Aspect Ratio**:
  - A checked blue Aqua checkbox labeled `Preserve aspect ratio using:`.
  - To its right, a dropdown menu is set to `Crop` with the helper text `(if required)` positioned directly underneath the dropdown.
- **Deinterlace Option**: An unchecked checkbox below labeled `Deinterlace Source Video`.
- **Action Buttons**: In the bottom right corner, two standard Aqua pill-shaped buttons: `Cancel` (white/gray) and `OK` (highlighted in pulsing blue).

## Visible Text & Labels
- `Export Size Settings`
- `Dimensions: HD 1920 x 1080 16:9`
- `Preserve aspect ratio using: Crop (if required)`
- `Deinterlace Source Video`
- `Cancel`, `OK`
