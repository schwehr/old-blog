# QuickTime Movie Settings Summary (`animatedgif2hd-3.png`)

## Overview
A macOS screenshot of the "Movie Settings" dialog window in QuickTime Pro, summarizing the video, sound, and internet streaming configuration prior to exporting an animated GIF as a DVCPRO HD movie.

## Interface & Controls
- **Window Header**: A standard Mac OS X gray gradient title bar reading `Movie Settings`.
- **Video Section (Top)**:
  - Enabled via a checked blue checkbox labeled `Video`.
  - Three stacked pill-shaped buttons on the left: `Settings...`, `Filter...`, and `Size...`.
  - A recessed summary text box on the right displaying the current video export configuration:
    - `Compression: DVCPRO HD 1080i60`
    - `Quality: Medium`
    - `Frame rate: 29.97`
    - `Dimensions: 1920x1080 (1888x1062)`
    - `Scale: Crop`
  - Below the buttons, a disabled (grayed-out) unchecked checkbox labeled `Allow Transcoding`.
- **Sound Section (Middle)**:
  - Disabled via an unchecked checkbox labeled `Sound` (grayed out).
  - A disabled `Settings...` button on the left and a grayed-out summary box on the right reading:
    - `Format: Integer (Little Endian)`
    - `Sample rate: 48.000 kHz`
    - `Sample size: 16-bit`
    - `Channels: Stereo (L R)`
- **Internet Streaming Section (Bottom)**:
  - An unchecked checkbox labeled `Prepare for Internet Streaming`.
  - Below it, a disabled dropdown menu set to `Hinted Streaming` and a disabled `Settings...` button.
- **Dialog Buttons**: At the bottom right, `Cancel` and `OK` (highlighted in blue) buttons.

- `Movie Settings`
- `Video` (`Settings...`, `Filter...`, `Size...`, `Allow Transcoding`)

- `Cancel`, `OK`
