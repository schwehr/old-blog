# Mac OS X "About This Mac" Window for Dual Quad-Core Xeon (`dual-quad-core.png`)

## Overview
A screenshot of the Mac OS X **"About This Mac"** dialog window from a newly configured Apple Mac Pro server equipped with dual 2.8 GHz Quad-Core Intel Xeon processors (8 cores total) and 10 GB of RAM, used to drive the 5-projector, 60-foot-wide display wall in the Phoenix Mars Lander Science Operations Center (SOC).

## Interface & Visible Text
- **Graphics**: Centered at the top against the light grey window background is the glossy silver 3D Apple logo.
- **Operating System Header**:
  - **`Mac OS X`** in large bold dark-grey sans-serif text.
  - **`Version 10.5`** in smaller medium-grey text directly below.
- **Button**: A rounded pill-shaped Aqua button labeled **`Software Update...`** sits below the version number.
- **Hardware Specifications**:
  - **`Processor`** `2 x 2.8 GHz Quad-Core Intel Xeon`
  - **`Memory`** `10 GB 800 MHz DDR2 FB-DIMM`
