# StarDot NetCam SC Web Configuration Interface (`stardot-web-ui.png`)

## Overview
A screenshot of the web-based administration interface (`StarDot/NetCamSC 1.1.55`) for a StarDot Technologies NetCam SC 5-megapixel IP camera, open to the **Image** settings tab.

## Interface & Controls
- **Header Banner**:
  - Styled with a dark navy-blue background.
  - Top left shows the StarDot Technologies logo (a blue six-spoked asterisk with an orange dot on the lower-right spoke, next to `STARDOT™ Technologies` in white text) and firmware version `StarDot/NetCamSC 1.1.55`.
  - Top right displays navigation links: `Live Image Page | Pop-up Live Image`.
- **Navigation Tabs**:
  - A horizontal row of eight tabs runs across the top of the panel:
    - **Image** (selected, highlighted in yellow bold text)
    - **Overlay**, **FTP**, **Date/Time**, **Network**, **Dial-Out**, **Security**, **Advanced** (light blue text).
- **Settings Sections (on Slate-Blue Background)**:
  - **`[-] PROCESSING`** (expanded, yellow header):
    - `Resolution:` dropdown set to `2592x1944 FULL (UHR-4.8)`.
    - `Saturation:` text box set to `140`.
    - `Haze:` text box set to `10`, with a checked `[x] Auto Haze` checkbox to the right.
    - `JPEG Quality:` text box set to `80`, with a checked `[x] Sharpen` checkbox to the right.
  - **`[-] EXPOSURE`** (expanded, yellow header):
    - Radio buttons for `Manual` (unselected) and `Auto` (selected).
    - `Exposure:` text box (grayed out) showing `1600`.
    - `Brightness:` text box set to `100`.
    - `Sync:` radio buttons for `Off` (unselected), `60Hz` (selected), and `50Hz` (unselected).
  - **Collapsed Sections**:
    - `[+] EXPOSURE GRID` (`Click to expand`)
    - `[+] ADVANCED` (`Click to expand`)
  - **`[-] MISCELLANEOUS`** (expanded, yellow header):
    - `Frame Skip:` text box set to `0`.
    - `LED:` dropdown set to `Always Green`.
    - `Video Out:` dropdown set to `NTSC`.
    - `IR:` dropdown set to `Auto`.
  - **`[+] COLOR BALANCE`** (`Click to expand`).
- **Action Buttons**:
  - Bottom right corner contains three rounded gray buttons: `Help`, `Apply`, and `Cancel`.
