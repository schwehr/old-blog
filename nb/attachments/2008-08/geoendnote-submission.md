# EndNote Output Style Request Form Submission for GeoEndNote (`geoendnote-submission.png`)

## Overview

A screenshot of a completed web form on Thomson Reuters' EndNote website submitting "GeoEndNote" (a Google Earth KML / Well-Known Text geospatial bibliography output style) as a suggested output format. Posted by Kurt Schwehr on August 25, 2008 in the blog entry "Submitted GeoEndNote to Thomson Reuters."

## Interface & Form Fields

- **Header & Top Selection**:
  - A dark blue banner across the top displays bold white sans-serif text: `Request Form`.
  - Below the banner are two centered radio buttons:
    - `New File` (selected with a blue Mac OS X Aqua radio button).
    - `Update Existing File` (unselected).
- **Section 1: `Requestee Information`** (Blue bold subheading):
  - **`Your Name`**: Text input containing `Kurt Schwehr`.
  - **`Your Email Address`**: Text input containing `kurt@ccom.unh.edu`.
  - **`Current Version`**: Mac OS X Aqua dropdown menu selected to `X1`.
- **Section 2: `Publication Information`** (Blue bold subheading):
  - **`Publication (no abbr. please)`**: Text input containing `Google Earth KML`.
  - **`URL (or source) for Author's Guidelines`** (`Author's Guidelines` is a red underlined hyperlink): Text input showing the end of a URL: `hwehr/papers/gebco-200805.png`.
  - **`Publisher Address Line 1`**: Empty text input.
  - **`Publisher Address Line 2`**: Empty text input.
  - **`City`**: Empty text input.
  - **`State or Province`**: Empty text input.
  - **`Postal Code`**: Empty text input.
  - **`Country`**: Empty text input.
  - **`Email of Editor`**: Empty text input.
  - **`Comments`**: Multi-line textarea (highlighted with a blue focus ring and vertical scrollbar) containing the visible text:
    ```text
    Mapping, we created
    a GeoEndNote
    prototype using WKT.
    ```
    (`GeoEndNote` and `WKT` have red dotted spell-check underlines).
- **Submit Button (Bottom Left)**:
  - A rectangular light green button with a dark teal border and bold red text reading `Submit Request`.
