# AIS Minimum Keyboard Display (MKD) Configuration Screen (`cape-cod-mkd.jpg`)

## Overview
A close-up photograph taken in low light showing the illuminated front panel of a C.N.S. Systems Automatic Identification System (AIS) Minimum Keyboard Display (MKD) unit installed at the Cape Cod AIS station.

## Display & Keypad Details
- **LCD Screen (Top)**: A rectangular, bright green backlit dot-matrix LCD screen at the top of the unit displays a four-line configuration menu in dark monospace characters:
  - Line 1: `CONFIGURE`
  - Line 2: ` Backlight (15/15)`
  - Line 3: ` Port settings`
  - Line 4: `>Silent mode Off` (with the `>` cursor selecting the fourth line)
- **Branding**: Directly beneath the recessed bezel of the LCD screen is embossed dark lettering reading `C.N.S. Systems`.
- **Backlit Keypad (Bottom)**: Below the screen is a 4x4 grid of square, amber/orange-backlit membrane keys:
  - **Left 3x4 Alphanumeric & Directional Grid** (outlined by a white border box):
    - Row 1: `1 Space` | `2 ▲ ABC` | `3 DEF`
    - Row 2: `4 ◄ GHI` | `5 JKL` | `6 ► MNO`
    - Row 3: `7 PQRS` | `8 ▼ TUV` | `9 WXYZ`
    - Row 4: `SYM` (outside border at bottom left) | `0` (inside border tab) | `ALT` (outside border at bottom third column)
  - **Right Column (Function Keys)**:
    - `MENU`
    - `ESC`
    - `ENT`
    - `CLR / ALARM`
