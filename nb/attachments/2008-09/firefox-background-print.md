# Annotated Screenshot of Firefox 3 Print Dialog Showing Background Color Printing (`firefox-background-print.png`)

## Overview

This annotated Mac OS X screenshot demonstrates how to enable printing background colors in Mozilla Firefox 3. It was posted on September 29, 2008 in the blog entry *"Firefox background color printing"* with the caption `"How to get the background colors to show on the printer"`.

## Interface & Red Oval Annotations

Three thick red ovals highlight the step-by-step selections across the Firefox menu bar and the Mac OS X Print dialog box:

1. **Menu Bar & `File` Menu (Left)**:
   - At the top of the screen, the Mac OS X menu bar shows the Apple logo, `Firefox`, `File` (highlighted in blue), `Edit`, `View`, `History`, `Bookmarks`, `Tools`, `Window`, and `Help`, along with system status icons on the right (Adium duck icon with `1`, Growl paw icon, network `Tx: 40B/s` / `Rx: 111B/s` graph, CPU `24%`, memory `26%`).
   - The open `File` menu lists `New Window (⌘N)`, `New Tab (⌘T)`, `Open Location... (⌘L)`, `Open File... (⌘O)`, `Close (⌘W)`, `Save Page As... (⌘S)`, `Send Link...`, `Page Setup...`, `Print... (⌘P)` (highlighted in blue), `Import...`, and `Work Offline`.
   - **First Red Oval**: Circles `Page Setup...` and the selected `Print... (⌘P)` menu item.

2. **Browser Window Background**:
   - Behind the menus and dialog, Firefox displays a web page titled `xargs -- construct and execute command lines` at URL `http://www.mkssoftware.com/docs/man1/xargs.1.asp`, showing `SYNOPSIS`, `DESCRIPTION`, and `Options` sections for the `xargs` command.

3. **Print Dialog (`Print`, Right)**:
   - `Printer`: Dropdown set to `chub.ccom.nh`.
   - `Presets`: Dropdown set to `Standard`.
   - `Copies`: `1` (selected text box), with `Collated` checked and `Two-Sided` unchecked.
   - `Pages`: Radio button `All` selected (above `From: 1 to: 1`).
   - **Second Red Oval**: Circles the application-specific settings dropdown menu in the middle of the dialog, which is set to `Firefox`.
   - `Options`: `Print Selection Only` (disabled/unchecked) and `Shrink To Fit Page Width` (checked).
   - **Third Red Oval**: Circles the `Appearance:` checkboxes:
     - `Print Background Colors` (checked)
     - `Print Background Images` (unchecked)
   - `Frames`: Disabled radio buttons for `As laid out on the screen`, `The selected frame`, and `Each frame separately`.
   - `Page Headers`: Three dropdowns (`Left`, `Center`, `Right`) set to `Title`, `(Blank)`, and `URL`.
   - `Page Footers`: Three dropdowns (`Left`, `Center`, `Right`) set to `Page # of #`, `(Blank)`, and `Date/Time`.
   - Bottom row buttons: Help (`?`), `PDF ▼`, `Preview`, `Supplies...`, `Cancel`, and `Print` (pulsing blue default button).
