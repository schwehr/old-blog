# Mac OS X 10.5 Screen Sharing Menu and Preferences Dialog (`macosx10.5-screen-sharing-prefs.png`)

## Overview
A screenshot of the Mac OS X 10.5 (Leopard) **Screen Sharing** application showing the open `Screen Sharing` application menu alongside its `Preferences` dialog box, illustrating display scaling, encryption, and quality options for remote VNC/screen-sharing sessions.

## Application Menu Bar & Dropdown (Left)
- **Top Menu Bar**: Shows the Apple icon (``), `Screen Sharing` (highlighted in blue), `Connection`, `Edit`, `View`, `Window`, and `Help`.
- **Dropdown Menu Items**:
  - `About Screen Sharing`
  - `Preferences...` (`⌘,`) — highlighted in blue selection bar
  - `Services` (with submenu arrow)
  - `Hide Screen Sharing` (`⌘H`)
  - `Hide Others` (`⌥⌘H`)
  - `Show All` (grayed out)
  - `Quit Screen Sharing` (`⌘Q`)

## Preferences Dialog Window (Right)
A floating Mac OS X dialog window titled `Preferences` with three radio-button option groups:
1. **`When viewing a computer with a larger screen:`**
   - Selected (`•`): `Scale to fit available space`
   - Unselected (` `): `Show full size`
2. **`When controlling computers:`**
   - Selected (`•`): `Encrypt passwords and keystrokes only (faster)`
   - Unselected (` `): `Encrypt all network data (more secure)`
3. **`When displaying remote screens:`**
   - Selected (`•`): `Adapt quality to network conditions (faster)`
   - Unselected (` `): `Show the screen at full quality (more detailed)`

## Background Context
Behind the menu and preferences dialog is the remote desktop window titled `snares-mm`, showing an `xterm` terminal window over the purple Leopard aurora wallpaper, and the edge of a local terminal window on the far left.
