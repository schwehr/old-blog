# Mac OS X 10.5 Leopard Finder and Screen Sharing Session (`macosx10.5-screen-sharing.png`)

## Overview
A screenshot of Mac OS X 10.5 (Leopard) demonstrating the built-in Screen Sharing feature launched from the Finder to connect to a remote Mac mini (`snares-mm`) running X11 and an `xterm` terminal session.

## Background Window: Mac OS X Finder (`snares-mm`)
- **Window Header & Toolbar**: Standard Aqua brushed-metal/gray window titled `snares-mm` at the top, with back/forward navigation arrows, four view-mode buttons (Column view selected), a Quick Look/Action gear dropdown, and a Spotlight search bar edge on the right.
- **Left Sidebar**:
  - `DEVICES`: `iDisk`, `CatBoxIII` (with an orange cat drive icon).
  - `SHARED`: `Bonita (2)`, `comet`, `dryfly`, `eel`, `snares-mm` (highlighted in gray, showing a Mac mini icon), and a partially occluded entry below (`s...`).
  - `PLACES`: Partially covered icons for Desktop, Home (`schwehr`), Applications, Documents, Movies, Music, and Pictures.
  - `SEARCH FOR`: Partially visible clock icons (`Today`, `Yesterday`, `Past Week`).
- **Column View Pane**:
  - Shows a silver Apple Mac mini icon centered at the top.
  - Labels: `snares-mm` and `Connected as: schwehr`.
  - Two rounded pill buttons: `Disconnect` and `Share Screen...`.
  - Below the buttons is a shared folder item with a blue network folder icon labeled `Kurt Sch...ic Folder` (`Kurt Schwehr's Public Folder`).

## Foreground Window: Screen Sharing (`snares-mm`)
Overlapping the lower-right portion of the Finder window is the active Screen Sharing client window titled `snares-mm`:
- **Remote Desktop**: Displays the remote Mac's top menu bar (``, `X11`, `Applications`, `Edit`, `Window`, `Help`) over the default Mac OS X 10.5 Leopard purple aurora/starfield desktop wallpaper.
- **Remote X11 Terminal (`xterm`)**: Inside the remote desktop is an open white `xterm` window with a bash prompt reading:
  - `* schwehr@snares.ccom.nh 1 $ cd && █`
