# Connecting to Windows XP Tablet PC Edition via rdesktop on Mac OS X (`rdesktop.png`)

## Overview
A screenshot of an X11 `rdesktop` window running on Mac OS X Leopard, connected via Remote Desktop Protocol (RDP) to a remote Windows XP Tablet PC Edition machine (`192.168.8.182`) displaying its login prompt and on-screen virtual keyboard.

## Interface & Window Elements
- **Mac OS X X11 Title Bar**: At the top is a standard Mac OS X window title bar with red, yellow, and green traffic-light window buttons on the left and the X11 icon followed by `rdesktop - 192.168.8.182` centered in the bar.
- **Top Status Banner**: Against the black desktop background in the upper left is a red circular icon showing a white hand pressing a fingerprint sensor, accompanied by bold white sans-serif text reading: `Please connect the fingerprint reader.`
- **Log On to Windows Dialog**: Centered in the middle of the screen is the classic Windows XP logon dialog box:
  - **Title Bar**: Blue gradient bar reading `Log On to Windows`.
  - **Banner Graphic**: Blue gradient banner featuring the four-color Windows flag logo and white text reading `Microsoft Windows XP Tablet PC Edition`, with `Copyright © 1985-2001 Microsoft Corporation` on the bottom left and `Microsoft` on the bottom right, underlined by an orange accent stripe.
  - **Input Fields**: Two text boxes on a beige form background labeled `User name:` (blank) and `Password:` (containing a vertical text cursor `|`).
  - **Buttons**: Four rectangular buttons along the bottom of the dialog: `OK` (highlighted default border), `Cancel`, `Shut Down...` (grayed out/disabled), and `Options <<`.
- **On-Screen Virtual Keyboard**: Positioned below the logon dialog is a blue-trimmed QWERTY virtual keyboard panel containing five rows of dark blue keys with white legends:
  - Row 1: `Esc`, `~`, `!`, `@`, `#`, `$`, `%`, `^`, `&`, `*`, `(`, `)`, `_`, `+`, `Bksp` | `Home`, `PgUp`
  - Row 2: `Tab`, `Q`, `W`, `E`, `R`, `T`, `Y`, `U`, `I`, `O`, `P`, `{`, `}`, `|` | `End`, `PgDn`
  - Row 3: `Caps`, `A`, `S`, `D`, `F`, `G`, `H`, `J`, `K`, `L`, `:`, `"`, `Enter (↵)` | `Del`, `PrtScn`
  - Row 4: `Shift`, `Z`, `X`, `C`, `V`, `B`, `N`, `M`, `<`, `>`, `?`, `Shift` | `Insert`, `Pause`
  - Row 5: `Ctrl`, Windows logo key, `Alt`, Spacebar, Context Menu key, `@`, `↓`, `↑`, `←`, `→` | `Func`, `ScrLk`
