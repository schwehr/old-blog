# Mac OS X Screen Sharing Connection Failure Dialog (`screen-sharing-no-xp.png`)

## Overview
A screenshot of an error dialog sheet from the Mac OS X 10.5 (Leopard) Screen Sharing application after attempting to connect to a Windows XP machine (`192.168.8.182`) that does not run a VNC/Screen Sharing server. Featured in the September 24, 2008 blog post *"Controlling other computers"*.

## Interface & Layout
- **Dialog Window**: A Mac OS X modal alert dialog with a blank gray top title bar and a light-gray body.
- **Application Icon**: On the left side of the dialog is the Mac OS X Screen Sharing icon, depicting two overlapping silver-framed widescreen LCD monitors—the rear monitor displaying a green aurora desktop background and the front monitor displaying a translucent blue aurora desktop background.
- **Action Button**: In the bottom-right corner is a blue default Aqua button labeled **OK**.

## Visible Text & Labels
- **Primary Heading (bold black text)**:
  - `Connection failed to “192.168.8.182”.`
- **Explanatory Message (regular black text)**:
  - `Please make sure that Screen Sharing (in the Sharing section of System Preferences) is enabled on the computer you're attempting to connect to. Also make sure your network connection is working properly.`
