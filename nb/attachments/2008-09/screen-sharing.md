# Mac OS X Screen Sharing Connection Dialog (`screen-sharing.png`)

## Overview
A screenshot of the "Connect to Shared Computer" dialog window from the Mac OS X 10.5 (Leopard) Screen Sharing application, launched via the terminal command line. The screenshot was included in a September 24, 2008 blog post titled *"Controlling other computers"* discussing remote desktop management across Mac, Linux, and Windows systems.

## Interface & Controls
- **Dialog Window**: A standard Mac OS X Aqua-styled window with a gray gradient title bar reading **Connect to Shared Computer**. On the far left of the title bar are the three traffic-light window controls: an active red close button, an active yellow minimize button, and a disabled (grayed-out) zoom button.
- **Host Input Field**: Inside the light-gray dialog body, a label reading `Host:` sits to the left of a focused text input box highlighted with a light-blue focus ring. The IP address `192.168.8.182` is typed into the box, followed by a vertical text cursor bar (`|`).
- **Action Buttons**: In the lower right of the dialog are two pill-shaped Aqua buttons:
  - **Cancel**: A white/gray button on the left.
  - **Connect**: A pulsing blue default action button on the right.

## Terminal Background & Visible Text
- Behind the dialog box is a black terminal window with light-gray/amber monospace text and a solid purple block cursor at the bottom:
  - `% open /System/Library/CoreServices/Screen\ Sharing.app`
