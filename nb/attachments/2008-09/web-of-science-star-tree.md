# ISI Web of Science Citation Map Star-Tree Visualization (`web-of-science-star-tree.png`)

## Overview
A screenshot of the interactive hyperbolic "Citation Map" (star-tree) visualization tool in Thomson Reuters / ISI Web of Knowledge (Web of Science), displaying the citation network for Kurt Schwehr's 2006 *Geochemistry, Geophysics, Geosystems* paper on compaction disequilibrium. Featured in the September 18, 2008 blog post *"Web-Of-Science star tree"*.
