# Zotero Reference Manager Firefox Extension Screenshot (`zotero.png`)

## Overview
A screenshot of a Mozilla Firefox 3 browser window on Mac OS X 10.5 showing the Zotero reference management extension panel open in the bottom half of the window while viewing the Zotero Quick Start Guide web page in the upper half. The library displays Kurt Schwehr's imported scientific publications and software references. Featured in the September 27, 2008 blog post *"Playing with Zotero, GeoEndNote/GeoCite"*.

## Browser & Web Page (Upper Half)
- **Window Header & Navigation Bar**: Standard Mac OS X window title bar reading `quick start guide [Zotero Documentation]` with red, yellow, and green window controls on the top left. Below it is the Firefox 3 navigation bar containing Back/Forward buttons, Reload, Stop, Home, the URL bar with a red `Z` favicon displaying `http://www.zotero.org/documentation/quick_start_guide`, and the Google search box on the right.
- **Web Page Content**: Shows the Zotero header logo (`zotero` in red and dark gray sans-serif letters) next to the tagline `Research, not re-search`, navigation tabs (`Home`, `Support` selected, `Forums`, `Extend`, `For Developers`, `About`), the red heading `quick start guide`, and wiki utility buttons (`Show pagesource`, `Old revisions`, `Recent changes`, and a `Search` input box).
