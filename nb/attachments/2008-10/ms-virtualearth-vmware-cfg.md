# Enabling 3D Hardware Acceleration in VMware Fusion Display Settings (`ms-virtualearth-vmware-cfg.png`)

## Overview
A composite screenshot of the VMware Fusion virtual machine `Display` settings dialog on Mac OS X, overlaid with two inset screenshots illustrating how to upgrade the virtual machine hardware and enable the `Accelerate 3D graphics` checkbox for Windows XP.

## Interface & Composite Elements
- **Left Sidebar (Hardware & Settings List)**:
  - `System Hardware`:
    - `Battery`
    - `Display` (highlighted in blue)
    - `Memory`
    - `Processors`
  - `Removable Devices`:
    - `CD/DVD`
    - `Hard Disk`
    - `Hard Disk 2`
    - `Network`
    - `Network 2`
    - `Serial Port`
    - `Sound`
  - `Shared Folders`:
    - `home`
  - `USB`:
    - `Apple Bluetooth ...`
  - Below the list are `+` and `-` buttons.
- **Main Display Settings Pane (Background)**:
  - Shows a cinema display icon on the left and a disabled (unchecked) checkbox `Accelerate 3D graphics` on the right.
  - Description text: `This option is experimental and enables DirectX 9.0 compatible graphics within Windows XP Service Pack 2 virtual machines. For a list of games and applications that are known to work, refer to the release notes.`
  - Below the description is a yellow warning triangle with an exclamation mark next to the message: `These settings cannot be changed unless the virtual hardware is upgraded. To make changes, shut down the virtual machine and upgrade the virtual hardware by selecting Virtual Machine > Upgrade Virtual Machine.`
  - Bottom dialog buttons: `Apply` (disabled/grayed out), `Cancel`, and `OK` (highlighted in blue).
- **Inset 1 (Bottom Center-Left)**:
  - A bordered screenshot of the Mac OS X `Virtual Machine` menu open, with `Upgrade Virtual Machine` highlighted in blue (among items `Settings ⌘E`, `Install VMware Tools`, `Take Snapshot ⌘T`, `Revert to Snapshot ⇧⌘T`, `Discard Snapshot`, `Send Ctrl-Alt-Del`, `Grab Input ⌘G`, `Power On`, and `✓ Powered Off`).
- **Inset 2 (Bottom Right)**:
  - A bordered screenshot showing the resulting Display pane after upgrading the virtual machine, where the `Accelerate 3D graphics` checkbox is now enabled and checked (`✓`).
