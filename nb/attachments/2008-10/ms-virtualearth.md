# Microsoft Virtual Earth 3D in Internet Explorer via VMware Fusion (`ms-virtualearth.png`)

## Overview
A screenshot of Microsoft Live Search Maps (`maps.live.com`) running the Microsoft Virtual Earth 3D browser plug-in inside Windows Internet Explorer on a Windows XP Professional virtual machine hosted in VMware Fusion on Mac OS X, displaying an oblique 3D aerial view of Boston Harbor and downtown Boston.
