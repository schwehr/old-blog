# CCOM Intranet Web Mapping Interface Using ka-Map and GeoMedia (`geomedia-ka-map-multibeam.png`)

## Overview
A screenshot of a Mac OS X web browser (`Web Mapping`) displaying the **CCOM Data Browser**, an intranet web-mapping prototype developed by Jim Case at the Center for Coastal and Ocean Mapping / Joint Hydrographic Center (CCOM/JHC) using Intergraph GeoMedia, ka-Map, and an Oracle database to visualize global multibeam sonar cruise tracks. Featured in a blog post on November 13, 2008, titled "ka-Map and GeoMedia."

## Webpage Header & Navigation
- **Browser Bar:** Standard Mac OS X Safari/Firefox window with back/forward buttons, address bar, and Google search box.
- **CCOM/JHC Banner:** Black header with the circular `CCOM / JHC` logo on the left, title text `Center for Coastal and Ocean Mapping / Joint Hydrographic Center / Intranet`, user status `Kurt Schwehr | Logout` in the top right, three blue navigation tabs (`Home`, `Documentation`, `Data`), and a 3D false-color bathymetric banner image across the width of the page.
- **Breadcrumbs & Notice:** `Data : Web Mapping`, followed by a `Text/HTML` section reading: *"This is a prototype and there are many data layers being added. Please bear with us as we populate this page. Click here for a full window version."*

## CCOM Data Browser (`ka-Map` IFrame)
Inside the `IFrame` section is the interactive map titled **CCOM DATA BROWSER** with a `Powered by ka-Map` badge in the top right:
- **Toolbar:** Dropdown selector set to `CCOM`, tool icons (info, pan hand, print, zoom out, zoom slider ladder, zoom in, full extent, zoom box), a `link to this view` link, and a search input box with a `Search` button.
- **World Map & Tracklines:** A global relief and bathymetry map heavily overlaid with dense black multibeam survey ship tracklines crisscrossing the Atlantic, Pacific, Indian, and Southern Oceans.
- **Overlay Panels:**
  - Bottom left: An empty gray `Search results` panel.
  - Bottom right: Coordinate readout (`x: 60.003373903995495`, `y: 0.634956337608418`), a `0` to `6000` scale bar, and a layer control list showing `Surveys` and `bathymetry` (checked) with color swatches for `ss2006`, `Atlantic`, `coastalrelief`, and `delbay`.
