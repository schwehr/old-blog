# Aldebaran II Coral Reef MIO S-57 Query Display (`mio-coral-reef.png`)

## Overview
A screenshot of the **Aldebaran II** electronic charting system displaying a Coral Reef Marine Information Object/Overlay (MIO) layered over aerial/satellite imagery near the Florida Keys (west of Key West, around Little Mullet Key, Big Mullet Key, Cottrell Key, Boca Grande Key, Woman Key, and Barracouta Keys), alongside an S-57 object query panel.
