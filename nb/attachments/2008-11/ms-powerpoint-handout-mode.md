# Microsoft PowerPoint Handout Printing Mode Dialog on Mac OS X (`ms-powerpoint-handout-mode.png`)

## Overview
A screenshot of the Mac OS X `Print` dialog box in Microsoft PowerPoint, showing how to select `Handouts (3 slides per page)` from the `Print What:` dropdown menu to generate printed note-taking handouts with ruled lines next to each slide.

## Dialog Controls & Layout
- **Top Selectors**:
  - `Printer:`: `hp LaserJet 4300 (0001E6A1B2DD)` with an upward disclosure triangle button next to it.
  - `Presets:`: `Standard`
  - Section dropdown: `Copies & Pages`
- **Left Quick Preview Pane**:
  - Shows a vertical page preview containing three slide thumbnails stacked on the left side of the page, each paired with a block of horizontal ruled note lines on the right.
  - Pagination controls below the preview read `1 of 12` between left and right circular arrow buttons.
  - Checked checkbox `Show Quick Preview` and a `Page Setup...` button below.
- **Right Print Options & Open Menu**:
  - `Copies:`: `1` (selected in blue focus ring) with an unchecked `Collated` checkbox.
  - `Slides:`: Radio button `All (34 slides)` selected; below it, an unselected radio button `From:` `1` `to:` `34`.
  - `Print What:`: An open pop-up menu displaying the available layout options:
    - `Slides`
    - `Handouts (2 slides per page)`
    - `✓ Handouts (3 slides per page)` (highlighted in blue)
    - `Handouts (4 slides per page)`
    - `Handouts (6 slides per page)`
    - `Handouts (9 slides per page)`
    - `Notes`
    - `Outline`
  - Partially obscured behind the open menu are `Slide Show`, `Output`, an unchecked `Print Hidden Slides` checkbox, and a checked `Frame Slides` checkbox.
- **Bottom Action Buttons**: Purple circular help button `?`, `PDF ▼` dropdown button, `Preview`, `Supplies...`, `Cancel`, and the default blue `Print` button.
