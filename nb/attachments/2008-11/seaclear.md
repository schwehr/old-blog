# SeaClear PC Chart Plotter Running in Windows XP on Mac OS X (`seaclear.png`)

## Overview

A screenshot of SeaClear, a free Windows PC chart plotter and GPS/AIS navigation application, running inside a virtualized Windows XP Professional window (via VMware Fusion) on Mac OS X.

## Interface & Map Details

- **VMware Fusion Toolbar (Top):**
  - Displays a Mac OS X window title `Windows XP Professional` and toolbar icons for `Suspend`, `Take Snapshot`, `Revert to Snapshot` (dimmed), and `Settings`.
- **SeaClear Application Window (`SeaClear [Z_USA - 1:25000000 @ 100%] - [RR=4]`):**
  - **Main Chart Area (Left):** Displays a coarse overview vector/raster map of the Pacific Northwest coast of North America (`Z_USA` at `1:25000000` scale). Landmasses (British Columbia, Washington, Oregon, Idaho, Montana, and California) are filled in solid olive green with black state/provincial borders and blue river lines (such as the Columbia, Snake, and Fraser rivers), while the Pacific Ocean, Puget Sound, and Strait of Georgia are filled in light cyan blue.
  - **Right Control Sidebar:**
    - **Menu Bar:** `File  Tools  >>`
    - **`DR` (Dead Reckoning / Own-Ship Status Panel, red background):**
      - `Lat`: `000°00.000 N`
      - `Long`: `000°00.000 E`
      - `Course`: `0` (with spin buttons)
      - `Speed`: `0` (with spin buttons)
    - **`Positions`:** Dropdown selector and `Find Position` button.
    - **`Routes`:** Links/buttons for `Open Route`, `Reverse Route`, and `Activate Route`.
    - **`Route Statistics`:** Fields for `Start:`, `End:`, and `Dist:`.
    - **`DoubleClick`:** Toggle buttons for `Measure` and `Center`.
    - **`Shading`:** Numbered buttons `1`, `2`, `3`, `4`.
