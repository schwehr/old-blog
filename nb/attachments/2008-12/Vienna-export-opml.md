# Exporting OPML Subscriptions in Vienna RSS Reader (`Vienna-export-opml.png`)

## Overview
A Mac OS X screenshot showing the **File** menu in the **Vienna** open-source RSS/Atom newsreader application, with the **Export Subscriptions...** command highlighted in blue as Kurt exports his feed list to an OPML file for import into Google Reader.
