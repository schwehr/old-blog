# MarView RSS Feed Configuration (`marview-rss.png`)

## Overview
A screenshot of the RSS feed management interface inside the MarView web portal, showing two side-by-side panels: `Available RSS Feeds` on the left and `Manage My Personal RSS Feeds` on the right.

## Interface & Controls
- **Available RSS Feeds (Left Panel)**:
  - Subheading in blue bold text: `No Default RSS Set`.
  - A scrollable list box with a blue Mac OS X Aqua scrollbar displaying ten pre-configured mainstream news, sports, and weather feeds:
    - `CNN.com - Travel`
    - `CNN.com - U.S.`
    - `CNN.com - World`
    - `MSNBC.com: Business`
    - `MSNBC.com: Health`
    - `MSNBC.com: Technology & Science`
    - `MSNBC.com: U.S. news` (highlighted in gray)
    - `MSNBC.com: World news`
    - `SI.com`
    - `The Weather Channel: National Weather Outlook`
  - Below the list box is a rounded pill button labeled `Set as My RSS Feed`.
- **Manage My Personal RSS Feeds (Right Panel)**:
  - `Your RSS Feeds` label next to an empty, narrow vertical list box with a scrollbar.
  - A rounded pill button below the empty list labeled `Remove RSS Feed`.
  - Two required text input fields marked with red asterisks (`*`):
    - `* Title`
    - `* RSS Feed URL:`
  - Below the input fields is a rounded pill button labeled `Add RSS Feed`.
