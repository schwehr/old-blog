# Nobeltec Navigation Software Showing Tidal Currents in Buzzards Bay and Nantucket Sound (`nobletec-currents.png`)

## Overview
A screenshot of Nobeltec marine navigation software (with the Tides & Currents module) running on Windows XP, displaying animated red tidal current vectors overlaid on NOAA nautical chart `13200_1` covering Buzzards Bay, the Cape Cod Canal, Martha's Vineyard, and Nantucket Sound.

- **Window Title Bar:**
  - Reads `"Nobeltec - [13200_1 1:400,000 (@41%<<49.489 nm>>) (FATHOMS) - GEORGES BANK AND NANTUCKET SHOALS]"`.
- **Menu Bar & Toolbars:**
  - Standard top menu items: `File`, `Edit`, `View`, `Tools`, `Radar`, `Sounder`, `Window`, `Help`.
  - Two rows of icon toolbars across the top featuring navigation, routing, boundary, man-overboard life ring, zoom in/out magnifying glasses, divider caliper, layer toggles, weather/cloud icon, gear settings, and tide/current vector controls.

- **Animation Dialog Overlay:**
  - In the top-left corner, a floating modal dialog titled `"Animating..."` displays the timestamp `"08:45"`, a green progress bar, and a `"Cancel"` button.
