# Interactive U3D Model Embedded in a PDF Viewed in Adobe Acrobat (`u3d-pdf-in-acrobat.png`)

## Overview
A screenshot of a sample PDF document (`Laurana.pdf`) open in **Adobe Acrobat**, demonstrating an interactive 3D mesh embedded using the **U3D** format exported from **MeshLab** and compiled with LaTeX (`pdflatex` and the `movie15` package).

## Document Header & Text
Centered at the top of the white page in black LaTeX Computer Modern serif font:
- Title:
  `Embedding interactive 3D object in a PDF using`
  `MeshLab and U3D`
- Subtitle / Attribution:
  `Visual Computing Group - ISTI - CNR`
- URL (in magenta/pink):
  `http://vcg.isti.cnr.it`

## 3D Toolbar & Model View
- **Acrobat 3D Toolbar**: A horizontal gray control bar sits below the header text, containing interactive 3D manipulation icons from left to right:
  - **Rotate** (selected/depressed inside a square box)
  - **Spin**
  - **Pan**
  - **Zoom**
  - **3D Measurement Tool** (caliper/ruler icon, hovered over with a small blue upward pointer triangle beneath it and a yellow tooltip reading `3D Measurement Tool`)
  - **Default View** (house icon)
  - **Views** dropdown menu
  - **Toggle Model Tree** icon
  - **Play/Pause Animation** icon (grayed out)
  - **Projection / Rendering Mode / Lighting / Background Color** icons on the far right (partially visible).
- **3D Model Viewport**: Below the toolbar on a white background is a smooth-shaded gray 3D surface mesh of the Renaissance sculpture bust of *Francesco Laurana*, tilted dynamically backward and viewed from below the chin and left cheek to illustrate interactive 3D rotation inside the PDF reader.
