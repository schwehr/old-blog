# LDEO Marine Geoscience Data System - Virtual Ocean Home Page (`virtual-ocean.png`)

## Overview
A screenshot of the **Virtual Ocean** home page (`http://www.virtualocean.org/`) developed by the Marine Geoscience Data System (MGDS) at the Lamont-Doherty Earth Observatory (LDEO) of Columbia University, viewed in Mozilla Firefox on Mac OS X in December 2008.

## Browser & Banner Layout
- **Browser Window**: Mac OS X Firefox window titled `Virtual Ocean`, displaying the URL `http://www.virtualocean.org/` in the address bar and a Google search box on the right.
- **Top Header Bar**: A blue gradient bar displaying a circular globe/grid logo and `MARINE GEOSCIENCE DATA SYSTEM` on the left, and a `Search` input box containing placeholder text `not yet enabled` with a `Go` button on the right.
- **Hero Graphic**: A wide 3D perspective rendering of exaggerated ocean-floor bathymetry and continental margins tinted in pearlescent gray, tan, and soft blue, overlaid with the text `Explore our planet with` above large metallic blue-gray italic letters reading `Virtual Ocean` with a water reflection effect beneath them.

## Main Content & Footer
- **Heading**: `Virtual Ocean` in dark blue serif text above a horizontal rule.
- **Left Globe Graphic**: A circular 3D shaded-relief globe centered on the Atlantic Ocean, illustrating detailed mid-ocean ridge and abyssal plain bathymetry alongside continental topography.
- **Description Text** (right of the globe, in blue text with external link icons):
  - Paragraph 1: `Virtual Ocean integrates the GeoMapApp tool suite with the NASA World Wind 3-D earth browser to create a powerful new platform for interdisciplinary research and education.`
  - Paragraph 2: `The Global Multi-Resolution Topography (GMRT) synthesis developed by the Marine Geoscience Data System (MGDS) is the primary base map for Virtual Ocean, providing access to a comprehensive multi-resolution compilation of satellite altimetry and multibeam bathymetry data. Several MGDS data sets are accessible in Virtual Ocean through live OGC-standard Web services. Options are also provided for users to import their own data sets.`
  - Action links:
    - `Visit the Help Page for more information on how to use Virtual Ocean.`
    - `Click here to launch Virtual Ocean. After initialization, select the Virtual Ocean base map projection.` (with `here` enclosed in a dotted focus rectangle).
  - System Note (italicized):
    `Note: For best performance, a 3D video card with up-to-date drivers is necessary and the display should be set to 32-bit true color. Virtual Ocean has been tested with ATI, NVIDIA, and Intel video cards using Windows (XP/Vista), Mac OS X (10.4/10.5), and Fedora Core (6/8) operating systems.`
- **Footer Box**: Light blue rounded bar reading:
  `Hosted by Marine Geoscience Data System at Lamont-Doherty Earth Observatory of Columbia University`
