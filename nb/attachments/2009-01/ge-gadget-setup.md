# Google Earth Embedded KML Viewer Gadget Setup Controls (`ge-gadget-setup.png`)

## Overview
A screenshot of the configuration panel on Google's Gadget creator page (`gmodules.com`) for customizing and embedding the "Embedded KML Viewer" Google Earth Browser Plugin gadget.

## Preview Footer (Top)
- The top edge shows the bottom portion of the live gadget preview framed in a reddish-pink border, with the attribution text (`Data U.S. Navy`, `© 2008 Tele Atlas`, `Image © 2009 DigitalGlobe`, `© 2008 Europa Technologies`) and the `Google` / `Terms of Use` watermark on the right.
- Directly below the preview frame are the `+ Google` button on the left, `Gadgets powered by Google` on the right, and centered grey helper text: `Tip: Drag the bottom right corner of the preview above to resize the gadget.`

## Configuration Panel (Middle)
A light grey rectangular box is divided into two columns:

### Display settings (Left Column)
- **Title**: Text input box containing `Embedded KML Viewer`.
- **Width**: Text input box set to `600` followed by `px`.
- **Height**: Text input box set to `400` followed by `px`.
- **Border**: A grid of 12 radio buttons, each paired with a miniature corner preview showing different border styles and colors (no border, thick light blue bevel, black double-line, light blue double-line, grey double-line, green double-line, reddish-pink double-line [selected with a blue radio dot], dark blue double-line, medium blue double-line, purple double-line, yellow double-line, and orange double-line).

### Gadget settings (Right Column)
- **KML or My Maps URL**: Text input box showing the end of a URL: `achments/2009-01/highland-light.kmz`.
- **View mode**: A Mac OS X dropdown menu set to `3D (Google Earth – requires plugin)`.
- **3D - Fall back to 2D on error**: Unchecked checkbox.
- **3D - Fly in from space**: Checked checkbox (blue checkmark).
- **3D - Show buildings**: Unchecked checkbox.

## Action Buttons (Bottom)
Centered below the grey configuration panel are two rounded pill-shaped buttons: `Preview Changes` and `Get the Code`.
