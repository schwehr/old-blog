# Kitchen Table AIS Hardware and Laptop Setup (`kitch-table-ais.jpg`)

## Overview
A color photograph showing a tabletop Automatic Identification System (AIS) testing and demonstration setup on a wooden kitchen table. Two laptops—an Apple MacBook Pro and a Lenovo/IBM ThinkPad—are connected via various serial, USB, and coaxial cables to an AIS receiver (SR162G) and related communication hardware, alongside technical manuals and a handwritten notebook.
