# InstallShield Feature Transfer Error Dialog over Remote Desktop (`install-shield-rdesktop.png`)

## Overview

A screenshot of a Windows XP `Feature transfer error` modal dialog box generated by an InstallShield installer when attempting to install commercial software over an `rdesktop` remote desktop session.

## Dialog Box & Interface Details

- **Background Window (InstallShield)**:
  - A beige Windows installer background window is partially visible behind the error popup.
  - A small green progress bar segment and the letter `N` appear just to the left of the error dialog.
  - Near the bottom, a horizontal etched separator line has the word `InstallShield` embedded on the left, and a standard `Cancel` button sits in the bottom right corner.
- **Foreground Modal Dialog (`Feature transfer error`)**:
  - **Window Frame**: Classic Windows XP Luna blue title bar with white bold text reading `Feature transfer error` on the left and a red close button (`X`) on the right.
  - **Error Details**: Displayed in black sans-serif text arranged in a two-column key-value layout against a light beige dialog background:
    - `Feature:` `NTX Data`
    - `Component:` `NTX Symbols`
    - `File:` `<szCommonDir>\`
    - `Error:` `The filename, directory name, or volume label syntax is incorrect.`
  - **Action Button**: A centered rectangular button at the bottom of the dialog box with a blue default-focus border labeled `OK`.
