# Linksys WRT54G Router Security and Firewall Web Interface (`linksys-wrt54g.png`)

## Overview

A cropped screenshot of the Linksys WRT54G wireless router web administration interface (firmware v2.02.7) showing the `Security` -> `Firewall` configuration settings required to allow AOL Instant Messenger (AIM) traffic through the router.

## Navigation Tabs & Bars

- **Primary Navigation Bar**: A black horizontal bar across the top with white bold text labels for the main configuration sections:
  - `Setup`
  - `Wireless`
  - `Security` — highlighted as the active tab with a medium-purple/slate-blue background block extending upward.
  - `Access Restrictions`
  - `Applications & Gaming`
- **Secondary Sub-navigation Bar**: Directly beneath the main tabs is a matching purple/slate-blue horizontal strip containing two sub-items separated by a vertical pipe (`|`):
  - `Firewall` (white text, active sub-tab)
  - `VPN` (light grey/lavender text, inactive)

## Firewall Settings Controls

On the white content area below a grey-shaded horizontal border:
- **Firewall Protection**:
  - Label on the left: `Firewall Protection:`
  - Two radio buttons to the right: `Enable` (selected with a blue-tinted circular radio button containing a black center dot) and `Disable` (unselected grey circular radio button), both with bold black labels.
- **Block Anonymous Internet Requests**:
  - Separated by a thin light-purple horizontal line below `Firewall Protection`.
  - A square blue-tinted checkbox on the left is **checked** with a black checkmark, followed by the label `Block Anonymous Internet Requests`.
