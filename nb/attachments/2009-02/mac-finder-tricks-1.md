# Customizing Mac OS X Finder: Show Path Bar and Column Width Handle (`mac-finder-tricks-1.png`)

## Overview

An annotated screenshot of a Mac OS X Leopard Finder window in column view with the `View` menu pulled down, highlighting the `Show Path Bar` menu command, the resulting path bar at the bottom of the window, and the column-resize handle.

## Menu Bar & View Menu Dropdown

- **Top Menu Bar**: Shows the Apple logo, `Finder` (in bold), `File`, `Edit`, `View` (highlighted in blue), `Go`, `Window`, and `Help`.
- **Open `View` Menu**:
  - `as Icons` (`⌘1`)
  - `as List` (`⌘2`)
  - `✓ as Columns` (`⌘3`, checked)
  - `as Cover Flow` (`⌘4`)
  - `Clean Up` (greyed out)
  - `Arrange By` (greyed out, with submenu arrow)
  - `Show Path Bar` — **highlighted in blue and circled with a hand-drawn orange oval**.
  - `Hide Status Bar` (greyed out)
  - `Hide Toolbar` (`⌥⌘T`)
  - `Customize Toolbar...`
  - `Show View Options` (`⌘J`)
