# Customizing Mac OS X Finder: Customize Toolbar Sheet (`mac-finder-tricks-2.png`)

## Overview

A screenshot of a Mac OS X Leopard Finder window showing the `View` -> `Customize Toolbar...` menu item selected and the customize toolbar palette sheet open over the Finder window.

## Menu Bar & View Menu Dropdown

- **Top Menu Bar**: Shows the Apple logo, `Finder`, `File`, `Edit`, `View` (active in blue), `Go`, `Window`, and `Help`.
- **Open `View` Menu**:
  - `as Icons` (`⌘1`), `as List` (`⌘2`), `✓ as Columns` (`⌘3`), `as Cover Flow` (`⌘4`)
  - `Clean Up` and `Arrange By` (disabled/greyed out)
  - `Hide Path Bar`, `Hide Status Bar` (disabled)
  - `Hide Toolbar` (`⌥⌘T`)
  - `Customize Toolbar...` — **highlighted in blue**.
  - `Show View Options` (`⌘J`)

## Customize Toolbar Sheet & Controls

- **Modified Finder Toolbar (Top of Window)**: Along the top of the Finder window (`Adobe Device Central CS3`), custom icons have already been added between the View switcher and the Search box: a `Path` dropdown button (on the left near Back/Forward), a blue circular `Get Info` (`i`) button, and a blue `New Folder` button with a `+` badge.
- **Draggable Item Palette**: Partially obscured on the left by the open `View` menu, the sheet displays available toolbar items arranged in rows with icons and labels:
  - **Row 1**: `Back` (back/forward arrows), `View` (4-mode view selector), `Action` (gear dropdown).
  - **Row 2**: `Eject`, `Customize` (crossed screwdriver and wrench), `Separator` (vertical dotted line).
  - **Row 3**: `Space`, `Flexible Space`, `New Folder` (blue folder with `+`), `Delete` (red circle with slash).
  - **Row 4**: `Connect` (blue globe with `@`), `Get Info` (blue circle with `i`), `iDisk` (purple hard drive icon), `Search` (rounded search field).
  - **Row 5**: `Quick Look` (eye icon button).
- **Default Toolbar Set**: Below the prompt `... or drag the default set into the toolbar.`, a boxed strip displays the standard default toolbar layout (`Back`, `View`, `Quick Look`, `Action`, and `Search`).
- **Footer Controls**: At the bottom of the sheet:
  - `Show` dropdown menu set to `Icon Only`
  - Unchecked checkbox labeled `Use Small Size`
  - Rounded `Done` button in the bottom right corner.
