# MacTubes YouTube Client and MP4 Downloader on Mac OS X (`mactubes.png`)

## Overview

A screenshot of the `MacTubes` desktop application on Mac OS X showing its main browser window in the background and an active `Downloads` window in the foreground downloading an `MPEG4` video of Kurt Schwehr's AGU Scientists Google Tech Talk.

## Main `MacTubes` Window (Background)

- **Title Bar & Toolbar**:
  - Inactive grey Mac OS X title bar centered with the title `MacTubes`.
  - Left side of the toolbar shows `Results 1 - 0 of 0`.
  - Right side of the toolbar features a list/grid view toggle button, two window/playlist toggle buttons, and a rounded search input box with a magnifying glass icon.
- **Left Pane**: Divided vertically into an upper light-blue/white playlist/category list area and a solid black video preview box at the bottom, with `+` and `-` buttons beneath it.
- **Main Results Table**: An empty alternating blue-and-white striped table with column headers: `No`, `Image`, `Description`, `Author`, `Time`, `Views`, and `Rating`.
- **Bottom Transport Bar**: Contains previous/play/next media control buttons (`<-`, play triangle, `->`), a horizontal slider, and a rounded `Filter` search box on the bottom right.

## `Downloads` Window (Foreground)

- **Window Frame**: Active Mac OS X window on the right side with red, yellow, and green traffic-light window buttons and the title `Downloads`.
- **Active Download Item**:
  - In the first row, a QuickTime document icon labeled `MPEG4` appears on the left.
  - **Title**: `AGU Scientists Tech Talks - ...`
  - **Progress Status**: Grey text below the title reads `53.3 MB / 80.0 MB - 66.7%`.
  - **Action Icons**: On the right side of the row are two small circular grey buttons: an `x` (cancel/stop) icon and a magnifying glass (reveal in Finder) icon.
- **Footer**: At the bottom left of the `Downloads` window is a rounded pill button labeled `Clear`.
