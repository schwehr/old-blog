# Selecting the 3D Tool in Adobe Acrobat Pro (`acrobat-pro-3D-tool.png`)

## Overview
A cropped macOS screenshot showing the top menu bar and cascading `Tools` menu in **Adobe Acrobat Pro**, demonstrating how to access the **3D Tool** to embed an interactive U3D 3D model into a PDF document.

## Interface & Menu Details
- **Top Menu Bar**: Shows the macOS menu bar with application menus `Forms`, `Tools` (highlighted in blue), `Advanced`, `Window`, and `Help`. To the right are macOS menu bar status icons: a monkey/gorilla icon, a black paw print icon (Growl), an AirPort Wi-Fi signal icon, and a network activity monitor graph showing green `Tx: 8B/s` and red `Rx: 44B/s`.
- **Application Toolbar (Background)**: Partially visible beneath the menus, showing a padlock icon, a magnifying glass zoom tool, and a `Review & Comment` dropdown button with a yellow speech-bubble icon.
- **`Tools` Dropdown Menu**:
  - `Comment & Markup` (with right submenu arrow)
  - `Select & Zoom` (with right submenu arrow)
  - `Advanced Editing` (highlighted in blue, with right submenu arrow)
  - `Forms` (with right submenu arrow)
  - `Measuring` (with right submenu arrow)
  - `Typewriter` (with right submenu arrow)
  - `Object Data` (with right submenu arrow)
  - Horizontal divider line
  - `Customize Toolbars...`
- **`Advanced Editing` Submenu**:
  - `Select Object Tool` (black cursor arrow icon)
  - `Article Tool` (red curved arrow path icon)
  - `Crop Tool` (blue crop marks icon)
  - `Link Tool` (chain link icon)
  - `3D Tool` (highlighted in blue with a white checkmark `✓` and a 3D geometric sphere/cone/cube icon)
  - `Movie Tool` (filmstrip icon)
  - `Sound Tool` (speaker icon)
  - `TouchUp Text Tool` (`T` inside a box icon)
  - `TouchUp Reading Order Tool` (numbered box icon)
  - `TouchUp Object Tool` (pencil over box icon)
  - Horizontal divider line
  - `Show Advanced Editing Toolbar`
