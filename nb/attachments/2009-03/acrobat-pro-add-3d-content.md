# Adobe Acrobat Pro Add 3D Content Dialog (`acrobat-pro-add-3d-content.png`)

## Overview
A screenshot of the **Add 3D Content** modal dialog box in **Adobe Acrobat Pro** on macOS, which appears after dragging a rectangular region on a PDF page using the 3D Tool to insert a 3D model (such as a `.u3d` file).

## Dialog Sections & Controls
- **Title Bar**: Gray macOS window header titled `Add 3D Content`.
- **Content Settings**:
  - `3D Model:`: Text field displaying `<No file selected>` alongside a blue-outlined `Choose...` button (focused).
  - `Retain Views, Comments, and Scripts`: Checked checkbox (disabled/grayed out until a file is chosen).
  - `Default Script:`: Text field displaying `<No file selected>` with `Choose...` and `Clear` buttons to the right.
- **Navigation and Display**:
  - `Default Background Color:`: A square color-picker swatch set to medium gray.
  - `Default Lighting:`: Dropdown menu set to `Lights from File`.
  - `Default Rendering Style:`: Dropdown menu set to `Solid`.
  - `Default Animation Style:`: Dropdown menu set to `None`.
  - `Add Default Views:`: Unchecked checkbox next to a disabled dropdown menu reading `No Views`.
  - `Open model tree by default`: Unchecked checkbox.
- **Poster Image**:
  - Three radio buttons:
    - `Keep current poster` (disabled/grayed out)
    - `Retrieve poster from default view` (selected with a blue radio button dot)
    - `Create poster from file` (unselected)
  - `Poster File:`: Disabled label and text field showing `<No file selected>` with a disabled `Choose...` button.
- **Bottom Action Buttons**:
  - `Help` button at the bottom left.
  - `Cancel` button and a disabled `OK` button at the bottom right.
