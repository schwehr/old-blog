# Exporting a U3D File in MeshLab on Windows XP (`meshlab-windows-u3d.png`)

## Overview
A screenshot of **MeshLab v1.1.1** running inside a Windows XP virtual machine, showing the `Save File` dialog configured to export a 3D bathymetry surface mesh (`g3.obj`, converted from a GMT grid) into the **U3D File Format (`*.u3d`)** for embedding into a PDF document via LaTeX `movie15`.

## Application Window & 3D Viewport
- **Title & Menu Bars**:
  - Window title bar: `MeshLab v1.1.1 - [g3.obj]`.
  - Menu bar: `File`, `Edit`, `Filters`, `Render`, `View`, `Windows`, `Tools`, `Help`.
  - Toolbar: Standard MeshLab icon bar showing file operations, rendering modes (Smooth shading and Lighting active), trackball, annotation (`A`), measurement tape, and mesh tools.
- **3D Viewport & Status Area**:
  - On the right side of the dark viewport, a gray 3D shaded relief surface mesh (`g3.obj`) is partially visible inside a white spherical trackball guide.
  - Along the bottom of the MeshLab window, a maroon/red status panel displays two lines of white warning text:
    - `There are gl errors`
    - `There are gl errors`
- **Windows XP Taskbar (Bottom)**: Shows the green `start` button, a Mozilla Firefox tab (`Index of /~schwehr/...`), and the active `MeshLab v1.1.1 - [g3...` window button.

A Windows XP `Save File` modal dialog occupies the left and center of the screen:
- **Save in**: `Desktop` (with navigation icons along the left sidebar for `My Recent Documents`, `Desktop` [selected], `My Documents`, `My Computer`, and `My Network Places`).
- **File List**:
