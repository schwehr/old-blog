# Windows Start Menu for Meinberg NTP (`ntp-start-menu.png`)

## Overview
A cropped screenshot of the Windows XP Start Menu cascading submenus for **Meinberg**, showing shortcuts for **Network Time Protocol**, **NTP Time Server Monitor**, and **Service Control** actions.

## Menu Hierarchy & Items
The screenshot displays four cascading menu levels from left to right (with the fourth level overlapping the second column):
1. **First Column**:
   - `Meinberg` (folder icon, highlighted in blue)
2. **Second Column (`Meinberg` Submenu)**:
   - `Network Time Protocol` (folder icon, highlighted in blue)
   - `NTP Time Server Monitor` (Meinberg `M` application icon on a pale yellow background)
3. **Third Column (`Network Time Protocol` Submenu)**:
   - `Documentation` (folder icon with submenu arrow)
   - `Installation` (folder icon with submenu arrow)
   - `Service Control` (folder icon, highlighted in blue)
   - `Weblinks` (folder icon with submenu arrow)
   - `Edit NTP Configuration` (notepad/editor icon)
   - `Quick NTP Status` (status window icon)
4. **Overlaid Submenu (`Service Control` Submenu)**:
   - `Restart NTP Service` (green circular refresh arrows icon)
   - `Start NTP Service` (green play button icon)
   - `Stop NTP Service` (red power/stop button icon)
