# USCG PSIX Vessel Details for M/V Cosco Busan (`uscg-psix-cosco-busan-512403.png`)

## Overview
A screenshot from the U.S. Coast Guard Port State Information eXchange (**PSIX**) web database (`http://cgmix.uscg.mil/PSIX/PSIXDetails.aspx?VesselID=512403`) displaying vessel particulars, tonnage, and safety certifications for the container ship **COSCO BUSAN**, published in a March 11, 2009 blog post titled *"Cosco Busan USCG Marine Causualty Report"*. As noted in the blog post, the table shows that several of the vessel's SOLAS and ISM certificates had been issued on October 25, 2007—just days before its November 7, 2007 allision with the San Francisco–Oakland Bay Bridge.
