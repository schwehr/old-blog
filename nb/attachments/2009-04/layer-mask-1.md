# Photoshop Layers Panel with Add Layer Mask and Channels Highlighted (`layer-mask-1.png`)

## Overview
An annotated screenshot of the Adobe Photoshop `Layers` palette on Mac OS X, demonstrating how to add a layer mask to a right whale tail icon (`Layer 2`) and switch to the `Channels` tab.

## Interface & Annotations
- **Tabs (Top):**
  - `Layers` (currently active tab, with a small `x` close button)
  - `Channels` (**circled in bright red** to indicate the next step in the workflow)
  - `Paths`
- **Blending & Opacity Controls:**
  - Blend mode dropdown set to `Normal`
  - `Opacity:` set to `100%`
  - `Lock:` row with four lock icons (transparent pixels, image pixels, position, all) and `Fill:` set to `100%`
- **Layer List:**
  - Single visible layer highlighted in light blue named `Layer 2`, with an eye visibility icon on the left.
  - **Layer Thumbnail (left):** Black silhouette of a right whale's flukes/tail with dark water ripples against a white background, surrounded by a double-line active border.
  - **Link Icon (middle):** Chain-link icon linking the layer and its mask.
  - **Layer Mask Thumbnail (right):** Inverted black-and-white mask showing a white whale tail silhouette against a black background.
- **Bottom Action Bar:**
  - Seven icons from left to right: Link layers (greyed out), Add a layer style (`fx`), **Add layer mask** (rectangle with a circle inside, **circled in bright red**), Create new fill or adjustment layer, Create a new group (folder), Create a new layer, and Delete layer (trash can).
