# Microsoft Access Security Warning Dialog (`ms-access-unhappy.png`)

## Overview
A screenshot of Microsoft Access on Windows XP displaying a modal error dialog when attempting to open a downloaded or externally sourced `.mdb` Jet database file that has been blocked by Windows attachment security.

## Interface & Controls
- **Application Window**: The background shows the top-left portion of the main **Microsoft Access** window with its purple key-and-database application icon in the blue title bar, standard menu bar (`File`, `Edit`, `View`, `Insert`, `Tools`, `Window`, `Help`), and toolbar (with `New`, `Open`, `Save`, `File Search`, and `Help` active, and most other icons disabled/grayed out over a dark gray workspace).
- **Modal Dialog Box**: Centered in the foreground is a Windows XP dialog box titled **Microsoft Access** with a red close (`X`) button in the top-right corner, a blue-and-white circular information (`i`) speech-bubble icon on the left, and a single centered **OK** button at the bottom.

## Visible Text & Error Message
Inside the dialog box, the message reads:
- **Heading (bold)**: `Microsoft Access cannot open this file.`
- **Body**:
  > This file is located outside your intranet or on an untrusted site. Microsoft Access will not open the file due to potential security problems.
  >
  > To open the file, copy it to your machine or an accessible network location.
