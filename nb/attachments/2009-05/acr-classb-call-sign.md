# ACR Link2AIS Call Sign Error Dialog (`acr-classb-call-sign.png`)

## Overview
A screenshot of a Windows error dialog box from the **ACR Link2AIS Class-B** configuration software, triggered when attempting to save static vessel data with an empty or single-character call sign field.

## Interface & Controls
- **Window Title Bar**: Blue Windows XP-style title bar reading **`Call Sign error`** in white bold text on the left, with a red close (`X`) button on the right.
- **Dialog Body**: Light beige/gray dialog area containing:
  - **Warning Icon (Left)**: A yellow triangle with a black exclamation point (`!`).
  - **Error Message (Center/Right)**: `The ship's call sign must have 2 characters or more!`
  - **Action Button (Bottom Center)**: A standard rectangular **`OK`** button with a black focus border.
