# ACR Link2AIS Class-B Device Status Window (`acr-classb-device-status.png`)

## Overview
A screenshot of the **Device Status** window in the **ACR Link2AIS Class-B** software, displaying transponder operational indicators and firmware version numbers for an **ACR Nauticast AIS-300** Class B transceiver prior to acquiring a GPS lock.

## Interface & Controls
- **Window Title Bar**: Blue Windows XP title bar labeled **`Device Status`** with minimize, maximize/restore, and red close (`X`) buttons on the right.
- **Transponder status section**:
  - **`MMSI valid:`** — Green checkmark (`✓`), indicating a valid 9-digit MMSI has been programmed.
  - **`GPS position fix:`** — Red cross (`✗`), indicating the internal GPS receiver does not currently have a satellite position fix.
  - **`Pos. Report Tx'd`** — Red cross (`✗`), indicating no Class B position report has been transmitted.
  - **`Pos. Report Rx'd`** — Red cross (`✗`), indicating no AIS position reports have been received from other vessels.
- **Transponder versions section**:
  - **`Software version:`** `10.0.7.0`
  - **`FPGA version:`** `05`
