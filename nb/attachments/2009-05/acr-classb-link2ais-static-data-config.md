# ACR Link2AIS Class-B AIS Operation Menu (`acr-classb-link2ais-static-data-config.png`)

## Overview
A screenshot of the **Link2AIS Class-B** Windows application showing the **AIS Operation** drop-down menu open with **Static Data Config** highlighted, overlaid on top of a radar-style display window.

- **AIS Operation Drop-Down Menu**:
  - `Radar View`
  - `Ship List`
  - **`Static Data Config`** (highlighted with a light blue selection box)
  - `Own Ship Data`
  - `Device Status`
  - `Safety Message`
  - `Silent`
  - `Switch Functionality` (with a right-pointing submenu arrow `▸`)
- **Child Radar Window (Background)**:

  - Displays concentric range rings on a beige background, a central own-ship circle labeled `000000000` (unconfigured default MMSI), and a scale bar in the lower-left corner labeled **`Ring: 1 NM`**.
