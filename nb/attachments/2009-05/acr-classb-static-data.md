# ACR Link2AIS Static Data Configuration Dialog (`acr-classb-static-data.png`)

## Overview
A screenshot of the **Static Data Configuration** dialog window in the **ACR Link2AIS Class-B** software, showing the vessel identification and dimension settings being programmed for the University of New Hampshire research vessel **R/V Cocheco**.

## Interface & Controls
- **Window Title Bar**: Blue Windows XP title bar labeled **`Static Data Configuration`** with minimize, maximize, and close (`X`) buttons.
- **Left Column (Identification & Type Fields)**:
  - **`Ship's MMSI`**: `369970120`
  - **`Verify MMSI`**: `369970120`
  - **`Ship's Name`**: `R/V COCHECO`
  - **`Call Sign`**: `NONE|` (with the text cursor positioned at the end)
  - **`Vessel Type`** (drop-down menu): `56 = Spare - for assignments to local vessels`
- **Right Column (GPS Antenna Offset Diagram & Dimension Fields)**:
  - A black-outlined plan-view schematic of a pointed ship hull containing a black dot labeled **`GPS antenna`** and dimension arrows for **A** (bow to antenna), **B** (antenna to stern), **C** (port side to antenna), and **D** (antenna to starboard side):
    - **`A`**: `7`
    - **`B`**: `4`
    - **`C`**: `3`
    - **`D`**: `1`
  - Caption below the diagram reads: **`all dimensions in meters`** (indicating an 11 m long by 4 m wide vessel).
- **Bottom Action Button**: **`Save to Nauticast-B`** button centered at the bottom.
