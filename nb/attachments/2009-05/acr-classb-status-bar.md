# ACR Link2AIS Status Bar Warning Indicator (`acr-classb-status-bar.png`)

## Overview
A close-up screenshot of the bottom status bar of the **ACR Link2AIS Class-B** application window, showing a yellow warning indicator light and its hover tooltip reading **`Tx timeout`**.

## Interface & Controls
- **Status Bar Elements (Left to Right)**:
  - **Connection Status**: A bright green circular LED indicator next to the label **`Connected`**.
  - **Four Circular LED Status Indicators**:
    1. Gray (inactive) LED
    2. Gray (inactive) LED
    3. **Yellow (active warning) LED**
    4. Gray (inactive) LED
  - **MMSI Field (Right)**: Partially visible text reading **`MMSI: 3...`**.
- **Tooltip & Desktop Background**:
  - Below the status bar, against the blue Windows desktop background (with part of a desktop icon label `ntp-... msacc...` visible), a pale yellow tooltip box points to the yellow LED and reads **`Tx timeout`**.
