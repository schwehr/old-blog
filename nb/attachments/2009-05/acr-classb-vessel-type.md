# ACR Link2AIS Vessel Type Drop-Down Menu (`acr-classb-vessel-type.png`)

## Overview
A close-up screenshot of the **Vessel Type** combo-box drop-down list inside the **Static Data Configuration** dialog of the **ACR Link2AIS Class-B** software, showing eight ITU-R M.1371 ship and cargo type codes (50 through 57).

## Interface & Controls
- **Label**: **`Vessel Type`** at the top left.
- **Combo-Box Input Field**: Blank white text box with a blinking vertical cursor (`|`) on the left and a downward-pointing arrow button (`▾`) on the right.
- **Expanded Drop-Down List** (with a vertical scrollbar on the right):
  - **`50 = Pilot vessel`** (highlighted in blue with white text)
  - `51 = Search and rescue vessels`
  - `52 = Tugs`
  - `53 = Port tenders`
  - `54 = Vessels with anti-pollution facilities or equipment`
  - `55 = Law enforcement vessels`
  - `56 = Spare - for assignments to local vessels`
  - `57 = Spare - for assignments to local vessels`
