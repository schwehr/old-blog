# Adium Accounts Preferences Dialog Showing AIM Login Server and Port Settings (`fixing-adium-aim.png`)

## Overview
A Mac OS X screenshot taken on May 17, 2009 of the **Adium** instant messaging client's `Accounts` preferences window, illustrating the `Options` tab where the AOL Instant Messenger (AIM) login port (`5190`) is highlighted so it can be changed to `80` to restore connectivity.

## Interface & Controls
- **Window Title Bar & Top Toolbar**:
  - Standard Mac OS X window controls (gray, yellow, and green buttons) at top left and title `Accounts` centered at the top.
  - Icon toolbar across the top with nine preference panes:
    - `Accounts` (selected, showing two silhouette Adium duck icons)
    - `General`
    - `Personal`
    - `Appearance`
    - `Messages`
    - `Status`
    - `Events`
    - `File Transfer`
    - `Advanced`
- **Account Configuration Sheet**:
  - A modal sheet drops down over the blurred Accounts list in the background.
  - Segmented tab bar across the top of the sheet: `Account` | `Personal` | `Options` (selected in blue) | `Privacy` | `Proxy`.
  - **Form Fields**:
    - `Login Server:` text input box containing `login.oscar.aol.com`.
    - `Port:` text input box to the right with a blue focus ring and the value `5190` highlighted in blue selection.
    - `Email:` unchecked checkbox labeled `Check for new mail`.
