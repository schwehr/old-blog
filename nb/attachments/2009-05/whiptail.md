# Linux Whiptail Console Yes/No Dialog (`whiptail.png`)

## Overview

A screenshot of a terminal-based user interface dialog box generated by the Linux `whiptail` command-line utility (`whiptail --yesno "Is the sky blue?" 10 30`), demonstrating a curses/newt-based yes/no prompt window.

## Interface & Visual Details

- **Background**: A solid bright blue (`#0038f8`) terminal screen background with a black drop shadow offset to the right and bottom of the central dialog box.
- **Dialog Box**: A centered light gray (`#e0e0e0`) rectangular window measuring 30 columns wide by 10 rows high.
- **Character Encoding / Border Artifacts**: Because the terminal's character encoding (such as UTF-8 box-drawing characters interpreted in Latin-1/ISO-8859-1) did not match the line-drawing character set expected by `whiptail`, the top, bottom, left, and right border lines are rendered using the lowercase letter `â` (`a` with circumflex) repeated along the entire perimeter.
- **Prompt & Buttons**:
  - Near the upper-left interior of the box, black monospace text asks: `Is the sky blue?`
  - Near the bottom of the dialog are two selectable text buttons:
    - `<Yes>`: Highlighted as the active selection with white text on a solid red (`#b82418`) rectangular background on the left.
    - `<No>`: Unselected black text on the light gray dialog background on the right.
