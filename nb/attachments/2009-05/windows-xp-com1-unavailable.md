# Windows XP HyperTerminal Serial Port Busy Error (`windows-xp-com1-unavailable.png`)

## Overview

A screenshot of a Windows XP **HyperTerminal** modal alert dialog box indicating that the selected serial communications port (`COM1`) is unavailable because another process or driver is holding it open.

## Interface & Dialog Details

- **Window Style**: A classic Windows XP Luna Blue theme dialog box centered over a blank white HyperTerminal application workspace.
- **Title Bar**: Blue gradient title bar with white bold text `HyperTerminal` on the left and a red square close (`X`) button on the right.
- **Dialog Content**:
  - On the left is a round light-blue speech-bubble information icon containing a bold blue lowercase `i`.
  - To the right of the icon, black sans-serif message text reads:
    ```text
    Another program is using the selected Telephony device.
    Try again after the other program completes.
    ```
  - Centered at the bottom of the dialog is a rectangular `OK` button with a blue highlight border.
- **Status Bar (Bottom)**: Along the bottom edge of the image is the grayed-out status bar of the underlying HyperTerminal window, displaying compartments labeled:
  - `SCROLL` | `CAPS` | `NUM` | `Capture` | `Print echo`
