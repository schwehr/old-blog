# Emacs Displaying a Webcam Image from USCGC Healy (`emacs-showing-an-image.png`)

## Overview

A screenshot of an X11 GNU Emacs window running on macOS (`emacs@eel.ccom.nh`), displaying a JPEG image (`20090524-1401.jpeg`) captured by the "Healy Aloft Conn" shipboard camera on the icebreaker USCGC *Healy* while docked in Seattle, Washington.

## Window & Interface Details

- **Title Bar:** Standard macOS X11 window frame with red, yellow, and green window buttons on the left and the title `emacs@eel.ccom.nh` centered next to an X11 icon.
- **Toolbar:** Standard Emacs graphical toolbar featuring 13 icons: New File, Open File, Read Directory (Dired), Close Buffer (`X`), Save (grayed out), Save As, Undo (grayed out), Cut, Copy, Paste, Search, Print, Customize (wrench/screwdriver), and Help (life preserver ring).
- **Status / Mode Line (Bottom):** Displays `:---  20090524-1401.jpeg   All L1     (Image)----5:08PM 0.30----------------`.
