# Microsoft Access File Menu — Get External Data Import (`ms-access-import-1.png`)

## Overview
A cropped Windows XP screenshot of the Microsoft Access application menu bar and open `File` menu, illustrating how to initiate a CSV file import via `File` -> `Get External Data` -> `Import...`.

## Interface & Menu Details
- **Title Bar:** A classic blue Windows XP title bar at the top left displays the red/maroon Microsoft Access key icon followed by bold white text **`Microsoft Access`**.
- **Menu Bar:** Below the title bar is the standard gray menu bar with items: **`File`** (selected/depressed), **`Edit`**, **`View`**, **`Insert`**, **`Tools`**, **`Window`**, and **`Help`**.
- **Open `File` Dropdown Menu:**
  - **`New...`** (`Ctrl+N`) with a blank page icon
  - **`Open...`** (`Ctrl+O`) with an open folder icon
  - **`Get External Data`** (highlighted in light blue selection border, with a right-pointing black submenu arrow)
  - **`Close`**
  - **`Save`** (`Ctrl+S`, grayed out/disabled with a floppy disk icon)
  - **`Save As...`** (grayed out/disabled)
- **Cascading Submenu:** Extending to the right of `Get External Data` is a two-item submenu:
  - **`Import...`** (highlighted in light blue, with an icon showing a black arrow pointing into two small database/table squares)
  - **`Link Tables...`** (with an icon showing a right arrow pointing to a table grid)
- **Background Workspace:** Partially visible behind the menus are disabled formatting toolbar icons (`B`, `I`, `U`, fill bucket, font color `A`, etc.) and an inner database window showing view mode icons and the text **`Design view`**.
