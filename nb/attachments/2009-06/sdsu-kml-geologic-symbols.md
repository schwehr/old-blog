# SDSU Geologic Map Symbol KML Generator Webpage (`sdsu-kml-geologic-symbols.png`)

## Overview
A screenshot of the "Geologic Map Symbol KML Generator 1.0 Beta" web application hosted by San Diego State University's (SDSU) Department of Geological Sciences (`KML Geology: Using Google in Geology`). Featured in a June 25, 2009 blog post (*"Geologic Symbols for Google Earth"*), the site allows field geologists to generate KML strike-and-dip plane symbols and plunge-and-trend lineation symbols for visualization in Google Earth.

## Interface & Layout
- **Top Header Banner (Black Background)**:
  - **Top Left**: Styled white cursive/serif title `KML Geology` above the sans-serif subtitle `Using Google in Geology`.
  - **Top Right**: The official university logo and wordmark featuring a red-and-black SDSU tower emblem beside gold serif text `SAN DIEGO STATE UNIVERSITY` and `Department of Geological Sciences`.
- **Three-Column Page Body (Overlaid on a Blue Earth Globe Background)**:
  - **Left Sidebar**:
    - Breadcrumb box at top: `Home:Tools`.
    - **`Tools` Box**: Shows a Google Earth `KML` document icon next to `Map Symbol Generator 1.0 Beta`.
    - **`What's New` Box**: Lists five downloadable KML datasets, each accompanied by a Google Earth `KML` file icon:
      1. `Geology of the San Diego 30'x60' Quad`
      2. `Geology of the San Diego Area`
      3. `US Isostatic Gravity Anomaly`
      4. `US Magnetic Anomaly`
      5. `US Terrestrial Gamma Radioactivity`
  - **Center Main Content Column**:
    - **Upper Overview Panel**: Headed in blue bold italic serif text `Geologic Map Symbol KML Generator 1.0 Beta`. Below the title is a horizontal graphic displaying five standard black geologic map symbols: a strike-and-dip symbol (line with short perpendicular tick), a thrust fault symbol (line with open triangle/barb), an overturned/cleavage symbol, a plunge-and-trend arrow, and a horizontal bedding circle-with-cross symbol. Beneath the graphic is the text: *"From your field data create plane and line symbols for your geolgic [sic] map in Google Earth."*
    - **Lower Generator Selection Panel**: Contains two bordered rectangular table sections:
      - **`PLANE` Section**: Displays an example strike-and-dip symbol labeled `45` on the left, alongside descriptive text: *"Generate a symbol that represents a planar feature, where strike and dip are measurements to define the plane. (i.e. N15W, 45 SW)"*, and a rounded gray button labeled `Generate Plane Symbol`.
      - **`LINE` Section**: Displays an example linear arrow symbol pointing up-left with `32` at the arrowhead, alongside descriptive text: *"Generate a symbol that represents a linear feature, where plunge and trend are measurements to define the line. (i.e. 32 at N20W)"*, and a rounded gray button labeled `Generate Line Symbol`.
  - **Right Sidebar**:
    - **Search Box**: Contains a `Google™ Custom Se` text input field and a rounded `Search` button.
    - **`Categories` Box**: Lists underlined links for `Gravity`, `Isotopes`, `Magnetics`, `Oceanography`, `San Diego Geology`, `Tools`, and `Volcanism`.
