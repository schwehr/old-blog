# Sediment Core Description Sheet Thumbnail (`core-description-sheet-sml.png`)

## Overview
A smaller, cropped version of the sediment core description sheet (`core-description-sheet.png`) for core `BPSIO 5G-Sec2` collected aboard the *R/V Sproul*, used as the inline preview image in Kurt Schwehr's July 13, 2009 blog post "Core description sheets."

## Layout & Contents
- **Cropping**: Unlike the full screenshot (`core-description-sheet.png`), this image crops out the surrounding Mac OS X Excel window title bar, row/column headers, and scrollbars, showing only the interior table cells of the core log.
- **Columns Shown**:
  - **Left Column (`BPSIO 5G-Sec2`)**: Displays `Photo Here)` above the vertical grayscale photograph of the split sediment core alongside the 0–150 cm vertical ruler scale.
  - **Second Column (`Pmag (cm)`)**: Contains the note `43 Samples Collected`.
  - **Third Column (`SS (cm)`)**: Empty column.
  - **Fourth Column (`Color`)**: Munsell color values (`5Y/4/2`, `5Y/4/1`, `5Y/3/2`) positioned at corresponding depths down the core.
  - **Fifth Column (`Description (Photo is archive half, description is working half)`)**: Centimeter-by-centimeter visual observations from `0-2cm Disturbed by tap endcap replacement` down to `150.7cm Bottom of section 2 - Total depth 194cm`.
- **Metadata Inset Box (Lower Right)**: Framed rectangular callout box listing:
  - `Expedition: bpsio`
  - `Ship: R/V Sproul`
  - `Core No: 5gw-sec2`
  - `Date Collected: 05-Aug-2004`
  - `Latitude: 34° 20.223' N`
  - `Longitude: 120° 01.414' W`
  - `Water Depth: 541 m`
  - `Chief Scientist: Schwehr/Babcock`
  - `Core Length: 150 (out of 194)`
  - `Core Diameter: 3.25 inch ID`
  - `Described By: Schwehr`
  - `Date Described: 06-Jan-2005`
  - `Date Split: 03-Sept-2004`
