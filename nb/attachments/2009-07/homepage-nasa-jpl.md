# NASA Jet Propulsion Laboratory Homepage (`homepage-nasa-jpl.png`)

## Overview
A screenshot of the NASA Jet Propulsion Laboratory (JPL) homepage (`http://jpl.nasa.gov/`) in Mozilla Firefox on Mac OS X, used by Kurt Schwehr in a July 8, 2009 blog post ("Goverment center homepage bake-off") to contrast JPL's multimedia-rich public outreach design with NOAA's Ocean Exploration website.

## Browser & Header Layout
- **Browser Chrome**: Mac OS X Firefox window titled `Space, Stars, Mars, Earth, Planets - NASA Jet Propulsion Laboratory` with URL `http://jpl.nasa.gov/`.
- **Top Banner**: Set against a dark blue starfield/nebula background:
  - Left: NASA "meatball" insignia next to white text `Jet Propulsion Laboratory` / `California Institute of Technology`.
  - Right: Top navigation links (`JPL HOME`, `EARTH`, `SOLAR SYSTEM`, `STARS & GALAXIES`, `SCIENCE & TECHNOLOGY`), secondary links (`BRING THE UNIVERSE TO YOU: JPL Email News | RSS | Podcast | Video`), and a search input box with a `search` button.
  - Main Navigation Bar: Horizontal gray buttons for `News`, `Missions`, `Multimedia`, `Kids`, `Education`, `Public Events`, `Work at JPL`, and `About JPL`.
