# ICANAppLoader HASP Driver Error Dialog (`ICANAppLoader-HASP.jpg`)

## Overview
A screenshot of a Windows Vista error dialog box generated by `ICANAppLoader` when attempting to launch the ICAN Aldebaran II navigation software without the hardware license dongle driver properly initialized.

## Interface & Visible Text
- **Window Frame:** Standard Windows Vista Aero-styled dialog box with a translucent blue-teal title bar, black title text `ICANAppLoader` on the top left, and a red close (`X`) button on the top right.
- **Dialog Content:**
  - Left side: A yellow triangular warning icon with a black exclamation point (`!`).
  - Right side message text (black sans-serif font on a white background):
    - `Error loading the HASP driver.`
    - `Please re-install the driver.`
- **Controls:** A gray `OK` button with a dotted focus rectangle in the lower right corner.
