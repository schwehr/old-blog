# Apple Hardware Test Error Screen (`apple-hardware-test-fail.jpg`)

## Overview
A photograph of a MacBook Pro screen running **Apple Hardware Test (Version 3A121)**, showing a detected hardware error (`4SNS/1/40000000: TG0D`) indicating a faulty motherboard/logic board temperature sensor after an AppleCare repair.

- **Tabs:** Three folder-style tabs above the main gray panel:

  - `Hardware Profile` (inactive)
