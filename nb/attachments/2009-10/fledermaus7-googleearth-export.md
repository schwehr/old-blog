# Exporting a GeoTIFF to Google Earth in Fledermaus 7 DMagic (`fledermaus7-googleearth-export.png`)

## Overview
A Mac OS X screenshot of the **DMagic** application (part of the IVS 3D **Fledermaus 7** software suite) demonstrating how to right-click an imported GeoTIFF (`mapsheet.tif`) to export a KML/KMZ image overlay for Google Earth.

## Interface & Context Menu
- **Window Title Bar:** `DMagic: /Users/schwehr/Desktop/FlederTmp/eel/`
- **Left Sidebar:**
  - **Top Pane (`Source Files`):** A hierarchical tree list with checked blue checkboxes:
    - `Ungidded`
    - `Grids`
    - `Images` (expanded):
      - `mapsheet.tif` (highlighted in blue)
    - `Vectors`
  - **Context Menu (Over `mapsheet.tif`):**
    - `Check All` (disabled/grayed out)
    - `Uncheck All` (disabled/grayed out)
    - `Add Image Data...`
    - `Convert to SD...`
    - `Edit Image...`
    - **Export to Google Earth...** (highlighted in blue)
    - `Edit Coordinate System...`
    - `View Metadata...`
    - `Remove File          Del`
  - **Bottom Pane (`SD Files`):** Columns for `Name` and `Type`, containing a checked item `eel-39.5-4...` of type `SonarDTM`.

## Preview Canvas (Right Pane)
- Against a black background, a vertically oriented grayscale shaded-relief bathymetric/topographic map sheet of the Eel River / northern California margin is displayed inside a cyan bounding box.
- White latitude labels run vertically along both the left and right edges of the map frame: `41°30'0.00"N`, `41°0'0.00"N`, `40°30'0.00"N`, and `40°0'0.00"N`.
