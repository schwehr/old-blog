# Knudsen Echosounder Control and Depth Display Windows on R/V *Marcus G. Langseth* (`langseth-knudsen-software-2.jpg`)

## Overview
A close-up photograph of a Windows computer monitor aboard the **R/V *Marcus G. Langseth*** displaying two floating dialog windows from the **Knudsen Sounder Suite** software—the **Echosounder** control panel on top and the **Depth Display** readout window below—while both high-frequency (HF) and low-frequency (LF) channels are turned off.

## Top Window (`Echosounder`)
A Windows XP-styled dialog window with a blue title bar (`Echosounder`) and three vertical control columns:
- **Left Column (`HF Channel`):**
  - `On/Off` button next to status `OFF`.
  - `Gain:` with a checked `Agc` checkbox and up/down spinner buttons.
  - `Power: 1` with up/down spinner buttons.
  - `Pulse Type:` with up/down spinner buttons (`1.5ms chirp`).
  - `Processing Gain:` `0` with up/down spinner buttons.
  - `Tx Blank:` `0.0` with up/down spinner buttons.
  - `Sensitivity:` `37` with up/down spinner buttons.
- **Middle Column (`LF Channel`):**
  - `On/Off` button next to status `OFF`.
  - `Gain: 122` with an unchecked `Agc` checkbox and up/down spinner buttons.
  - `Power: 4` with up/down spinner buttons.
  - `Pulse Type:` with up/down spinner buttons (`24 ms chirp`).
  - `Processing Gain:` `1` with up/down spinner buttons.
  - `Tx Blank:` `10.0` with up/down spinner buttons.
  - `Sensitivity:` `08` with up/down spinner buttons.
- **Right Column (Range, Phase & Depth Limits):**
  - `Range`: `1000` with up/down spinner buttons.
  - `Phase`: `1` with up/down spinner buttons.
  - `Wdw Limits:` `0-1000m`.
  - Unchecked `AutoPhase On` checkbox.
  - `Max. Depth Limit:` `4500` with up/down spinner buttons.
  - `Min. Depth Limit:` `5` with up/down spinner buttons.
  - **Close** button in the bottom-right corner.

## Bottom Window (`Depth Display`)
- Positioned directly below the `Echosounder` dialog, displaying large black sans-serif status text on a gray background:
  - **`HF: OFF`**
  - **`LF: OFF`**
