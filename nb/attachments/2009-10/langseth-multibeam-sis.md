# Kongsberg Seafloor Information System (SIS) Display on R/V Marcus G. Langseth (`langseth-multibeam-sis.jpg`)

## Overview
A photograph of an LCD monitor running Kongsberg's Seafloor Information System (SIS) hydrographic data acquisition software for the EM122 multibeam echosounder aboard the *R/V Marcus G. Langseth* while the sonar is inactive.

## Interface & Controls
- **Left Docked Panels**:
  - **Top Left (`Intensity` / `Quality`)**: A small black plot window displaying horizontal grid lines from `0` to `-60` on the left axis and `0` to `120` on the right axis.
  - **Upper Middle Left (`Crosstrack` / `Depth`)**: A black plot window showing depth axis ticks from `0.0` down to `50.0`.
  - **Lower Middle Left (`Waterfall`)**: An empty black waterfall display panel.
  - **Bottom Left (`Numerical display`)**: A tabular readout listing real-time navigation and system parameters, including:
    - `N 46 11.7369` / `North (DDMM.MMMM)`
    - `W 123 45.3264` / `East (DDMM.MMMM)` (Astoria, Oregon area)
    - `0.00` `Speed (kn)` / `Course (d)`
    - `14:17:04` `ZDA Clock` / `PU Time`
    - `2009-9-26` `Date`
    - `0.56` `Roll`, `0.35` `Pitch`, `-0.14` `Heave`, `112.9` `Heading`
- **Main Geographical View (Top Center)**:
  - A large black coordinate grid window labeled `Geographical` at the top right, with white latitude/longitude grid lines (`N46.197°` to `N46.194°`, `W123.76°` to `W123.75°`).
  - A cyan ship-heading vector arrow is positioned near the center of the black grid.
  - Along the bottom of the black canvas is a rainbow color scale bar labeled `Depth` ranging from `0.00` to `100.00`.
- **Runtime Parameters Panel (Bottom Center)**:
  - A tabbed configuration pane titled `Runtime parameters` with the **`Sounder Main`** tab active (alongside `Sound Speed`, `Filter and Gains`, `Data Cleaning`, `Seabed Image`, `Water Column`, `BIST`, `Simulator`, and `Survey Information`).
  - **Sector Coverage**: `Port` and `Starboard` `Max. angle (deg.)` set to `75` / `75`; `Max. Coverage (m)` set to `2500` / `2500`; `Angular Coverage mode` set to `AUTO`; `Beam Spacing` set to `EQUIDISTANT`.
  - **Depth Settings**: `Force Depth (m)` = `125`, `Min. Depth (m)` = `10`, `Max. Depth (m)` = `1000`, `Dual Swath mode` = `DYNAMIC`, `Ping Mode` = `AUTO`, and `FM disable` checked.
  - **Stabilization**: `Pitch stabilization` checked, `Along Direction (deg.)` = `0.0`, `Yaw Stabilization` `Mode` = `REL. MEAN HEADING`, `Heading` = `0.0`, `Heading filter` = `MEDIUM`.
- **Window & Taskbar**:
  - Standard Windows XP taskbar at the bottom with the green `start` button.
