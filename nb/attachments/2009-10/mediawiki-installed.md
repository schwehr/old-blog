# Fresh MediaWiki Installation Main Page (`mediawiki-installed.png`)

## Overview
A Mac OS X Safari browser screenshot showing the default `Main Page` of a newly installed local MediaWiki instance (`Finktest`) running via Fink on `http://localhost/mediawiki/index.php/Main_Page`.

  - Safari window titled `Finktest` with navigation buttons and the URL `http://localhost/mediawiki/index.php/Main_Page` in the address bar.
