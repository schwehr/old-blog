# Windows XP Professional Setup Partition Formatting Screen on MacBook Pro (`must-format-to-ntfs.jpg`)

## Overview
A photograph of a MacBook Pro screen running the blue text-mode Windows XP Professional Setup installer during a Boot Camp installation on Mac OS X 10.6, highlighting the requirement to format the Boot Camp partition as NTFS rather than leaving the default FAT32 file system intact.

## Interface & Visible Text
- **Laptop Frame**:
  - Silver aluminum MacBook Pro display bezel with the built-in iSight camera at the top center and `MacBook Pro` printed along the bottom bezel.
- **Setup Screen Content (Blue Background with White/Cyan Monospace Text)**:
  - Top header underlined: `Windows XP Professional Setup`
  - Prompt text:
    - `Setup will install Windows XP on partition`
    - `C: Partition3 (BOOTCAMP) [FAT32] 29378 MB ( 29362 MB free)`
    - `on 238473 MB Disk 0 at Id 0 on bus 0 on atapi [MBR].`
  - Instructions:
    - `Use the UP and DOWN ARROW keys to select the file system you want, and then press ENTER. If you want to select a different partition for Windows XP, press ESC.`
  - **File System Options List**:
    - `Format the partition using the NTFS file system (Quick)`
    - `Format the partition using the FAT file system (Quick)`
    - `Format the partition using the NTFS file system` — marked with two added orange horizontal indicator lines on the left and right to emphasize the recommended choice.
    - `Format the partition using the FAT file system`
    - `Convert the partition to NTFS`
    - `Leave the current file system intact (no changes)` — currently highlighted by the light-blue selection bar.
  - **Bottom Status Bar**:
    - `ENTER=Continue   ESC=Cancel`
