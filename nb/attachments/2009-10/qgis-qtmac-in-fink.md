# Quantum GIS 1.0.2-Kore Native Qt/Mac Build via Fink (`qgis-qtmac-in-fink.png`)

## Overview
A Mac OS X screenshot showing a freshly built native Qt-Mac version of Quantum GIS (`Quantum GIS - 1.0.2-Kore`) packaged in Fink by BABA Yoshihiko, running natively under Mac OS X Aqua without X11.

## Interface & Controls
- **Mac OS X Menu Bar (Top)**:
  - Apple icon, bold **`QGIS`**, `File`, `Edit`, `View`, `Layer`, `Plugins`, `Window`, `Help`, and right-side system tray icons.
- **Main Application Window (`Quantum GIS - 1.0.2-Kore`)**:
  - **Two Rows of Icon Toolbars**:
    - *Top row*: File operations (`New Project`, `Open Project`, `Save Project`, `Save Project As`, `Print Composer`), layer addition buttons (`Add Vector Layer`, `Add Raster Layer`, `Add PostGIS Layer`), layer management icons (`New Vector Layer`, `Remove Layer`, `Add to Overview`, `Show All Layers`, `Hide All Layers`), and identification/measurement/bookmark tools (`Identify Features`, `Select Features`, `Open Attribute Table`, `Measure Line`, `Measure Area`, `Show Bookmarks`).
    - *Second row*: Digitizing tools (disabled/grayed out), map navigation tools (`Pan Map` hand icon active, `Zoom In`, `Zoom Out`, `Zoom Full`, `Zoom to Selection`, `Zoom to Layer`, `Zoom Last`, `Refresh`), and GRASS tools on the right.
  - **Left Docked Panel (`Legend`)**:
    - Empty white layer tree pane below the `Legend` header bar.
  - **Central Map Canvas**:
    - Blank white map viewport.
  - **Bottom Status Bar**:
    - Coordinate display box showing `0,0`, `Scale` box showing `Invalid scale`, a red `X` stop-rendering button, a checked `Render` checkbox, and a projector icon for CRS/projection settings in the bottom-right corner.
