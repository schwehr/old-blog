# Select a Backup Screen in Mac OS X Time Machine System Restore (`timemachine-restore-2.jpg`)

## Overview
A photograph of a Mac screen showing the **Select a Backup** step of the Mac OS X **Restore System From Backup** utility during a recovery from a Time Machine backup after experimenting with Boot Camp partitioning.

## Dialog Layout & Visible Text
- **Header**: Large centered dark text at the top reads **Select a Backup**.
- **Instructions**: Below the title, two lines of explanatory text state:
  > Select the Time Machine backup you want to restore. Only complete backups of Mac OS X appear in the list.
- **Backup Source Selector**: A centered drop-down menu labeled **Restore From:** is set to **`CatboxIII on CatboxIII`**.
- **Backup List Table**: A large white list box with two column headers—**Backup Date & Time** on the left and **Mac OS X Version** on the right—contains a single highlighted row in blue:
  - **Backup Date & Time**: `October 22, 2009 3:45:47 PM`
  - **Mac OS X Version**: `10.6.1 (10B504)`
- **Navigation Buttons**: At the bottom center of the dialog are two pill-shaped buttons: **Go Back** on the left and **Continue** on the right, with the mouse cursor hovering just above the **Continue** button.
