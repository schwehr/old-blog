# Selecting Restore System From Backup in Mac OS X Installer (`timemachine-restore.jpg`)

## Overview
A close-up photograph of a Mac laptop screen running the **Mac OS X Installer** environment (Mac OS X 10.6 Snow Leopard), showing the **Utilities** drop-down menu with the **Restore System From Backup...** option highlighted.

## Interface & Menu Details
- **Top Menu Bar**: A translucent gray menu bar at the top of the screen displays the Apple logo on the far left, followed by **Mac OS X Installer**, **File**, **Edit**, **Utilities** (highlighted in blue), and **Window**.
- **Utilities Drop-Down Menu**: The open menu lists eight utility applications, each accompanied by its Mac OS X icon on the left:
  1. **Startup Disk...** (gray hard drive icon with a question mark)
  2. **Reset Password...** (silver padlock icon)
  3. **Firmware Password Utility...** (large silver padlock icon)
  4. **Disk Utility...** (hard drive icon with a stethoscope)
  5. **Terminal...** (black command-line prompt icon `>_`)
  6. **System Profiler...** (hard drive/caliper icon)
  7. **Network Utility...** (radar screen icon)
  8. **Restore System From Backup...** (highlighted in bright blue with white text, featuring the circular Time Machine clock/counterclockwise arrow icon; the black arrow cursor hovers directly at the bottom of this item).
- **Background**: The dark space/starfield aurora wallpaper of the Mac OS X Snow Leopard installer is visible on the left, with the edge of an installer dialog window on the right.
