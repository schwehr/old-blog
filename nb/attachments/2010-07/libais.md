# CMake Graphviz Dependency Graph for `libais` (`libais.png`)

## Overview
A simple directed dependency graph generated by CMake (`cmake --graphviz=libais.dot .`) and rendered with Graphviz (`dot -Tpng`), showing the build target relationship in Kurt Schwehr's `libais` C++ library project. Featured in the July 7, 2010 blog post *"CMake continued - trying to make a setup for libais"*.

## Diagram Structure & Elements
- **Background & Style:** Black line drawings and black serif text on a plain white background.
- **Top Node (`node1`):** A five-sided house-shaped polygon (flat bottom, vertical sides, peaked roof) containing the label `test_libais` (representing the C++ test executable target).
- **Directed Edge:** A vertical black arrow pointing straight downward from the bottom center of the `test_libais` house node to the top vertex of the `ais` diamond node.
- **Bottom Node (`node0`):** A four-sided diamond polygon containing the label `ais` (representing the shared/static library target `libais`).
