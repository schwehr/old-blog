# Google Scribe Predictive Writing Web Interface (`google-scribe.png`)

## Overview
A screenshot of a Mac OS X web browser window displaying **Google Scribe** (`http://scribe.googlelabs.com/`), an experimental Google Labs predictive text and autocomplete writing tool from September 2010.

## Interface & Controls
- **Browser Chrome (Top)**:
  - Mac OS X window title bar reading `Google Scribe` with red, yellow, and green window controls on the left.
  - Browser toolbar showing Back/Forward buttons, Reload, Stop (disabled), Home, Top Sites grid, Reading List/Bookmarks icon, a `TAG` button, and the address bar displaying `http://scribe.googlelabs.com/`.
- **Page Header & Toolbar**:
  - **Logo**: Classic multicolor `Google` logo followed by blue `scribe` text and gray `labs` subscript.
  - **Tagline**: `Get autocomplete suggestions as you type`
  - **Control Bar**: A light gray horizontal bar containing:
    - Language dropdown menu set to `English`
    - **`Show suggestions`** dropdown menu set to `as I type ("Always")`
    - Keyboard shortcut hint on the right: **`Enter`**` - Choose suggestion`

## Text Editor & Autocomplete Dropdown
- **Typed Text**: Inside the main monospace text area, the user has typed:
  - `Scribe is a writing tool that au` followed by the inline highlighted completion **`tomates`** (shaded in light blue).
- **Autocomplete Suggestion Menu**: A floating white dropdown menu positioned directly below `automates` lists 10 numbered completions (with keyboard shortcuts `1`–`9` and `0`, plus small flag icons on the right of each row to report offensive/bad suggestions):
  1. `auto` (`1`)
  2. `automates` (`2`, highlighted in gray)
  3. `automates context` (`3`)
  4. `automates the` (`4`)
  5. `automatically` (`5`)
  6. `automatically generates` (`6`)
  7. `automatically keep` (`7`)
  8. `automatically tracks` (`8`)
  9. `audits the` (`9`)
  10. `augments` (`0`)
- **Menu Footer**: Bottom row of the popup contains blue underlined action links: `A-Z`, `G`, `R`, `S`, and `?`.
