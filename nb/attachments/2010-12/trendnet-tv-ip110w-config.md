# TRENDnet TV-IP110W Wireless Internet Camera Configuration Screen (`trendnet-tv-ip110w-config.png`)

## Overview
A screenshot of the web-based administration interface for a TRENDnet `TV-IP110W` Wireless-G Internet Camera Server, showing the `Video » Camera` configuration page and live preview feed on December 2, 2010.

## Interface & Controls
- **Top Banner**:
  - Left: Circular blue-and-white globe icon and `TRENDnet` logo.
  - Right: `Wireless Internet Camera Server` / `TV-IP110W`, with status line `Location: home   2010/12/02 21:14:55`.
- **Left Navigation Sidebar**:
  - Mode buttons at top: `Live View` (with eye icon) and `Setup` (with gears icon).
  - Configuration menu buttons below: `Smart Wizard`, `Basic`, `Network`, `Video` (expanded to show `• Camera` underlined and `• Video`), `Event Server`, `Motion Detect`, `Event Config`, `Tools`, and `Information`.
- **Main Content Area (`Video » Camera`)**:
  - **Live Video Preview**: Centered 320×240 camera feed with a black top status bar stamped `2010/12/02 21:14:58`, showing an indoor view of a dark wooden bookshelf filled with books and binders next to a burgundy wall and white door trim.
  - **`Image Setting` Table**:
    - `Brightness:`: text input set to `10` `(0~100)`
    - `Contrast:`: text input set to `32` `(0~100)`
    - `Saturation:`: text input set to `36` `(0~100)` alongside a rounded `Default` button
    - `Mirror:`: checkboxes for `Vertical` (unchecked) and `Horizontal` (unchecked)
    - `Light Frequency:`: radio buttons for `50Hz` (unselected), `60Hz` (selected in blue), and `Outdoor` (unselected)
  - **`Overlay Setting` Table**:
    - `Include Date & Time`: checkbox (checked)
    - `Enable Opaque`: checkbox (checked)
  - **Bottom Action Bar**: Blue metallic `Apply` and `Cancel` buttons, above a footer reading `Copyright © 2009 TRENDnet. All Rights Reserved.`
