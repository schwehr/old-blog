# Open Wonderland Server Administration Interface (`openwonderland-server-admin.png`)

## Overview

A screenshot of the Open Wonderland web-based `Server Admin` interface displaying the `Manage Content` page and a directory listing of installed server modules.

## Header & Navigation Sidebar

- **Top Banner**: A dark slate-gray header bar featuring the white `openwonderland` logo (with three exclamation-mark-like rays radiating from a circle) on the left. On the right, small dark text reads `Server: 192.168.0.6, Port: 8080` and `Version: 0.5-preview4 (rev. 4418)` above the large light-gray heading `Server Admin`.
- **Left Navigation Menu**: A vertical gray sidebar with blue links divided by horizontal separators:
  - `Home`
  - `Manage Server`
  - `Edit Placemarks`
  - `Manage Apps`
  - `Manage Content`
  - `Manage Groups`
  - `Manage Modules`
  - `Manage Worlds`
  - `Monitor Server`
