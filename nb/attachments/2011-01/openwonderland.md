# Open Wonderland 3D Virtual World Client (`openwonderland.png`)

## Overview

A screenshot of the Open Wonderland Java client window running on Mac OS X, showing the default 3D virtual environment with a user avatar (`schwehr...`) standing in a stone courtyard surrounded by classical arches and cypress trees.

- **Window Title & Menu Bar**: A Mac OS X application window titled `Wonderland` with a menu bar inside the window frame listing `File`, `Edit`, `View`, `Insert`, `Placemarks`, `Tools`, `Window`, and `Help`.
