# Mac OS X System Preferences - Remapping Caps Lock to Control (`systempreferences-kbd-capslock.png`)

## Overview

A screenshot of the `Keyboard` pane in Mac OS X `System Preferences` showing the `Modifier Keys...` sheet open, where the `Caps Lock` key is being remapped to `^ Control` for easier use in Emacs.

## Interface & Controls

- **Menu Bar & Window Header**: At the top is the Mac OS X menu bar showing the Apple logo, `System Preferences` (in bold), `Edit`, `View`, `Window`, and `Help`. Below it is the `Keyboard` preference window header with back/forward navigation arrows, a `Show All` button, and a search field.
- **Background Keyboard Pane**: Dimmed behind the modal sheet, showing the `Show Keyboard & Character Viewer in menu bar` checkbox (unchecked), an illumination timeout slider (`5 secs`, `10 secs`, `30 secs`, `1 min`, `5 mins`, `Never`), and the `Modifier Keys...` button at the bottom right.
- **Modifier Keys Modal Sheet**:
  - **Device Selector**: At the top, `Select keyboard:` is set to `Apple Internal Keyboard / Trackpad` in a blue-highlighted dropdown menu.
  - **Instructions**: Text reads: `For each modifier key listed below, choose the action you want it to perform from the pop-up menu.`
  - **Key Mapping Dropdowns**:
    - `Caps Lock (⇪) Key:` — The pop-up menu is actively open, showing options `⇪ Caps Lock`, `✓ ^ Control` (highlighted in blue with a checkmark), `⌥ Option`, `⌘ Command`, and `No Action`.
    - `Control (^) Key:` — Partially covered by the open pop-up menu.
    - `Option (⌥) Key:` — Partially covered by the open pop-up menu.
    - `Command (⌘) Key:` — Set to `⌘ Command`.
  - **Action Buttons**: At the bottom of the sheet are three pill-shaped buttons: `Restore Defaults`, `Cancel`, and `OK` (pulsing blue default button).
