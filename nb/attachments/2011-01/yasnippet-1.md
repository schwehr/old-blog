# Aquamacs Emacs YASnippet Completion Menu in SQL Mode (`yasnippet-1.png`)

## Overview

A screenshot of Aquamacs Emacs on Mac OS X showing the `YASnippet` template completion pop-up menu triggered after typing `create` in an SQL buffer (`test.sql`).

## Interface & Editor Details

- **Mac OS X Menu Bar**: At the top of the screen, the menu bar displays the Apple icon, `Aquamacs` (in bold), `File`, `Edit`, `Options`, `Tools`, `SQL`, `YASnippet`, `Window`, and `Help`.
- **Window Title & Toolbar**: The window title bar shows `/Users/schwehr/Desktop/org` on the right. Below it, the Aquamacs toolbar features large icons for `New`, `Open`, `Recent`, `Save`, and `Print` on the left, and `Undo`, `Redo`, and `Cut` on the right.
- **Buffer Tab Bar**: Four open buffer tabs are displayed across the window:
  1. `*scratch*` (`1`)
  2. `kurt-2011.org` (`2`)
  3. `foo.py` (`3`)
  4. `test.sql` (`4`, active white tab)
- **Editor Buffer & Pop-up Menu**:
  - Inside the black editor buffer, the word `create` is typed in cyan syntax-highlighted text at the top left, followed by a red vertical cursor bar.
  - Directly below the cursor is a white Mac OS X pop-up context menu headed by disabled gray text `Choose a snippet:`, followed by two selectable SQL template options:
    - `create table ...` (currently highlighted in blue with white text)
    - `create procedure ...`
