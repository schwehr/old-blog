# Google Cr-48 Chrome OS Default New Tab / Home Screen (`cr48-05-home.jpg`)

## Overview
This photograph shows the default **New Tab** home screen of the Google Cr-48 Chrome OS notebook, displaying the pre-installed web applications grid and collapsible sections.

## Interface & App Icons
- **Browser Chrome (Top)**:
  - Active tab titled `New Tab` with a `+` button to its right.
  - Navigation bar below with Back (`←`), Forward (`→`), Reload (`↻`), and an omnibox containing a magnifying glass icon and a blinking text cursor (`|`).
  - Bookmarks bar banner directly beneath the omnibox reading: `For quick access, place your bookmarks here on the bookmarks bar.`
- **Apps Section**:
  - An expanded section header reading `▾ Apps` with a horizontal divider line and a close/hide (`x`) control on the far right (a hand cursor icon hovers near the top right of the grid).
  - **First Row of App Icons (Left to Right)**:
    1. **Get Started**: Blue circular icon with an orange/red retro rocket ship.
    2. **Entanglement**: Square geometric tile game icon with a red hexagonal path pattern.
    3. **Poppit**: Light blue square icon with a yellow star-marked balloon.
    4. **YouTube**: Classic `You` above a red rounded rectangle containing `Tube`.
    5. **Scratchpad**: Yellow lined notepad icon with a folded bottom-right corner.
    6. **Google Maps**: Blue-bordered map square with a red location pin (`📍`).
    7. **Web Store**: White shopping bag icon featuring the colorful Google Chrome logo on its side.
  - **Second Row of App Icons (Left to Right)**:
    1. **Gmail**: Classic red-and-white `M` envelope icon.
    2. **Google Talk**: White speech bubble containing `talk` in blue, red, yellow, and green letters.
- **Bottom Sections**:
  - Below the Apps grid are two collapsed section headers side-by-side: `▸ Most visited` and `▸ Recently closed`.
