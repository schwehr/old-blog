# Google Cr-48 Chrome OS Wrench Menu and Tools Submenu (`cr48-06-tools.jpg`)

## Overview
This photograph shows the top-right corner of the Google Cr-48 Chrome OS browser with the main wrench (`🔧`) settings menu open and the **Tools** submenu expanded to the left.

  - A dark gear/extension icon.
  - The active **Wrench** (`🔧`) menu button depressed in the top-right corner.
- **Main Wrench Menu (Right Vertical Menu)**:

  - `New window` (`Ctrl+N`)

  - Separator line
  - `Edit` row with three inline buttons: `Cut` | `Copy` | `Paste`
  - Separator line
  - `Zoom` row with inline controls: `-` | `100%` | `+` and a full-screen icon button
  - Separator line
  - `Save page as...` (`Ctrl+S`)

  - `Settings`
