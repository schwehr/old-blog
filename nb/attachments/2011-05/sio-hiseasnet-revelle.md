# SIO HiSeasNet Real-Time Ship Data Webpage for R/V Roger Revelle (`sio-hiseasnet-revelle.png`)

## Overview
A screenshot of a Mac OS X web browser window taken on May 4, 2011, displaying the Scripps Institution of Oceanography (SIO) **HiSeasNet** real-time vessel telemetry, map position, and live shipboard webcam page for the research vessel *R/V Roger Revelle* while operating in the Philippine Sea southeast of Taiwan.

- **Browser Chrome**: Mac OS X window titled `HiSeasNet: Research Vessel Realtime Data: R/V Roger Revelle` at URL `http://rtapps.ucsd.edu/hiseasnet/rtship/index.php?ship=revelle`.
