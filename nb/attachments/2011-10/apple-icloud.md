# Apple OS X System Preferences iCloud Sign-In Pane (`apple-icloud.png`)

## Overview
A screenshot of the `"iCloud"` preference pane in Mac OS X Lion (10.7) System Preferences, showing the welcome/sign-in screen with application icons and an Apple ID login form.

## Interface & Visual Details
- **Window Header & Toolbar**:
  - Standard Mac OS X window title bar with red, yellow, and green window control buttons on the left and the title `"iCloud"` centered.
  - Below the title bar is a brushed-metal toolbar with back/forward navigation arrows (`<`, `>`), a `"Show All"` button on the left, and a rounded search field with a magnifying glass icon on the right.
- **Main Content Area**:
  - **Heading**: Large dark-gray sans-serif title `"iCloud"`, followed by the subtitle `"iCloud stores your content and wirelessly pushes it to your devices."` and a blue hyperlink `"Learn more about iCloud..."`.
  - **Icon Banner**: A row of seven glossy, angled application icons with subtle reflections on a light gray surface:
    1. **iTunes** (purple icon with a white circle and musical note)
    2. **Documents in the Cloud / Pages** (blue document page icon with a small gray cloud)
    3. **Photo Stream / iPhoto** (sky-blue icon with a yellow sunflower)
    4. **iCloud** (large central brushed-stainless-steel square icon featuring the recessed metallic cloud symbol)
    5. **Mail** (blue sky icon with a white envelope)
    6. **iCal / Calendar** (red-topped calendar page showing `"Monday"` and a large black `"6"`)
    7. **Address Book / Contacts** (tan leather-bound address book with a user silhouette and alphabetical tabs `A–F`)
- **Sign-In Form (Bottom)**:
  - Prompt text: `"Set up iCloud with your Apple ID:"`.
  - Left text input field: Pre-filled Apple ID email address redacted with a solid black rectangle, with a blue link below reading `"Create an Apple ID..."`.
  - Middle text input field: Placeholder text `"Password"`, with a blue link below reading `"Forgot password?"`.
  - Right button: Rounded white button labeled `"Sign In"`.
