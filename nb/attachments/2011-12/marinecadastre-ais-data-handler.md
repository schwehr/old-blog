# MarineCadastre.gov AIS Data Handler Webpage (`marinecadastre-ais-data-handler.png`)

## Overview
A screenshot of the **MarineCadastre.gov** webpage (`http://marinecadastre.gov/AIS/`) introducing the 2009 archived Automatic Identification System (AIS) dataset and the **AIS Data Handler** ArcGIS add-in and conversion toolset developed by the NOAA Coastal Services Center and BOEM.

## Page Layout & Navigation
- **Header Banner**: Dark navy-blue header with the silver-blue title **`MARINECADASTRE.GOV`** at top left and a horizontal navigation bar below containing links: `Home`, `About`, `Partnerships`, `Data`, `Regional Resources`, `Map Gallery`, `Support`, and `Updates`.
- **Left Sidebar**:
  - **Regional Navigation Menu**: Dark blue vertical menu boxes for:
    - `AIS Data Home`
    - `Hawaii & Alaska`
    - `West Coast`
    - `Gulf of Mexico`
    - `Atlantic`
    - `Request Access`
  - **`Downloads (version 1.0)` Panel**: Framed box below the menu with orange-gold links:
    - `AIS Data Handler Tutorial (Draft)`
    - `AIS Data Handler ArcMap Add-In`
    - `AIS Data Handler Pre-Processor`
    - `AIS Data Metadata`
    - `AIS Data Handler source code` `- for developers`
    - `Miami Port Sample Data`

## Main Content Area
Set on a dark slate-blue background with white text and orange hyperlinks:
- **`AIS Data`**: Explains that AIS data are collected by the U.S. Coast Guard to track real-time vessel information (ship identity, purpose, course, speed) in coastal U.S. waters, and that the featured 2009 archived dataset is intended for the ocean planning community, linking to the `Nationwide Automatic Identification System` website.
- **`The AIS Data Handler`**:
  - Describes how the tool streamlines the acquisition, loading, filtering, display, and analysis of AIS data with data conversion tools and an ArcGIS add-in, developed as part of the Multipurpose Marine Cadastre project by the NOAA Coastal Services Center and the Department of the Interior's Bureau of Ocean Energy Management (BOEM).
  - **Inset Map Graphic** (right side): A color-coded vessel density map of the entrance to Miami Port showing high-density shipping lanes in red/orange/yellow radiating eastward into the Atlantic over a blue/green bathymetric background.
  - **`AIS Data Handler Database`**: Notes that the archive originates from USCG land-based receiver stations for calendar year 2009, filtered to 1 minute and formatted in zipped monthly file geodatabases by Universal Transverse Mercator (UTM) zone, with links to `index map of UTM zones` and `user name and password`.
