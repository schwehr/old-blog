# Research Tools 2011 Lecture 26 Title Slide (`rt-26.png`)

## Overview
The title slide for **Lecture 26** (the final class session) of Kurt Schwehr's **Research Tools 2011** course (`ESCI 895`) at UNH CCOM/JHC on December 1, 2011, covering open-source software licensing and writing KML and SQLite files in Python.

## Slide Layout & Text
Set on a light gray gradient background with dark gray Gill Sans / sans-serif typography centered in the middle and lower half:
- **Main Title**:
  `RESEARCH TOOLS 2011`
  `LECTURE 26`
- **Subtitle / Metadata**:
  `2011-Dec-01`
  `Kurt Schwehr`
  `http://schwehr.org` *(underlined)*
- **Footer Text**:
  `UNH CCOM/JHC`
  `Python: writing KML and SQLite`
- **License Badge**: Bottom-left corner displays a Creative Commons **BY-NC-SA** (` Attribution-NonCommercial-ShareAlike`) icon.

## Inset Screenshots
Four screenshots illustrate the topics of the lecture:
1. **Top Left**: An Ubuntu Linux desktop running Mozilla Firefox displaying Wikipedia's *"Comparison of free and open-source software licenses"* table with green (`Yes`) and red/pink (`No`) cells.
2. **Top Center**: A Mac OS X **Google Earth** window showing a white vessel trackline plotted offshore in the ocean off the northeastern United States (`2011_198_1259_500_sub.kml`).
3. **Top Right**: An Ubuntu Linux desktop running the **SQLite Manager** Firefox add-on inspecting a table named `sbet_entry` (with columns `id`, `time`, `x`, `y`, `z`, `x_sd`, etc.) and displaying query results for `SELECT * FROM sbet_entry LIMIT 10` highlighted in green and pink.
4. **Middle Left**: A form widget showing radio buttons for **Version control system** (`Git`, `Mercurial`, `Subversion`) and an open dropdown menu for **Source code license** (currently set to `Eclipse Public License 1.0`, with `New BSD License` highlighted in blue among options including `Apache License 2.0`, `Artistic License/GPL`, `GNU GPL v2`, `GNU GPL v3`, `GNU Lesser GPL`, `MIT License`, `Mozilla Public License 1.1`, and `Other Open Source`).
