# YouTube Machine Transcription Captions Interface (`youtube-machine-translations-for-captions.png`)

## Overview
A screenshot of the YouTube Video Manager Captions editor interface taken in December 2011, showing the automatic machine-generated English transcription for Kurt Schwehr's instructional video `"RT 1 - emacs keyboard introduction"`.

## Interface & Controls
- **Top Navigation Bar**:
  - The classic red-and-black **YouTube** logo on the top left, followed by a white search input box with a magnifying glass button, and navigation links `Browse`, `Movies`, and `Upload`.
  - On the top right, the logged-in user's avatar thumbnail and username `goatbar` with a dropdown arrow.
- **Dark Gray Video Editor Sub-Header**:
  - Four navigation tabs on the left: `Info and Settings`, `Enhancements`, `Annotations`, and the active tab `Captions` (highlighted with a darker background).
  - Two dark gray action buttons on the right: `View on video page` and `Video Manager`.
- **Video Title**: Below the sub-header in large black sans-serif text: `RT 1 - emacs keyboard introduction`.
- **Left Column (Video Player)**:
  - An embedded YouTube video player showing a screenshot of an Ubuntu desktop running GNU Emacs with tutorial notes on keyboard shortcuts (`C-x o other window`, `C-x 3 split left right`, `C-s text <--- search`, etc.).
  - A large semi-transparent play button overlay sits in the center of the video frame, and the bottom control bar shows the play button, volume icon, timestamp `0:00 / 0:00`, and fullscreen button.

## Caption Track Editor (Right Column)
- **Header & Track Controls**:
  - Bold heading `Editing Track:` above a `Language:` dropdown menu (set to `English`, grayed out) and an empty `Name:` text input field.
- **Caption Text List**: A scrollable gray-bordered table under the dark header bar `Caption Text`, displaying timestamped rows of humorous speech-to-text misrecognitions of technical terms (such as "Kurt Schwehr" becoming "kurt shillinger" and "Emacs" becoming "the game now", "he max", and "imax"):
  - `00:01` — `pull my name is kurt shillinger and i'll be showing you the game now`
  - `00:04` — `expect senator`
  - `00:06` — `now he max is more than just tech center itself`
  - `00:10` — `pull environment for all sorts of text manipulation passes including`
  - `00:15` — `programming handed nanjing`
  - `00:18` — `have projects in other tasks`
  - `00:21` — `to tell it to give you an overview of how to use imax using just the keyboard`
- **Bottom Actions**:
  - Blue link on the bottom left: `« Return to All Tracks`.
  - White button on the bottom right with a downward arrow icon: `Download`.
