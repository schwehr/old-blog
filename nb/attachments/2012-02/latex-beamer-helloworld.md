# LaTeX Beamer Hello World Presentation in Mac OS X Preview (`latex-beamer-helloworld.png`)

## Overview
A screenshot of Mac OS X's `Preview` application displaying a single-page PDF slide (`helloworld-beamer.pdf`) generated using the LaTeX `beamer` document class with the default theme.

## Slide Content & Layout
- **Slide Title**: Near the top left of the white 4:3 slide canvas, the frame title reads `A universal law` in large, sans-serif blue text.
- **Slide Body**: Vertically centered toward the left side of the slide, the body text reads `Hello world!` in clean black sans-serif font.
- **Beamer Navigation Symbols**: Along the bottom-right edge of the slide are faint light-blue/gray standard Beamer navigation icons (slide, frame, subsection, section, presentation, and search/go-back arrows).

## Application Interface & Menu Bar
- **Mac OS X Menu Bar**: At the top of the screen, the Apple logo is followed by `Preview`, `File`, `Edit`, `View`, `Go`, `Tools`, `Bookmarks`, `Window`, `Help`, and two status bar icons on the right (including a black-and-white character icon and the blue Dropbox box icon with a green checkmark).
- **Window Title Bar**: Standard red, yellow, and green Mac window buttons on the left, a PDF document icon with the title `helloworld-beamer.pdf (1 page)` in the center, and a full-screen double-arrow icon on the right.
- **Preview Toolbar**:
  - Zoom out and zoom in magnifying glass buttons
  - Tool mode selector: Move/hand, Text selection (`A`, active/highlighted in dark gray), Rectangular selection
  - Annotation pencil button
  - View mode selector: Content Only (active), Thumbnails, Table of Contents, Contact Sheet
  - Rounded search bar on the right with a magnifying glass icon
