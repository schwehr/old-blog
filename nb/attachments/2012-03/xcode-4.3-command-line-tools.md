# Xcode 4.3 Downloads Preferences Window Showing Command Line Tools (`xcode-4.3-command-line-tools.png`)

## Overview
A screenshot of the Mac OS X `Xcode` 4.3 Preferences window (`Downloads` -> `Components` tab), illustrating that the `Command Line Tools` package (`171.7 MB`) is no longer bundled by default and must be installed separately from within Xcode's preferences.

## Window Controls & Component List
- **Mac OS X Menu Bar**: Apple icon, `Xcode`, `File`, `Edit`, `View`, `Navigate`, `Editor`, `Product`, `Window`, `Help`, and status icons on the right (Dropbox, headphones, and display/window utility icon).
- **Preferences Toolbar (`Downloads`)**:
  - Seven top-level preference icons: `General`, `Behaviors`, `Fonts & Colors`, `Text Editing`, `Key Bindings`, `Downloads` (selected/highlighted), and `Locations`.
- **Segmented Sub-tabs**: `Components` (selected in dark gray) and `Documentation`.
- **Update Controls**:
  - Unchecked checkbox: `Check for and install updates automatically`
  - Button on right: `Check and Install Now`
- **Downloadable Components List**:
  1. `iOS 4.3 Simulator (499.2 MB)` — with `Install` button
  2. `iOS 4.0 - 4.1 Device Debugging Support (505.1 MB)` — with `Install` button
  3. `iOS 3.0 - 3.2.2 Device Debugging Support (686.3 MB)` — with `Install` button
  4. `Command Line Tools (171.7 MB)` — with `Install` button
