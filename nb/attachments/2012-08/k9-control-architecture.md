# NASA Inventions and Contributions Board Release Form for K9 Rover Control Software (`k9-control-architecture.png`)

## Overview
A screenshot of an official NASA legal release document titled **"Release for Award from the NASA Inventions and Contributions Board"** for **NASA Case No. ARC-14587-1 (`K9 Rover Control Software`)**, which Kurt Schwehr signed to receive a monetary software release award for his work on the NASA Ames K9 Mars rover architecture.
