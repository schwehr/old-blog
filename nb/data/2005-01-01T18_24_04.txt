Wow.  It actually works.  I have been trying to get these things to
work for a long time!  I copied moods and configure blog.conf like
this 

<pre>
  cp -r /sw/share/nanoblogger/moods $BLOG_DIR

  MOODS_URL="http://schwehr.org/blog/moods"
  AUTO_FORMAT="1"
</pre>

Then it magically worked.  Now I do not need to put in paragraph tags
either.

I updated the nanoblogger.info file so that <b>nb --manual</b> now
works if you have set BROWSER in ${BLOG_DIR}/blog.conf to something
like <b>open</b>
