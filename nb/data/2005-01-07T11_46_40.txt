For my Mac trick of the moment, check out this.  First quit x11.  Then
open a terminal and run the following command.  open-x11 makes sure
that x11 if first running and then runs the command.  This is good for
wrapping x11 programs in a double clickable Aqua app.
<pre>
  open-x11 xterm

  For example: <a href="http://schwehr.org/software/marine-geo-fink-v2.dmg.bz2">marine-geo-fink-v2.dmg.bz2</a>
</pre>
