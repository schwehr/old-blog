Interesting virtual filesystem that lets you see inside db and tar
files too.  Nifty idea.

I was saved by USENET today.  I was trying to figure out how to get
multiple tall skinny plots next to each other in a row.  I posted via
Google groups and 2 hours later I had the answer to check out
multiplots.
<pre>
  gnuplot
  set size 0.7,0.7
  set origin 0.1,0.1
  set multiplot
  set size 0.4,0.4
  set origin 0.1,0.1
  plot sin(x)
  set size 0.2,0.2
  set origin 0.5,0.5
  plot cos(x)
  unset multiplot
</pre>
