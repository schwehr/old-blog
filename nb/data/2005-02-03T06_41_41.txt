I got an email from <a href="http://www.faldersons.net/">Freddy
Aldersons</a> about the release of some free seismic programs.  Too
bad he does not release the source.  I can't put binary only stuff in
fink.  Sorry.

<a href="http://www.geocenter.com/">Geocenter</a> just announced a
release of SeisUP on freshmeat.net, but this is unfortunately not an
F/OSS system.

Jenna is still asking for Landmark since it can pick a horizon from
multiple lines and make a surface.  Can't other programs do that too?

<a href="http://www.ngdc.noaa.gov/mgg/gebco/gebco.html">Gebco</a> -
General Bathymetric Chart of the Oceans.

<a
href="http://www.sciencedaily.com/releases/2005/02/050201100856.htm">Cardiff
Univ, UK</a> has a program that "features novel 3-D methods to map the
seabed."  They are using software by <a
href="http://www.codaoctopus.com/">CodaOctopus</a>.  I have never
heard of them.  But that is not too surprising as I live in the land
of MB-System. (ScienceDaily)

Maybe <a href="http://miek.nl/projects/hdup2/index.html">hdup2</a>
would be a good simple backup system.

Check out the <a href="http://hvo.wr.usgs.gov/cam/index.htm">HVO Live
Camera</a> of Kilauea.  Very cool!  Kilauea was just on CNN.

<a href="http://freshmeat.net/projects/gnusmalltalk/">GNU
