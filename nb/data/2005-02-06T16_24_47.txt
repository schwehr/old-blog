AUTHOR: Kurt

BODY:
In trying to find more info on pysqlite for my data import and
processing scripts, I ran into <a
href="http://thuban.intevation.org/">Thuban</a>.  This is a
Interactive Geographic Data Viewer that can read Shapefile, PostGIS,
and GeoTiff.  Looks nice and it uses wxWindows, proj, pysqlite, and optionally
GDAL.  I was unable to get the big gdal based GIS program to port to
mac osx (what was it called?), but maybe this could be ported.  It
looks like all the prerequisites are already in fink.  When I have to
next deal with one of these data types I may give it a go.

href="http://www.cbel.com/python_programming_language/?order=alpha&setcols=4">CBEL
list of python resources</a> - Nice jumping off point.
