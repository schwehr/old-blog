Attached to Wolf Berger et al (2004) is a data file of varve
thickness, TOC, and fish scales that I wanted to take a look at.  Here
how I did it.  First get the data and make it text
<pre>
  wget ftp://rock.geosociety.org/pub/reposit/2004/2004055.pdf
  pdf2text 2004055.pdf
  emacs 2004055.txt
</pre>
Use your text editor to save the varve years to one file and the varve
thicknesses to another.  It must be one value per line.  e.g. M-x
replace-string space C-q C-j.  Then use the unix paste command (thanks
Julie!) to bring the two columns together:
<pre>
  paste mm.dat year.dat > varves-mm-year.dat
</pre>
Now use this python script to convert the mm for each year into a
depth of each year:
<pre>
<font color="#444444">#!/usr/bin/env python</font>

<strong>import</strong> <font color="#2040a0">os</font>	<font color="#444444"># os.remove()</font>
<strong>import</strong> <font color="#2040a0">sys</font>	<font color="#444444"># sys.exit()</font>
<strong>import</strong> <font color="#2040a0">string</font>

<font color="#2040a0">inFile</font><font color="4444FF">=</font><font color="#2040a0">open</font><font color="4444FF">(</font><font color="#008000">&quot;varves-mm-year.dat&quot;</font><font color="4444FF">)</font>
<font color="#2040a0">depth</font><font color="4444FF">=</font><font color="#FF0000">0</font>. <font color="#444444"># cm</font>
<strong>print</strong> <font color="#008000">&quot;# depth in cm, calendar year&quot;</font>
<strong>for</strong> <font color="#2040a0">line</font> <strong>in</strong> <font color="#2040a0">inFile</font>.<font color="#2040a0">xreadlines</font><font color="4444FF">(</font><font color="4444FF">)</font><font color="4444FF">:</font>
    <font color="#2040a0">mm</font>,<font color="#2040a0">year</font><font color="4444FF">=</font><font color="#2040a0">line</font>.<font color="#2040a0">split</font><font color="4444FF">(</font><font color="4444FF">)</font>
    <font color="#2040a0">depth</font><font color="4444FF">+</font><font color="4444FF">=</font><font color="#2040a0">float</font><font color="4444FF">(</font><font color="#2040a0">mm</font><font color="4444FF">)</font>/<font color="#FF0000">10</font>.
    <strong>print</strong> <font color="#2040a0">depth</font>,<font color="#2040a0">year</font>

</pre>
Then fire up gnuplot:
<pre>
  set yrange [] reverse
  set xrange [] reverse
  set xlabel "year"
  set ylabel "depth(cm)"
  plot 'varve-depthcm-year.dat' using 2:1
</pre>
And now you have a nice graph showing the varve thickness decreases
with depth and that compaction happens.  Woowee.
