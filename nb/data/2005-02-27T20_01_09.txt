I just finished up the first draft of a "super AF demag poster"
generator.  This little python program uses pysqlite to go into my
Santa Barbara paleomag database and find all of the AF
demagnetizations that Jason and I have been doing.  It then uses
Lisa's plotdmag to make a postscript plot of each one.  Then a tangled
web of netpbm and pil (Python Imaging Library) creates a png image of
each plot.  I then use pdflib_py to layout all the plots in a 3ft x 5ft
poster form.  Tomorrow I will know if this sucker plots out okay on
the large format HP printer in the lab.

In the process, I wrote a type_pkg variant info file for pil_py so
that I could have pil_py24.  Sent that off to the package
maintainer... Jeff the super packager.  I really like the new variant
mechanism.  Makes life much easier for python in fink.

It has been a busy day!  I did just over 4 hours in the lab this
morning doing more AF demag.  Without further delay, here is the code
in all its wartiness.
