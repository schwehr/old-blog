So my 2nd python test case for the sql code from yesterday showed me
that I had a fundamental design flaw.  Dictionaries do not keep their
order.  So if I want to write test cases with a dictionary, I need to
know the dictionary order for the expected string.  I guess I could
switch over to lists of tuples, but there is nothing wrong with the
dictionary.  Is the sort order of a dictionary stable?  It makes sense
that it world be as python probably keeps the keys sorted.  On the
other hand, there is no reason that this sorted alphanumerically.  It
could be a hash function.  If it is, Guido and company could change
which has function they are using which would make my test cases very
unstable.  And now that I look at my test code results, it is not
alphanumeric forward.
