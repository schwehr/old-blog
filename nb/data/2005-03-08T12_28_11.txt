Well, I was right.  Jeff W. had a quick fix for the Python Imaging
Library (pil).  I now have a working test case for loading a true type
font.  It is a bit of a weird one since it is the first thing I ran
into.  I am trying to get as much done as possible before I talk to
Lisa and Neal tomorrow afternoon.  First, here is how I randomly found
the font I used in the example:
<pre>
  locate .ttf  | grep '\.ttf$' | less
</pre>
I used a random font from Apple's X11.  This font is not pretty, but
it works.
<pre>
<font color="#444444">#!/usr/bin/env python</font>
<strong>import</strong> <font color="#2040a0">Image</font>, <font color="#2040a0">ImageDraw</font>, <font color="#2040a0">ImageFont</font>
<font color="#2040a0">im</font> <font color="4444FF">=</font> <font color="#2040a0">Image</font>.<font color="#2040a0">new</font><font color="4444FF">(</font><font color="#008000">&quot;RGB&quot;</font>,<font color="4444FF">(</font><font color="#FF0000">400</font>,<font color="#FF0000">400</font><font color="4444FF">)</font>,<font color="#008000">&quot;white&quot;</font><font color="4444FF">)</font>
<font color="#2040a0">draw</font> <font color="4444FF">=</font> <font color="#2040a0">ImageDraw</font>.<font color="#2040a0">Draw</font><font color="4444FF">(</font><font color="#2040a0">im</font><font color="4444FF">)</font>

<font color="#2040a0">font</font> <font color="4444FF">=</font> <font color="#2040a0">ImageFont</font>.<font color="#2040a0">truetype</font><font color="4444FF">(</font><font color="#008000">&quot;/usr/X11R6/lib/X11/fonts/TTF/luxirb.ttf&quot;</font>,<font color="#FF0000">30</font><font color="4444FF">)</font>

<font color="#2040a0">draw</font>.<font color="#2040a0">text</font><font color="4444FF">(</font><font color="4444FF">(</font><font color="#FF0000">10</font>,<font color="#FF0000">100</font><font color="4444FF">)</font>,<font color="#008000">&quot;hello&quot;</font>, <font color="#2040a0">font</font><font color="4444FF">=</font><font color="#2040a0">font</font>, <font color="#2040a0">fill</font><font color="4444FF">=</font><font color="#008000">&quot;red&quot;</font><font color="4444FF">)</font>
<font color="#2040a0">im</font>.<font color="#2040a0">show</font><font color="4444FF">(</font><font color="4444FF">)</font>
</pre>
By the way, I have PIL 1.1.4-26 installed.  This will not work with older
versions of PIL from fink.
