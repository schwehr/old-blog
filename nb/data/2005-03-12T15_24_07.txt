Wow!  <a

devil on Mars!!</a>  This is really cool.  

I'm looking at ivcon again to see if it can solve some of the problems
I have been having.  The main problem is lots of autogenerated files
in OpenInventor that must make their way to Lightwave, Blender, and
Maya for visualization.  DeepExploration works, but is Windows only,
costs, and it very slow to use.  Also, models do not get an
intelligent name so people have to load each model and rename it.  Not
good!  Animators have better things to do with there time.

I got a little bit of a start in that Burkardt's web page moved since
the last time a looked.  Here it  is:
<pre>
  <a href="http://www.csit.fsu.edu/~burkardt/g_src/ivcon/ivcon.html">IVCON - 3D Graphics File Conversion</a>
</pre>
My goal is to generate quality Alias Wavefront OBJ files that can be
quickly animated into a nice scene with as little effort as possible.

I was not able to get the version on Burkardt's web page to build on
Mac OSX.  It builds fine on Linux, but it has huge static arrays on
the stack that upset the Mac OSX tool chain.  I was able to build the
version from <a
href="http://sourceforge.net/projects/ivcon/">sf.net/projects/ivcon</a>.
All it needs is to comment out the INFINITY definition in mesh.cpp and
the addition of a Makefile like this one.
