I am going back through my older data generating xpd (xcore
description files) so that I can put photos next to some of my new
measurements for TTN136B.  Here are some notes on how I am currently
making these files.  This is not the best way, but it works for now.

This is for piston core 2 from TTN136b (a.k.a. ttn136b-2p or 02PC)

I start by using the ImageMagick program <b>identify</b>.  Identify
gives the size of the image so that we can setup the coordinate frame
in the next step.
<pre>
  identify 02pcArchivesBW.jpg 
  02pcArchivesBW.jpg JPEG 1935x2874 PseudoClass 256c 1.1mb 0.420u 0:01
</pre>
I then subtract one from the width and hight.  Those go into a
Makefile entry for processing these images as the WIDTH2 and HEIGHT2
<pre>
<font color="2040a0">WIDTH2  :=</font> 1934 <font color="#444444"># 1935</font>
<font color="2040a0">HEIGHT2 :=</font> 2873 <font color="#444444"># 2874</font>
<font color="8b2252"><strong>designate-points-2</strong>:</font> 2p.pgm designate-instructions
	g3data -scroll -coords 0 <font color="2040a0">${HEIGHT2}</font> <font color="2040a0">${WIDTH2}</font> 0 <font color="4080ff">$&lt;</font> -scale 1
<font color="8b2252">
<strong>02pcArchivesBW.jpg</strong>:</font>
	wget http://schwehr.org/TTN136B/Data/CorePhotos/02pcArchivesBW.jpg
<font color="8b2252"><strong>2p.pgm</strong>:</font> 02pcArchivesBW.jpg
	convert 02pcArchivesBW.jpg 2p.pgm
<font color="8b2252"><strong>2p-gray-total.png</strong>:</font> 2p.pgm 2p.xpd
	processCore <font color="4080ff">$&lt;</font> 2p.xpd 2p-gray
	convert 2p-gray-total.pgm 2p-gray-total.png
	open -a /Applications/Adobe\ Photoshop\ CS/Adobe\ Photoshop\ CS.app 2p-gray-total.png
</pre>
The next step is to run <b>make desinate-points-2</b>.  This starts
g3data with a pre-defined coordinate frame for the image.  Go through
and click first on the top right corner of all the n*10 cm ticks
(0,10,...,140,150) for the left ruler and then the right ruler.  Make
sure to go from 0..150 in order.  Then for each section click on the
four corners starting with the bottom left and going counter
clockwise.  Leave out the empty liner or edges unless you really want
them to be a part of your core photo.

<img src="http://schwehr.org/blog/attachments/2005-04/g3data-core2.png">

Warning, try not to make too many mistakes.  Erasing points has a
tendency to crash g3data later on when saving.  I have not found time
to track down this bug.

converts them into an xpd file.  Not the most exciting program, nor is
the documentation any good, but python makes this easy to do!
