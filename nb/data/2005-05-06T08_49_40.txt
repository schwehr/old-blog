BODY:
I have been thinking about the issues with digital xrays of cores.
What we have done works pretty well, but we can always do better.
There are several goals that I have in mind for processing xrays.
<ul>
  <li>Make nice mosaics for publications
  <li>Make mosaics that best show off all of the features in the core
  <li>Be able to make quantative statements about xray density
</ul>
I haven't really figured out any of these issues to any satisfaction,
but I have lots of ideas.

This morning, I ran into a document on the web about compositing xray
images from paintings using a system called VIPS:

<a
href="http://www.vips.ecs.soton.ac.uk/vips-7.6/doc/ipdummies/x-ray/">Working
With Digital X-ray Images: Some practical image manipulation using
VIPS/ip 7."</a> by Joseph Padfield.  Some issues are the same, some
are not.  It would be great to be able to do a good job with whole
round or half round cores by correcting for both thickness and xray
emmission issues(e.g. where on the plate the pixel comes from).
