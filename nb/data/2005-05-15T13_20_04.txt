For some reason, I just decided that it is time to start adding
doctest examples into my water analysis code.  Then I discovered that
I am not really understanding how this is supposed to work.  I thought
my array slicing function would be a good starting point.  After a
step back, I have a working example of doctest.
<pre>
<font color="#444444">#!/usr/bin/env python</font>

<font color="#2040a0">def</font> <font color="#2040a0">subsetList</font> <font color="4444FF">(</font><font color="#2040a0">list</font>, <font color="#2040a0">min</font>, <font color="#2040a0">max</font><font color="4444FF">)</font><font color="4444FF">:</font>
    <font color="#008000">&quot;&quot;</font><font color="#008000">&quot;
    return a subregion of a list of (x,y) pairs based on the x range

    &gt;&gt;&gt; subsetList([(1,11),(2,22),(12,1212),(15,1515),(21,2121),(30,3030)], 10,20)
    [(12, 1212), (15, 1515)]
    &quot;</font><font color="#008000">&quot;&quot;</font>
    <font color="#2040a0">newList</font><font color="4444FF">=</font><font color="4444FF">[</font><font color="4444FF">]</font>
    <strong>for</strong> <font color="#2040a0">item</font> <strong>in</strong> <font color="#2040a0">list</font><font color="4444FF">:</font>
        <strong>if</strong> <font color="#2040a0">item</font><font color="4444FF">[</font><font color="#FF0000">0</font><font color="4444FF">]</font><font color="4444FF">&gt;</font><font color="4444FF">=</font><font color="#2040a0">min</font> <strong>and</strong> <font color="#2040a0">item</font><font color="4444FF">[</font><font color="#FF0000">0</font><font color="4444FF">]</font><font color="4444FF">&lt;</font><font color="4444FF">=</font><font color="#2040a0">max</font><font color="4444FF">:</font>
            <font color="#2040a0">newList</font>.<font color="#2040a0">append</font><font color="4444FF">(</font><font color="#2040a0">item</font><font color="4444FF">)</font>
    <strong>return</strong> <font color="#2040a0">newList</font>

<font color="#2040a0">def</font> <font color="#2040a0">_test</font><font color="4444FF">(</font><font color="4444FF">)</font><font color="4444FF">:</font>
    <strong>import</strong> <font color="#2040a0">doctest</font>, <font color="#2040a0">foo</font>

    <font color="#2040a0">_test</font><font color="4444FF">(</font><font color="4444FF">)</font>
</pre>
Which I then run by doing:
<pre>
  chmod +x foo.py
  ./foo.py -v

Trying:
    subsetList([(1,11),(2,22),(12,1212),(15,1515),(21,2121),(30,3030)], 10,20)

    [(12, 1212), (15, 1515)]
ok

    foo

</pre>
The key was to add "<b>-v</b>" after the command name to get more
output as to what is going on through the tests.
