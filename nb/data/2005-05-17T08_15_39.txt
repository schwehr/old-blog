This was my first chance to use the SQL DELETE command.  Up until now,
the only removal I needed to do was to delete the <b>entire</b>
database as I regenerate it in about 30 sections from all of the flat
file data tables.  Now my problem is that I am on a deadline and
crafting a way to compose a graph of remeasured data is a bit of a
challenge (to me at least).  I do not want to comment out the older
values from the weights table that now how new measurements, but if I
remove them from the table, I can later remove one function call from
python to nuke that remove set of calls.

So how to make the query?  Here are the schemas for the weights and
the ams tables.  I need the ams table since weights does not know
about sections, cores, and other handy stuff:
<pre>
  sqlite db ".schema weights"

  CREATE TABLE weights (id INTEGER PRIMARY KEY, samplename
  VARCHAR(40), weight REAL, timeMeasured TIMESTAMP, status
  VARCHAR(20), operator VARCHAR(20), sticker VARCHAR(15), step
  INTEGER);

  sqlite db ".schema ams"

  CREATE TABLE ams (id INTEGER PRIMARY KEY, samplename VARCHAR(40),
  user VARCHAR(40), datemeasured TIMESTAMP, cruise VARCHAR(20),
  corenum INTEGER, coretype VARCHAR(1), corehalf VARCHAR(1), section
  INTEGER, sectionoffset REAL, depth REAL,counts INTEGER, sampleholder
  REAL  ... and so forth
</pre>
The final delete query:
<pre>
  sqlite db "DELETE FROM weights WHERE weights.id IN (SELECT\
  weights.id FROM weights,ams WHERE weights.samplename=ams.samplename\
  AND corenum=3 AND section=2 AND weights.step=1);"
</pre>
