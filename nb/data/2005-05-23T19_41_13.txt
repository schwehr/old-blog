Now that I finished my poster presentation today at AGU, I wanted to
take a quick look at reading segy files with python.  I wanted to read
straigt from mmap, but did not know how.  Now I do.  I have not
started working with byte order, but here is the basics.  Byte order
can be done with <a
href="http://www.zvon.org/other/python/doc21/lib/module-socket.html">Module-socket</a>
with the htonl type functions.  Or better yet with the struct module
with the "@=&lt;&gt;"

<a href="http://seg.org/publications/tech-stand/">SEG
publications</a>: segy rev 0 and reb 1 are on this page.
<pre>
All values in the binary File Header and the Trace Header are two's
compliment integers, either two bytes or four bytes long.  There are
no floating-point values defined in the headers.

Trace Data sample values are either two's complement integers or
floating-point.  This revision adds data sample formats of 8-bit
integer and 32-bit IEEE floating-point.  Both IBM floating-point and
IEEE floating-point values are written in big-endian byte order.
</pre>
