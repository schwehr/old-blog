Python's optparse is a very nice little package!  It seems even easier
than the gengetopt package that I have been using with the C++ code in
<a href="http://schwehr.org/software/density/">density</a>.  I
addition to command line parsing, I want to be able to produce
complete documentation which includes man pages and html version of
man pages.  Here is my quick tutorial of what I have figured out so
far.  This is not much, but in 30 minutes, I got quite a bit figured
out.

First off, here is the official documentation: <a
href="http://www.python.org/doc/lib/module-optparse.html">6.21
optparse -- More powerful command line option parser</a> [python.org]

Based on that documentation, I created a quick program to test out the
module:
<pre>

OptParse produces a little dictionary of option values.  How nice!

Now that I have a quick working test program, here is how to generate
a man page and an htmlized web page.  I use help2man and man2html
which I have installed from fink on my Mac OSX laptop.  First, create
a man page with help2man.  help2man uses the --version and --help
commands to get the neccesary text.  That is why I had to have
'OptionParser(version="%prog 1.0")' in the code to set the version number.
<pre>
  help2man ./cmdlineopt.py > cmdlineopt.py.1

  cat cmdlineopt.py.1

.\" DO NOT MODIFY THIS FILE!  It was generated by help2man 1.29.

.SH NAME

Raw man files are not fun.  This is in troff/groff format.  Yeah, I
know that some professors still write papers with these tools.  Ouch.
We need to have the computer show us this next in a much more humane
format.  Groff will do that for us:
<pre>
<b>groff -Tascii -man cmdlineopt.py.1</b>

CMDLINEOPT.PY(1)                 User Commands                CMDLINEOPT.PY(1)

customize the man page.  Here is an example from density:
<pre>

Kurt Schwehr

[DESCRIPTION]

Now we can take the text and make an html man page.
<pre>
  <b>groff -Tascii -man cmdlineopt.py.1 | man2html > cmdlineopt.py.1.html</b>
  <b>open cmdlineopt.py.1.html
</pre>
