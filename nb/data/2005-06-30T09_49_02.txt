I had an idea the might help editing.  What if I have mypaper.tex.in?
In that file, I put a @PARAGRAPH_COUNT@ at the beginning of each
paragraph.  Then I write a little python script to process the .tex.in
into a .tex file with each paragraph count marker replaced with the
paragraph number?  Something like this:
<pre>
<b>foo.tex.in:</b>
@PARAGRAPH_COUNT@The first paragraph.

@PARAGRAPH_COUNT@Another paragraph yammering on.

@PARAGRAPH_COUNT@The end.

<em>numberParagraphs foo.tex.in foo.tex</em>

<b>foo.tex:</b>
[1] The first paragraph.

[2] Another paragraph yammering on.

[3] The end.
</pre>
I am sure there is a way to do this in latex/tex, but I am not going
to try to figure out how when I can just use python with
<em>line.find('@PARAGRAPH_COUNT@')</em>.  Unless someone wants to tell
me the latex solution :)
