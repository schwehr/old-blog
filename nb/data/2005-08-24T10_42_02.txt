AUTHOR: Kurt

BODY:
I got a very quick response back from folks at UTexas <a
href="http://www.ig.utexas.edu/sdc/search/index.htm">Marine Geoscience
Data Management System, Processed Seimic Data Center</a> about the Eel
W9605 data sample format issue:
<pre>
  Almost certainly it is 32 bit floating point IEEE, which was not a
  'standard' SEGY rev. 0 format back when these data were processed.
</pre>
They are looking into it further, but that is enough for me.  I may
add a command line option to force the sample type and see if the
traces look sane.  I still have not integrated code to read the IBM
floating point data that are in the other files.

<b>UPDATE:</b>
Looks like things should be good to go!  Many thanks to Lisa and Tom
at UTexas.
<pre>
  I went through the segy files for W9605B and made a list of the ones
  with Format=6.  We ran a SIOSEIS script which changed it to 5.   The
  modified files are now available through the website.  At the end of
  this e-mail is the list that I came up with. 

Cheers,
Lisa
