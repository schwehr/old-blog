From this graph it is clear that [a-zA-Z0-9 ] for EBCDIC and ASCII are
in very different ranges.

A little python trick to get the numberical value for a string
element:
<pre>python
&gt;&gt;&gt; a = "abc123"
&gt;&gt;&gt; type (a)
&lt;type 'str'&gt;
&gt;&gt;&gt; type (a[1])
&lt;type 'str'&gt;
&gt;&gt;&gt; print a[1],ord(a[1])
b 98
&gt;&gt;&gt; chr (98)
'b'
</pre>
<b>ord</b> is the trick.
