I want to be able to test for the existance of a field in a SQL table.
The segysqldump.py command can be run on any number of database files
and each one can have a different layout of fields.  For example, the
xstar driver does not have an EnsembleNo.  I want to be able to check
for the existance of say EnsembleNo and if it does not exist, then I
will not add it to the SELECT statement.  Sqlite has a sqlite_master
table that contains the CREATE command for each table.  Here is how to
check for the existance of a field.  The spaces around the field name
should prevent false matches from substrings.
<pre>

<font color="#2040a0">cu</font>.<font color="#2040a0">execute</font><font color="4444FF">(</font><font color="#008000">'select sql from sqlite_master where name = &quot;segyTrace&quot;'</font><font color="4444FF">)</font>
<strong>for</strong> <font color="#2040a0">row</font> <strong>in</strong> <font color="#2040a0">cu</font>.<font color="#2040a0">fetchall</font><font color="4444FF">(</font><font color="4444FF">)</font><font color="4444FF">:</font>
