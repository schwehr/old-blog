<b>Coin 2.4.4 Released</b>
<pre>
Systems in Motion is proud to release v2.4.4 of the Coin 3D graphics
library.  Coin 2.4.4 is a patchlevel release.  Patchlevel releases
contain mostly bugfixes, optimizations, documentation improvements,
and configure and build setup fixes.  This release does not extend the
library API beyond the previous release.
</pre>
<em>NEWS File Excerpt for 2.4.4:</em><br>
improvements and optimizations:
<ul>
  <li> further improvements to SoOffscreenRenderer performance
  <li> SoRayPickAction precision improvements
  <li> Visual Studio project now installs only selected build (including
    static configurations now)
  <li> misc minor details, build fixes, documentation updates
</ul>
bugfixes:
<ul>
  <li> SoSurroundScale bugfix
  <li> hidden field enableTextureCompression access crashbug fix
  <li> misc minor robustness fixes
<ul>
