<pre>
SoQt 1.3.0 is a minor release.  The release contains build setup
improvements, bugfixes, and documentation improvements.  It also
contains some minor API extensions beyond the previous release.
</pre>
<ul>
<li> install SoGuiMaterialEditor.h
<li> SoQtGLWidget::setStealFocus()/isStealFocus()
<li> support for Mac OS 10.4 "Tiger"
<li> complete Visual Studio project file setup under build/
<li> misc minor fixes
</ul>
