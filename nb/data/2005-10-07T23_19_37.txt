That does it.  I am switching to matplotlib for my graphing.  There
are just so many things that it has which are not really possible with
the python gnuplot.
<ul>
<li> Loading images into the plot.  <a href=http://matplotlib.sourceforge.net/matplotlib.image.html">matplotlib.image</a> and the Hubble Telescope image demo.
<li> Pie charts
<li> blending
<li> Better multiplot support (subplots)
<li> Mapping suport
<li> TeX style symbols and equations
<li> Detecting mouse clicks and key hits
<li> The demo images are prettier than those in the gnuplot demo directory
</ul>
What is it missing that gnuplot does have?  matplotlib seems to only
focus on png.  I did not see anything that talked about pdf or ps
output.  I hope it's there and I just did not see it.  I know gnuplot
pretty well and have not done matlab plotting since 2001.
