Hmmm... <a href="http://www.oreillynet.com/pub/wlg/7627">Journaling</a> by 
Steven Douglas Olson on the Orielly Blogs.  He talks about keeping a
paper journal while you work.  I keep a couple different ones at this
point and go back and forth all the time.
<ul>
<li> <b>paper based</b> - I have a hard bound, no lines drawing book as my
paper based note book.  It is easy to sketch in.  I add a table of
contents to the front and it is really easy to flip through.
Sometimes I scan in the log book when it is really important like
being used as <a
href="http://schwehr.org/Gaviota/bpsio-Aug04/bpsio-log/index.htm">a
cruise log</a> (Warning... that was my first attempt at a photoshop
built web page and it sucks)
<li> <b>blog based</b> - This is where I try to write in a style where
anyone (well, almost) can see what I am doing and is hopefully does
using half-way passable English.  Indexed by Google, grepped by me.
This is even more valuable (to me) now that I include images when
relevant.
<li> <b>text file</b> - My true garbage can of notes.  I have one file
per year and paste in whatever junk I want.  This is not released to
the world so it gets little if any actual writing, but lots of command
lines and web links.  Grep, grep, grep...
<li> <b>readme's...</b> - Many of my sub-projects have readme type
files where very specific information goes. Sometimes this is good,
other times it feels like it is diluting the power of my "one big
textfile".  Too many places to grep.
<li> <b>revision control logs</b> - I try to always write good logs,
but it is rare that I go back to them.  I need to start using some
better tools!  This is mostly to keep myself ready to work in groups
again where reading the cvs/svn logs is a regular occurrence.  Maybe I
need a bridge to a news feed of log entries.  That would be great! (or
could really be annoying)
<li> <b>wiki's</b> - (Aurelio's fav)  I think I have make 3 total entries in wiki's in my entire life.  They sound good, but I think I like the other methods more, at least for now...
</ul>
