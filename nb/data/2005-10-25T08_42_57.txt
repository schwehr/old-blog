This is fantastic news!!!!   Doxygen now supports python.  Thanks to
Dennis Benzinger for pointing this out to me.

<a href="http://www.stack.nl/~dimitri/doxygen/features.html">Doxygen
features</a> now lists python as the second bullet.

Dennis pointed me to the <a
href="http://www.stack.nl/~dimitri/doxygen/formulas.html">doxygen
formulas</a> page.  The best part is that it uses LaTeX (well that is
great for Lisa and I), so I don't have to learn MathML right now.

<a href="http://www.stack.nl/~dimitri/doxygen/docblocks.html#pythonblocks">Directions on doxygen for python</a>

There is also <a
href="http://i31www.ira.uka.de/~baas/pydoxy/">pyfilt</a> that mushes
python code with doxygen tags into a C file that doxygen can use for
documentation.
