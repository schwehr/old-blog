<a href="http://news.com.com/Oracle+to+offer+free+database/2100-1012_3-5920796.html?part=rss&tag=5920796&subj=news">Oracle to offer free database</a>
<pre>
  The database heavyweight on Tuesday is expected to announce the beta
  release of Oracle 10g Express Edition (Oracle Database XE), which
  will be generally available by the end of the year. It is targeted
  at students, small organizations and software vendors that could
  embed the Oracle database with an application. 

  The latest edition is the same as other databases in Oracle's lineup
  but is limited in usage. It can only run servers with one processor,
  with 4GB of disk memory and 1GB of memory. 
</pre>
