US Army Corps of Engineers has a <a href="http://www.tec.army.mil/td/tvd/survey/vendors_web_alpha.html">Commercial Terrain Visualization Software Product Info Page</a>

If you are building a graphics application, there are a lot of
different APIs and systems to base your work on.  Here are some of
them in no particular order and does not include raytraced systems.
Back in the day SGI owned the world with 5 tiers of libraries:
<ol>
<li>OpenGL and ImageVision - basic 3D graphics and image display
<li>OpenInventor - a really nice scene graph API that made graphics software much easier to write
<li>Performer - for the maximum graphics performance with multiple CPUs and pipes.  Not that much fun to program, but fast.
<li>Explorer - Visual programming for graphics.  Drop in a few widgets and add some wires to get instant visualization.
<li>Volumizer for volumetric data
</ol>
They then followed up with Cosmo and VRML and managed to sell off or
distance themselves from everything that I thought was really awesome
about SGI in terms of graphics.  I was one of those diehard SGI/IRIX
fans until 2000.  Now the field is a confusing set of options, where I
am never sure what the right choice is.
<ul>
<li> <a href="http://www.sgi.com/products/software/opengl/">OpenGL</a>
<li> <a href="http://msdn.microsoft.com/msdnmag/issues/03/07/DirectX90/">Direct3D/DirectX</a>
<li> <a href="http://oss.sgi.com/projects/inventor/">SGI Open Inventor 2.1</a> (err... use Coin3D or TGS Inventor instead).  This is essentially the parent to VRML.
<li> <a href="http://www.sim.no/products/Coin3D/">Coin3D</a> by SIM.  Compatible with SGI's Open Inventor 2.1 API.
<li> <a href="http://www.tgs.com/">TGS OpenInventor</a> - a.k.a. Mercury OpenInventor.
<li> SGI <a href="http://www.sgi.com/products/software/performer/">Performer</a>
<li> What happened to Sense8 who made WorldToolKit (WTK) and World2World?
<li> <a href="http://www.vterrain.org/">VTP</a> Virtual Terrain Project.  Have to Request the Code.
<li> <a href="http://public.kitware.com/VTK/">VTK</a>
<li> <a href="http://www.openscenegraph.org/">OpenSceneGraph</a>
<li> <a href="http://www.openvrml.org/">OpenVRML</a>
<li> <a href="http://www.web3d.org/">X3D</a> aka web3d is supposed to be the follow on to VRML.
<li> <a href="https://java3d.dev.java.net/">Java3D</a>
<li> <a href="http://www.nag.com/Welcome_IEC.asp">IRIS Explorer</a> which SGI sold to NAG
<li> <a href="http://www.opendx.org/">OpenDX</a> is much like IRIS Explorer
</ul>
With that list, I have left out tons of quality software.  If anyone
knows what is up with Sense8, please let me know.  Also, I thought
OpenSceneGraph was in Fink, but I can't find it.  Strange. 

There are many ways to extend the basic graphics libraries with more
dynamic languages.  One of my favorite languages is python, but there
are many others :)
<ul>
<li> <a href="http://pivy.tammura.at/">Pivy</a> - Python bindings for Coin3d.
<li> <a href="http://sourceforge.net/projects/ivupy">IVuPy</a> - Another python binding for Coin3d (Thanks Harry!).
<li> <a href="http://togl.sourceforge.net/">Togl</a> - Tk OpenGL widget.  This one is used by GeoZui4D.
<li> and about 50 more...
</ul>
I tried to get Pivy going on the Mac about a year ago, but Pivy
requires a much newer swig than is in fink.  I am hoping to give the
python/coin3d on the mac thing another go soon.

One last thing: Don't forget about things like Blender3D, povray,
bluemoon, etc.  This is a whole set of tools that are important (and
that I want to explore more).
