Here is a nice example python module that illustrates 4 imporant
concepts.
<ol>
<li> Using <b>doctest</b> is really easy.  Lines 15-18 and 32-38 define some
examples that doctest will validate.  The python code starts with
&gt;&gt;&gt; and is followed by the expected output from that
command.  At the end of the program (lines 59-60), doctest is called.
It will scan through the whole module and validate every doctest
formatted example.
<li> Using <b>unittest</b> is a little bit more work,  Lines 48-55 are
a basic unittest setup.  This can be done much fancier with setup and
teardown methods before and after groups of tests and much more.
<li>On a different note, this module handles NMEA 0183
checksum calculation and validation for AIS and GPS strings.  Not very
exciting, but it provides an example and shows how the string is
XOR'ed (^ in python) together.
<li>Finally, I used "pydoc -w nmeaChecksum.html" to produce the <a
href="http://schwehr.org/blog/attachments/2006-03/nmeaChecksum.html">nmeaChecksum
web documentation</a>.  I still need to give epydoc a try, as it looks
more like doxygen.  Pydoc is not all that powerful.
</ol>
