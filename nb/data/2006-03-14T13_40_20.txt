I just added <a
href="http://rvl4.ecn.purdue.edu/~kak/dist/BitVector-1.2.html">BitVector
1.2</a> to fink 10.4-transitional/unstable.  This is a nice package
for bit twiddling written by <a
href="http://rvl4.ecn.purdue.edu/~kak/">Avi Kak</a> at Purdue.

This package makes working with bit level data much easier than it
ever was in C or C++.  STL in C++ has trouble with bit vectors and the
C bit operators are not the most fun.  BitVector has the muscle to
make the job much more understandable. 
<pre>
python
from BitVector import BitVector
bv = BitVector(bitlist = [ 0,0,1,0]); print bv
  0010
print bv[-2]
  1
b2=BitVector(intVal=2);print b2
  10
</pre>
