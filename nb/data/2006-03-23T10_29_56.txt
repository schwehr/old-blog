Nathan has setup 3 more public subversion projects for me.  
<ul>
<li><a href="https://cowfish.unh.edu/projects/seismic-py/">https://cowfish.unh.edu/projects/seismic-py/</a>

seismic-py represents a name change from segy-py to avoid a name clash
(yes, I did have segy-py public first).  No point in confusing people.
I need to do freshmeat and cheeseshop (aka pypi) announcements this
week.

xsonar is my protoized update to the USGS xsoanr sidescan.  That means
I converted K&amp;R function prototypes to modern ANSI-C prototypes.

terrain is the same old terrain that tries to convert height field
grids between a number of different formats (gmt grids, lightwave,
Alias obj, OpenInventor, PDS, Vicar).  Lightwave is a pretty crazy
format, so my support for it has a lot of troubles.
