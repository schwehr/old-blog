This not the most clever implementation of twos complement signed
integer decoding, but it seems to work.  I am putting this here since
Avi is holding off on additional functionality in BitVector until the
end of his semester.  He did fix the bitvec[-1]=0 reverse accessor bug
today, so the code below could be even simpler.
<pre>
<font color="#FF8800">#!/usr/bin/env python</font>
<strong>from</strong> <font color="#2040a0">BitVector</font> <strong>import</strong> <font color="#2040a0">BitVector</font>

<font color="#2040a0">def</font> <font color="#2040a0">setBitVectorSize</font><font color="4444FF">(</font><font color="#2040a0">bv</font>,<font color="#2040a0">size</font><font color="4444FF">=</font><font color="#FF0000">8</font><font color="4444FF">)</font><font color="4444FF">:</font>
    <font color="#008000">&quot;&quot;</font><font color="#008000">&quot;Pad a BitVector with 0's on the left until it is at least the size specified

    @param bv: BitVector that needs to meet a minimim size
    @type bv: BitVector
    @param size: Minimum number of bits to make the new BitVector
    @type size: int
    @return: BitVector that is size bits or larger
    @rtype: BitVector

    @todo: What to do if the vector is larger than size?
    &quot;</font><font color="#008000">&quot;&quot;</font>
    <font color="#2040a0">pad</font><font color="4444FF">=</font><font color="#2040a0">BitVector</font><font color="4444FF">(</font><font color="#2040a0">bitlist</font><font color="4444FF">=</font><font color="4444FF">[</font><font color="#FF0000">0</font><font color="4444FF">]</font><font color="4444FF">)</font>
    <strong>while</strong> <font color="#2040a0">len</font><font color="4444FF">(</font><font color="#2040a0">bv</font><font color="4444FF">)</font><font color="4444FF">&lt;</font><font color="#2040a0">size</font><font color="4444FF">:</font> <font color="#2040a0">bv</font> <font color="4444FF">=</font> <font color="#2040a0">pad</font> <font color="4444FF">+</font> <font color="#2040a0">bv</font>
    <strong>return</strong> <font color="#2040a0">bv</font>

<font color="#2040a0">def</font> <font color="#2040a0">addone</font><font color="4444FF">(</font><font color="#2040a0">bv</font><font color="4444FF">)</font><font color="4444FF">:</font>
    <font color="#008000">''</font><font color="#008000">'
    Add one bit to a bit vector.  Overflows are silently dropped.
    &gt;&gt;&gt; print addone(BitVector(bitstring='</font><font color="#FF0000">1100</font><font color="#008000">'))
    1101
    &gt;&gt;&gt; print addone(BitVector(bitstring='</font><font color="#FF0000">1111</font><font color="#008000">'))
    0000

    @param bv: Add one to these bits
    @type bv: BitVector
    @return: Bits with one added
    @rtype: BitVector
    '</font><font color="#008000">''</font>
    <font color="#2040a0">new</font> <font color="4444FF">=</font> <font color="#2040a0">bv</font>
    <font color="#2040a0">r</font> <font color="4444FF">=</font> <font color="#2040a0">range</font><font color="4444FF">(</font><font color="#FF0000">1</font>,<font color="#2040a0">len</font><font color="4444FF">(</font><font color="#2040a0">bv</font><font color="4444FF">)</font><font color="4444FF">+</font><font color="#FF0000">1</font><font color="4444FF">)</font>
    <strong>for</strong> <font color="#2040a0">i</font> <strong>in</strong> <font color="#2040a0">r</font><font color="4444FF">:</font>
	<font color="#2040a0">index</font> <font color="4444FF">=</font> <font color="#2040a0">len</font><font color="4444FF">(</font><font color="#2040a0">bv</font><font color="4444FF">)</font><font color="4444FF">-</font><font color="#2040a0">i</font>
	<strong>if</strong> <font color="#FF0000">0</font><font color="4444FF">=</font><font color="4444FF">=</font><font color="#2040a0">bv</font><font color="4444FF">[</font><font color="#2040a0">index</font><font color="4444FF">]</font><font color="4444FF">:</font>
	    <font color="#2040a0">new</font><font color="4444FF">[</font><font color="#2040a0">index</font><font color="4444FF">]</font><font color="4444FF">=</font><font color="#FF0000">1</font>
	    <strong>break</strong>
	<font color="#2040a0">new</font><font color="4444FF">[</font><font color="#2040a0">index</font><font color="4444FF">]</font><font color="4444FF">=</font><font color="#FF0000">0</font>
    <strong>return</strong> <font color="#2040a0">new</font>

<font color="#2040a0">def</font> <font color="#2040a0">subone</font><font color="4444FF">(</font><font color="#2040a0">bv</font><font color="4444FF">)</font><font color="4444FF">:</font>
    <font color="#008000">''</font><font color="#008000">'
    Subtract one bit from a bit vector

    &gt;&gt;&gt; print subone(BitVector(bitstring='</font><font color="#FF0000">1111</font><font color="#008000">'))
    1110
    &gt;&gt;&gt; print subone(BitVector(bitstring='</font><font color="#FF0000">0010</font><font color="#008000">'))
    0001
    &gt;&gt;&gt; print subone(BitVector(bitstring='</font><font color="#FF0000">0000</font><font color="#008000">'))
    1111

    @param bv: Bits to add one bit to the right side
    @type bv: BitVector
    @rtype: BitVector
    '</font><font color="#008000">''</font>
    <font color="#2040a0">new</font> <font color="4444FF">=</font> <font color="#2040a0">bv</font>
    <font color="#2040a0">r</font> <font color="4444FF">=</font> <font color="#2040a0">range</font><font color="4444FF">(</font><font color="#FF0000">1</font>,<font color="#2040a0">len</font><font color="4444FF">(</font><font color="#2040a0">bv</font><font color="4444FF">)</font><font color="4444FF">+</font><font color="#FF0000">1</font><font color="4444FF">)</font>
    <strong>for</strong> <font color="#2040a0">i</font> <strong>in</strong> <font color="#2040a0">r</font><font color="4444FF">:</font>
	<font color="#2040a0">index</font> <font color="4444FF">=</font> <font color="#2040a0">len</font><font color="4444FF">(</font><font color="#2040a0">bv</font><font color="4444FF">)</font><font color="4444FF">-</font><font color="#2040a0">i</font>
	<strong>if</strong> <font color="#FF0000">1</font><font color="4444FF">=</font><font color="4444FF">=</font><font color="#2040a0">bv</font><font color="4444FF">[</font><font color="#2040a0">index</font><font color="4444FF">]</font><font color="4444FF">:</font>
	    <font color="#2040a0">new</font><font color="4444FF">[</font><font color="#2040a0">index</font><font color="4444FF">]</font><font color="4444FF">=</font><font color="#FF0000">0</font>
	    <strong>break</strong>
	<font color="#2040a0">new</font><font color="4444FF">[</font><font color="#2040a0">index</font><font color="4444FF">]</font><font color="4444FF">=</font><font color="#FF0000">1</font>
    <strong>return</strong> <font color="#2040a0">new</font>

<font color="#2040a0">def</font> <font color="#2040a0">bvFromSignedInt</font><font color="4444FF">(</font><font color="#2040a0">intVal</font>,<font color="#2040a0">bitSize</font><font color="4444FF">=</font><font color="#2040a0">None</font><font color="4444FF">)</font><font color="4444FF">:</font>
    <font color="#008000">''</font><font color="#008000">'
    Create a twos complement BitVector from a signed integer.

    Positives must have a '</font><font color="#FF0000">0</font><font color="#008000">' in the left hand position.

    &gt;&gt;&gt; print bvFromSignedInt(0,bitSize=4)
    0000
    &gt;&gt;&gt; print bvFromSignedInt(1,bitSize=4)
    0001
    &gt;&gt;&gt; print bvFromSignedInt(7,bitSize=4)
    0111

    Negative numbers must have a '</font><font color="#FF0000">1</font><font color="#008000">' in the left hand position.

    &gt;&gt;&gt; print bvFromSignedInt(-1,bitSize=4)
    1111
    &gt;&gt;&gt; print bvFromSignedInt(-2,bitSize=4)
    1110
    &gt;&gt;&gt; print bvFromSignedInt(-7,bitSize=4)
    1001

    @param bv: Bits to subtract one bit from the right side
    @type bv: BitVector
    @rtype: BitVector
    '</font><font color="#008000">''</font>
    <font color="#2040a0">bv</font> <font color="4444FF">=</font> <font color="#2040a0">setBitVectorSize</font><font color="4444FF">(</font><font color="#2040a0">BitVector</font><font color="4444FF">(</font><font color="#2040a0">intVal</font><font color="4444FF">=</font><font color="#2040a0">abs</font><font color="4444FF">(</font><font color="#2040a0">intVal</font><font color="4444FF">)</font><font color="4444FF">)</font>,<font color="#2040a0">bitSize</font><font color="4444FF">-</font><font color="#FF0000">1</font><font color="4444FF">)</font>
    <strong>assert</strong><font color="4444FF">(</font><font color="#2040a0">bitSize</font><font color="4444FF">-</font><font color="#FF0000">1</font><font color="4444FF">=</font><font color="4444FF">=</font><font color="#2040a0">len</font><font color="4444FF">(</font><font color="#2040a0">bv</font><font color="4444FF">)</font><font color="4444FF">)</font> <font color="#FF8800"># FIX: what to do about overflow beyond bitSize?</font>
    <strong>if</strong> <font color="#2040a0">intVal</font><font color="4444FF">&gt;</font><font color="4444FF">=</font><font color="#FF0000">0</font><font color="4444FF">:</font>
	<font color="#2040a0">bv</font> <font color="4444FF">=</font> <font color="#2040a0">BitVector</font><font color="4444FF">(</font><font color="#2040a0">intVal</font><font color="4444FF">=</font><font color="#FF0000">0</font><font color="4444FF">)</font> <font color="4444FF">+</font> <font color="#2040a0">bv</font>
    <strong>else</strong><font color="4444FF">:</font>
	<font color="#2040a0">bv</font> <font color="4444FF">=</font> <font color="#2040a0">subone</font><font color="4444FF">(</font><font color="#2040a0">bv</font><font color="4444FF">)</font>
	<font color="#2040a0">bv</font> <font color="4444FF">=</font> ~<font color="#2040a0">bv</font>
	<font color="#2040a0">bv</font> <font color="4444FF">=</font> <font color="#2040a0">BitVector</font><font color="4444FF">(</font><font color="#2040a0">intVal</font><font color="4444FF">=</font><font color="#FF0000">1</font><font color="4444FF">)</font> <font color="4444FF">+</font> <font color="#2040a0">bv</font>
    <strong>return</strong> <font color="#2040a0">bv</font>
    
<font color="#2040a0">def</font> <font color="#2040a0">signedIntFromBV</font><font color="4444FF">(</font><font color="#2040a0">bv</font><font color="4444FF">)</font><font color="4444FF">:</font>
    <font color="#008000">''</font><font color="#008000">'
    Interpret a bit vector as an signed integer.  int(BitVector)
    defaults to treating the bits as an unsigned int.  Assumes twos
    complement representation.

    U{http://en.wikipedia.org/wiki/Twos_complement}

    Positive values decode like so:

    &gt;&gt;&gt; signedIntFromBV(BitVector(bitstring='</font><font color="#FF0000">0000</font><font color="#008000">'))
    0
    &gt;&gt;&gt; signedIntFromBV(BitVector(bitstring='</font><font color="#FF0000">0101</font><font color="#008000">'))
    5

    Here are some negative integer examples:

    &gt;&gt;&gt; signedIntFromBV(BitVector(bitstring='</font><font color="#FF0000">1111</font><font color="#008000">'))
    -1
    &gt;&gt;&gt; signedIntFromBV(BitVector(bitstring='</font><font color="#FF0000">1110</font><font color="#008000">'))
    -2
    &gt;&gt;&gt; signedIntFromBV(BitVector(bitstring='</font><font color="#FF0000">1010</font><font color="#008000">'))
    -6
    &gt;&gt;&gt; signedIntFromBV(BitVector(bitstring='</font><font color="#FF0000">1001</font><font color="#008000">'))
    -7

    @param bv: Bits to treat as an signed int
    @type bv: BitVector
    @return: Signed integer
    @rtype: int

    @note: Does not know the difference between byte orders.
    '</font><font color="#008000">''</font>
    <strong>if</strong> <font color="#FF0000">0</font><font color="4444FF">=</font><font color="4444FF">=</font><font color="#2040a0">bv</font><font color="4444FF">[</font><font color="#FF0000">0</font><font color="4444FF">]</font><font color="4444FF">:</font> <strong>return</strong> <font color="#2040a0">int</font><font color="4444FF">(</font><font color="#2040a0">bv</font><font color="4444FF">)</font>
    <font color="#FF8800"># Nope, so it is negative</font>
    <strong>return</strong> <font color="4444FF">-</font><font color="4444FF">(</font><font color="#2040a0">int</font><font color="4444FF">(</font><font color="#2040a0">addone</font><font color="4444FF">(</font>~<font color="4444FF">(</font><font color="#2040a0">bv</font><font color="4444FF">[</font><font color="#FF0000">1</font><font color="4444FF">:</font><font color="4444FF">]</font><font color="4444FF">)</font><font color="4444FF">)</font><font color="4444FF">)</font><font color="4444FF">)</font>
