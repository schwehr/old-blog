To play with setuptools, I has to do a little extra work.  I
downloaded the zip from the cheeseshop and did this.
<pre>
cd ~/Desktop
mkdir setuptools && cd setuptools
wget http://cheeseshop.python.org/packages/source/s/setuptools/setuptools-0.6a10.zip

mkdir -p /Users/schwehr/Desktop/setuptools/sw/lib/python2.4/site-packages

PYTHONPATH=/Users/schwehr/Desktop/setuptools/sw/lib/python2.4/site-packages/ \
 python setup.py install --root=/Users/schwehr/Desktop/setuptools/
</pre>
If I did not put the target site-packages location in PYTHONPATH it failed to install.
