I just got the xsv command line program properly built and it now
"works for me."  You will need ltxml.info, pyltxml-py.info, and
xsv-py.info from <a
href="http://schwehr.org/software/fink">http://schwehr.org/software/fink</a>
<pre>
  fink install ltxml pyltxml-py24 xsv-py24
  wget http://www.xml.com/2000/11/29/schemas/library1.xsd
  xsv library1.xsd
</pre>
