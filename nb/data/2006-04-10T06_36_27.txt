I have yet to see a good discussion as to which Schema language is the
best.  I wrote my first (and only so far) schema in XML Schema.  The
RELAX NG ("relaxing") home page is <a
href="http://relaxng.org/">http://relaxng.org/</a>

The list of software tools on that site is intriguing.  Sun has <a
href="http://www.sun.com/software/xml/developers/relaxngconverter/">relaxngconverter</a>
to convert from other schema languages to RELAX NG.  libxml2 is
supposed to know about Relax NG and there is the <a
href="http://www.thaiopensource.com/relaxng/jing.html">Jing</a>
validator.  Finally, <a
href="http://www.xmloperator.net/i2s/">isntancetoschema</a> (i2s)
makes Relax NG schemas from XML documents.  That would have been great
for my first project!  Is there something like that for XML Schema?

And finally, the main reason I should pay attention to Relax NG is
that there is a schema for XML Schema... <a
href="http://www.jenitennison.com/schema/xmlschema.rng">xmlsschema.rng</a>

Now how do I use libxml2 to validate my schema with a schema?  Ah,
finally found <a
href="http://www.w3.org/TR/2001/REC-xmlschema-1-20010502/#normative-schemaSchema">http://www.w3.org/TR/2001/REC-xmlschema-1-20010502/#normative-schemaSchema</a>
which is the schema for XML schemas.  Doh!  Where exactly is
datatypes.xsd that is required for the normative schema?
