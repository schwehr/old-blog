I am working on what happens with trac when the pysqlite2 db driver is
added after initial startup.  Here is my setup on Mac OSX 10.4.x:
<pre>
cd ~/Desktop
mkdir trac
cd trac
mkdir svnroot
cd svnroot
svnadmin create `pwd`
cd ..
trac-admin ${HOME}/Desktop/trac/tracfoo initenv
  Defaults for all except:
  Path to repository &gt; YOURHOMEDIR/Desktop/trac/svnroot
tracd --port 8000 /Users/schwehr/Desktop/trac/tracfoo
open http://localhost:8000/tracfoo
</pre>
Now to install the pysqlite driver:
<pre>
fink install pysqlite2-py24
  
tracd --port 8000 /Users/schwehr/Desktop/trac/tracfoo &

open http://localhost:8000/tracfoo

Available Projects
    * tracfoo: Error
      (file is encrypted or is not a database) 
</pre>
