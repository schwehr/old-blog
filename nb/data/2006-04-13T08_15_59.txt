Today's python problem is comparing values pulled out of XML fields.
I pull out a field and run a translator on it which gives me a float,
Decimal, integer, or string.  Then I pull from another location a
value that I want to compare to the translated value.  The trouble is
that this second value is always encoded in a string.  I want to do
the comparison with a minimum of hassle, so I want to coerce the
second value to the type of the first.  Confused yet?  Here is the
python code that states the problem and shows the solution.
