I just realized (am I am sure this is documented) that within a doc
string, that doctest chain beyond just the current group.  I thought
before (which was not correct) that everything was reset after the
first result.  This makes my life easier for setting up more
complicated examples.  I was worried that I would have to keep
generating longer and longer blocks.  For example, these work:
<pre>
    '''
    Some silly math
    >>> a = 1
    >>> print a
    1
    >>> print a+1
    2

    And...

    >>> print a+2
    3
    '''
</pre>
Here is my current template file for a module.  Note that this is a
work in progress!  Being that these are just templates and they need
to be improved, I give permission for folks to use these how ever they
see fit.

  chmod +x mynewfile.py
  svn add mynewfile.py
  svn propedit svn:keywords mynewfile.py
     Revision
     Date
  svn commit mynewfile.py
