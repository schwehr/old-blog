The GNU makefile to go with it for mac osx with fink
10.4-transitional.  The c++ compiler must match what was used to build
CppUnit, so if you are using the 10.4 fink tree, chage g++-3.3 to just
g++.
<pre>
CXX:=g++-3.3
CXXFLAGS:=-I/sw/include 
LDFLAGS:=-lcppunit -L/sw/lib

dirtsimple:
</pre>
Then build and run it:
<pre>
$ make
g++-3.3 -I/sw/include   -lcppunit -L/sw/lib  dirtsimple.C   -o dirtsimple

$ ./dirtsimple 
...

OK (3 tests)
</pre>
