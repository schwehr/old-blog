That is not the simplest example possible.  You can ignore the "ok" stuff.  I just pulled this main from a file with my funky test code.
I use the slogcxx library, but you can replace slog with cout and it
should work just fine.  To build it on my Mac, here is the command:
<pre>
g++ map.C -o map -Wall -Wimplicit -pedantic -W \
  -Wredundant-decls -I/sw/include -L/sw/lib  \
  -g3 -O0 -D_GLIBCXX_DEBUG -lslogcxx
</pre>
