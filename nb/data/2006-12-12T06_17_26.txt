The bug occurs when I try to make BitVectors of very large integers
(greater than int(2**31-1) ... 2147483647).  BitVector would throw an
exception.

The problem stems from the hex function as Avi found.  The case of
A..F is different between integers less than 2**31.  Lower below and
upper above in python 2.4:
<pre>
ipython2.4
In [1]:  print hex(300000000)
0x11e1a300
In [2]:  print hex(3000000000)
0xB2D05E00L
</pre>
When I try python 2.5, I see different behavior (which I think is more
correct):
<pre>
ipython2.5
In [1]: print hex(300000000)
0x11e1a300
In [2]: print hex(3000000000)
0xb2d05e00L
</pre>
