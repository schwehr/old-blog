DESC: Messages split across channels?
-----
BODY:
I'm working on a simpler AIS normalization program that takes a feed
from multiple receivers and makes sure that each AIS message is
represented by just a one line NMEA string.  My code freaked out on
this pair.
<pre>
!AIVDM,2,1,6,B,58153K02=PAQKLQ3J20uHE9&lt;D5&gt;058T4@l5:221ABPR,0*4F,s32065,d-085,r00370003,1169771540
!AIVDM,2,2,6,A,N`5Ve0I1m@F@C@@0000000000000,2*2A,s25906,d-106,r00370003,1169771540
</pre>
Note that the first part is marked as coming on channel B whereas the
2nd nmea string is on channel A.  If this is true, that is bad news
for folks out there with one channel receivers.  Very strange.
