Here are some quick notes to help people decode AIS messages.  Thanks
to Lam Lap for prompting me to write this quick message.  We
definitely need libraries for a range of languages.  First we need an
AIS message to use as a test case.
<pre>!AIVDM,1,1,,A,34QiN:1001GWS7LBd1lt3GD20000,0*58,rb03660465,1171825441</pre>
Now use my noaadata/ais scripts to decode the message.

In the ais directory, let's do a little from the ipython shell
<pre>
In [1]: msg='34QiN:1001GWS7LBd1lt3GD20000'
In [2]: import binary
</pre>
The first character is the AIS message number.  Here it is 3 (which is
a position message.
<pre>
In [3]: bv = binary.ais6tobitvec('3')
In [4]: print bv
000011
In [5]: print int(bv)
3
</pre>
One positive feature of the AIS NMEA encoding scheme is that the first
character completely describes the message number and messages 1-9 are
completely human readable.  From 10 on, the coding is not as easy to 
remember.
<pre> 
In [6]: bv = binary.ais6tobitvec('D')
In [7]: print bv
010100
In [8]: print int(bv)
20
</pre>
I use a python dictionary (aka hash table) to lookup the associated values.
<pre>

And back to the original message, here are the bits
<pre>
In [11]: bv = binary.ais6tobitvec(msg)
In [12]: print bv
000011000100100001110001011110001010000001000000000000000001010111100111100011000111011100010010101100000001110100111100000011010111010100000010000000000000000000000000
</pre>
From which, we can slice off the first 6 bits to get the message number.
<pre>
In [13]: print bv[0:6]
000011
In [14]: print int(bv[0:6])
3
</pre>
