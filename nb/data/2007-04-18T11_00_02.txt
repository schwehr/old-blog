Thanks to Val, I went and looked up how to convert from seconds since
the Epoch in UTC to date/time.  Here is what I did:
<pre>
set xdata time
set format x "%d-%b-%Y"
set timefmt "%s"
plot 'temp.dat' using 1:2 with l, 'waterlevel.dat' using 1:2 with l
</pre>
