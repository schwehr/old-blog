<a href="https://networkx.lanl.gov/wiki">networkX</a> is potentially a
very useful python package for some of the research problems that many of us
here have been thinking about.

Features:
<ul>
        <li> Allows for 1M+ nodes, 10M+ edges</li>
        <li> Includes standard graph-theoretic and statistical physics functions</li>
        <li> Easy exchange of network algorithms between applications, disciplines, and platforms</li>
        <li> Includes many classic graphs and synthetic networks</li>
        <li> Nodes and edges can be "anything" (e.g. time-series, text, images, XML records)</li>
        <li> Exploits existing code from high-quality legacy software in C, C++, Fortran, etc.</li>
        <li> Open source (encourages community input)</li>
        <li> Unit-tested</li>
</ul>
