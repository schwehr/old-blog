I am close to having serial_logger.py working as a daemon on remoting
linux boxes (ubuntu).  It needs to be able to start itself on reboot
and respond to stop/restart requests.  Here is my initial ugly script that
is now in /etc/init.d.  I need to fix serial_logger.py to have an option
to act like a daemon (fork to the background) and to catch a shutdown
signal so that it writes the shutdown into the log file.  Always more work
to do!

The <b>start-stop-daemon</b> program is a nice addition to linux that
I have not used before.  If only my program behaved better so that it
played nicely with this handler.  I have not put in the links into
/etc/rc?.d for the start script, but when I have the serial logger
setup correctly in daemon mode, I will do that.
