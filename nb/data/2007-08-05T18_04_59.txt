Then the gnuplot commands:
<pre>
  set term x11
  set dgrid3d 5,5,1
  splot '4-grid.dat' with l, '4.dat'
  set ticslevel 0.5
  set view 60,30
  set autoscale
  set parametric
  set style data points
  splot '4.dat'
  set style data lines
  splot '4.dat'
</pre>
