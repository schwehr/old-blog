TITLE: Upgrading PostGIS to 1.3.1 on fink
AUTHOR: Kurt
DATE: 09.30.2007 10:27
DESC: success?
-----
BODY:
I finally figured out how to work around my upgrade troubles for
PostGIS on my old laptop.  I did a "fink selfupdate && fink
update-all" that built PostGIS 1.3.1 (was 1.2.?) before.  The shared
library that contains all the stored procedures changed minor
versions from 1.2 to 1.3, thus the update script did not work.
<pre>
% psql sbnms_ais_2006 <  /sw/share/doc/postgis82/lwpostgis_upgrade.sql
BEGIN
CREATE FUNCTION
ERROR:  could not access file "/sw/lib/postgresql-8.2/liblwgeom.1.2.so": No such file or directory
CONTEXT:  SQL statement "SELECT postgis_lib_version()"
PL/pgSQL function "postgis_major_version_check" line 19 at SQL statement
ERROR:  current transaction is aborted, commands ignored until end of transaction 
</pre>
I then tried to see what the update script was doing.  It fails on this simple check:
<pre>
% psql sbnms_ais_2006
<b>SELECT postgis_lib_version();</b>
ERROR:  could not access file "/sw/lib/postgresql-8.2/liblwgeom.1.2.so": No such file or directory
</pre>
Looking in the shared library directory shows that I am out of luck.
<pre>
% ls /sw/lib/postgresql-8.2/lib*.so
liblwgeom.1.3.so  liblwgeom.1.so  liblwgeom.so
</pre>
As the documentation states that a dump/restore is only needed for a
major version number change, I decided that the solution was to fake a
1.2 version of the library so that the update script would take.  I think
it works.
<pre>
% cd /sw/lib/postgresql-8.2
% sudo ln -s liblwgeom.1.3.so liblwgeom.1.2.so
% psql sbnms_ais_2006 <  /sw/share/doc/postgis82/lwpostgis_upgrade.sql
BEGIN
CREATE FUNCTION
       postgis_major_version_check        
==========================================
 Scripts versions checked for upgrade: ok
(1 row)

DROP FUNCTION
CREATE FUNCTION
CREATE FUNCTION
CREATE FUNCTION
...
CREATE FUNCTION
CREATE FUNCTION
COMMIT
% sudo rm liblwgeom.1.2.so
</pre>
After that, the PostGIS database appears to be happy.
<pre>
% psql sbnms_ais_2006
sbnms_ais_2006=# <b>SELECT postgis_lib_version();</b>
 postgis_lib_version 
=====================
 1.3.1
sbnms_ais_2006=# <b>select position from position limit 1;</b>
                      position                      
====================================================
 0020000001000010E6C051A9E53D4DAFFE404539F1F6E12BB8
sbnms_ais_2006=# <b>select AsText(position) from position limit 1;</b>
                  astext                   
==========================================
 POINT(-70.6546166666667 42.4526966666667)
</pre>
