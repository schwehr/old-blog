BODY:
Just release <a
href="http://vislab-ccom.unh.edu/~schwehr/software/density/">density</a>
0.24.  The key addition is State Stamp Markup Language.  This provides
a very simple way to animate a scene with the simpleviewer.
<ul>
	<li>version: Released 0.24</li>
	<li>simpleview.C: Added state stamp markup language files for animation (ssml).  Uses libxml2.</li>
	<li>ssml: A language that is a more time oriented than RKSML (Rover Kintematic State Markup Language)</li>
	<li>simpleview.C: Uses SbTime for tracking time</li>
	<li>simpleview.C: Reworked intialization on startup a bit</li>
	<li>simpleview_cmd.ggo.in: Added statestamp and timescale options</li>
	<li>general: used gengetopt 2.21 instead of 2.19</li>
	<li>Makefile: added libxml2 to simpleview</li>
	<li>Makefile: SRL found a typo in rule name for install-density.info</li>
	<li>TODO: Realizing that autoconf is soon in the future</li>
</ul>
