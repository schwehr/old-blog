<b>svn blame</b> is a pretty cool command.  I don't tend to work with
anyone else on source code these days, but I could have really used
this command back in the mid 90's doing distributed development work
with ARC, CMU, GROK (hi Geb!), etc.  Here is an example from one of
the trees from CCOM.
<pre>
svn blame MainWindow.cpp
...
  2597     roland #include "interactors/Tool3DPallette.h"
   790        mdp #ifndef WIN32
   790        mdp     #include <unistd.h>
   790        mdp #endif
  2575     roland #include <gz4d/Filename.h>
   790        mdp 
...
</pre>
Then when somebody fixed a bug for me I could have zephyr ++'ed them. :)

Okay, not many people know about zephyr these days.  However,
wikipedia knows about <a
href="http://en.wikipedia.org/wiki/Zephyr_%28protocol%29">Zephyr</a>
which came out of MIT and Project Athena.
