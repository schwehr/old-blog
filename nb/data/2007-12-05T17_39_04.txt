Hmm... I need a scheduling language that I can embed in AIS message
definitions.  I would prefer something XML and as standard as
possible.  It needs to be able to express things like "send this every
3 minutes", "if condition x, send now", "if speed >= 10 and speed <
20, send every 5 seconds".

So far, my 10 minute search, my have run across <a
href="http://www.ietf.org/rfc/rfc2445.txt">RFC 2245</a> (iCalendar),
RFC 2446 IcaL Transport (iTIP), <a
href="http://www.idealliance.org/papers/xml2001/papers/html/05-04-06.html">Calendaring
and Scheduling with XML-RDF</a> (orlando), <a
href="http://www.w3.org/TR/2000/WD-smil-boston-20000225/Time-Integrate.html">SMIL
Time</a>, <a
href="http://tools.ietf.org/html/draft-royer-calsch-xcal-03">iCalendar
in XML Format</a> (xCal-Basic), and ?  iCalendar and xCal are
interesting, but I am not specifying actual events with respect to an
actual date, so maybe they just are not appropriate.  Maybe xCal could
be used to schedule an AIS basestation for broadcasting some
information.  And then there is the microformat world with <a
href="http://microformats.org/wiki/hcalendar">hcalendar</a>.

Suggestions/thoughts?
