I've been working my way through the SVN book a couple minutes a day
and I hit properties just as I was creating my 2008 work log and
retiring my 2nd 2007 log.  To have a keyword replacement for tracking
a file, I did this from the command line:
<pre>
% <b>svn propset svn:keywords 'Id' kurt-2008.txt</b>
% <b>svn proplist kurt-2008.txt -v</b>
Properties on 'kurt-2008.txt':
  svn:keywords : Id
</pre>
By putting "$Id:$" at the top of the file, it gets replaced with the
current revision information at each commit.
<pre>
$Id: kurt-2007.txt 8058 2008-01-01 16:07:52Z schwehr $
</pre>
I'd been using "svn propedit svn:keywords" and that pops up a text
editor.  Not very convenient if you need to do this on many files.

I was also reading about arbitraty keywords.  I can't think of a
really good use for me right now, but I can see how it could be
important tool.
