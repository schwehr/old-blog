My blog has been severly lacking in the other than black-and-white
category lately.  I haven't been taking much in the way of pictures,
so you will have to put up with a bit of color code.  This was posted
today here: <a
href="http://debaday.debian.net/2008/01/09/colordiff-put-some-color-in-your-diffs/">colordiff:
put some color in your diffs</a> [debaday].

colordiff is already in fink, so I did a "fink install colordiff" and now
can do: "svn diff | colordiff".  Too bad it doesn't work with less, but it
is still very cool when writing up svn commit log messages.

So a little color... and some amusing code that I wrote today.
