BODY:
There have been a number of people on the fink mailing lists that have
been getting weird problems with fink that boil down to the Apple
installers not putting all the necessary files onto a Mac.  We figured
out today that was why Rob's laptop could not compile ghostscript.  e.g.
this:
<pre>
gcc -DHAVE_MKSTEMP -DHAVE_HYPOT -DHAVE_FONTCONFIG -O2 -Wall \
-Wstrict-prototypes -Wmissing-declarations -Wmissing-prototypes \
-Wwrite-strings -Wno-strict-aliasing -fno-builtin -fno-common \
-DHAVE_STDINT_H -DGX_COLOR_INDEX_TYPE="unsigned long long" -I./obj \
-I./src -I/usr/X11/include -o ./obj/gp_unix.o -c ./src/gp_unix.c \
In file included from ./src/gp_unix.c:17:
./src/pipe_.h:39: warning: function declaration isn't a prototype
./src/gp_unix.c:25:37: error: fontconfig/fontconfig.h: No such file or directory
</pre>
My solution today was a bit different than the normal one suggested by
people on the fink mailing lists.  They suggest telling the mac to force
remove the X11SDK and reinstall.  We didn't have the install media on us,
so I made a tar of the missing headers and dropped them into the right spot
on his computer.
<pre>
cd ~/Desktop
wget <a href="http://schwehr.org/blog/attachments/2008-01/mac-10.5.1-x11-fontconfig-headers.tar.bz2">http://schwehr.org/blog/attachments/2008-01/mac-10.5.1-x11-fontconfig-headers.tar.bz2</a>
cd /usr/X11/include/fontconfig
sudo tar xf ~/Desktop/mac-10.5.1-x11-fontconfig-headers.tar.bz2
</pre>
Warning... the above assume that the only problem is the missing
headers in that one particular place.  If anything else is borked in
the Apple install, then it still is may fail for other things.  The
more Apple way is:

<a href=http://www.mail-archive.com/fink-users@lists.sourceforge.net/msg26382.html">msg26382.html</a> [fink users post archive]a
<pre>
Looks like you might need to re-install x11.
 pkgutil --forget com.apple.pkg.X11User
 pkgutil --forget com.apple.pkg.X11SDKLeo
 pkgutil --forget com.apple.pkg.X11DocumentationLeo
 pkgutil --forget org.x.X11.pkg
</pre>
Then reinstall X11.  On my machine, these are what I have installed:
<pre>
pkgutil --pkgs | grep -i X11
com.apple.pkg.X11User
com.apple.pkg.X11SDKLeo
com.apple.pkg.X11DocumentationLeo
</pre>
See Also: <a href="http://www.uoregon.edu/~noeckel/LeopardIntelSetup.html">LeopardInstelSetup</a> [noeckel at uoregon]
