BODY:
Briana has been trying out several commercial offerings of ECS system
at the low end of the price range.  We have been having fun checking
out "Coastal Explorer" by <a href="http://rosepointnav.com/">Rose
Point</a>.  These are my quick first impressions from the desktop as Briana
navigated through the software interface.

As a side note, for the Mac, I know of <a
href="http://www.macenc.com/">MacENC</a> and <a
href="http://www.macgpspro.com/">MacGPS Pro</a>.  Are there other ENC
type software packages out there for the Mac?  Any for Linux?

The program is easy to use.  It is able to attach to a number of AIS
ship tracking sources at one time.  We hooked it up to our feed 
using a TCP/IP socket to another computer and right off had vessel
traffic showing up.  Nice!

<img src="http://schwehr.org/blog/attachments/2008-02/CoastalExplorer-overview.jpg"/>

It is a little crazy at the scale showing the entire US (sorry
Alaska), but it gets the point across.  We then zoomed into New York.
One you get in close, you can see vessel names and the clutter gets
more manageable.

<img src="http://schwehr.org/blog/attachments/2008-02/CoastalExplorer-ny.jpg"/>

Coastal Explorer is able to go out to the Internet and grab tide and
current data.  I didn't trace this with something like tcpdump or
wireshark, so I am not sure how they do this.  It could be a SOAP or
OpenDAP connection to NOAA.  It is also possible that they data is
getting filtered by another provider who pulls the data from NOAA.

To my untrained eye, the ENC vector data is rendered very nicely.

<img src="http://schwehr.org/blog/attachments/2008-02/CoastalExplorer-tides.jpg"/>

<img src="http://schwehr.org/blog/attachments/2008-02/CoastalExplorer-cruisemode.jpg"/>

The general cruise mode has access to the contents of the NOAA Coast
Pilot volumes.  On the right are key features and bottom has the text
and paragraph numbers.

<img src="http://schwehr.org/blog/attachments/2008-02/CoastalExplorer-cruisemode-guide.jpg"/>

Briana has put together a new <a
href="http://www.ccom.unh.edu/vislab/projects/ChartoftheFuture.html">Chart
of the Future</a> project page.  On that page, we have a screenshot of our
research prototype of the Digital Coast Pilot.  We have been
researching both the front end User Interface (UI; 3D graphics/UI and
2D UI) and the back end XML representation.  My hope is that with some work, 
there will be a standard baseline XML.  From there, vendors could either
apply the content directly or add value how they see fit.
