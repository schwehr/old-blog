<b>UPDATE:</b> I did a 'sudo apt-get update' and uncheck and check the
static interface active icon and the 'auto eth0' line in
/etc/network/interfaces.  

This is really more of a gnome bug, but it is hitting me with Ubuntu
8.04 beta.  Thanks to Roland for sitting through a debug session with
me.  The problem is that a machine (actually 3 new machines)
configured for a static IP was not coming up on the network on boot.
Kind of important for a machine that will be remotely deployed for 
data logging.  The machines do come up on the network if I do
<pre>sudo ifup eth0</pre>
This is listed as bug <a
href="http://bugzilla.gnome.org/show_bug.cgi?id=526137">526137</a> for
gnome.  Or on ubuntu launchpad: <a href="https://bugs.launchpad.net/ubuntu/+source/gnome-system-tools/+bug/185854">185854</a>

The solution is to add the bold line below.
<pre>
cat /etc/network/interfaces 
auto lo
iface lo inet loopback
<b>auto eth0</b>
iface eth0 inet static
address 10.0.0.243
netmask 255.255.255.224
gateway 10.0.0.225
</pre>
Replace 10.0.0. with your local network config.
