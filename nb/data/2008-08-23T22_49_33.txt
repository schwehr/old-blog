Then I took a look at <a
href="http://tilloy.net/dev/pyexiv2/">pyexiv2</a>.  I was not able to
figure out how to properly pass include and library flags to the
compile lines, so I wrote a quick setup.py:
<pre>
from distutils.core import setup, Extension
srcs = ['src/libpyexiv2.cpp','src/libpyexiv2_wrapper.cpp']
setup(name='pyexiv2',
      version='1.0',
      ext_modules=[
        Extension('libpyexiv2', 
                  srcs,
                  libraries=['boost_python','exiv2']), 
        ],
      py_modules=['pyexiv2'],
      )
</pre>
Then I whipped up a fink info file: <a href="http://vislab-ccom.unh.edu/~schwehr/software/fink/pyexiv2-py.info">pyexiv2-py.info</a>
<pre>
% <b>ipython</b>
import pyexiv2
image = pyexiv2.Image('IMG_6829.JPG')
image.readMetadata()
lat =  image['Exif.GPSInfo.GPSLatitude']
[str(field) for field in lat]
lat[0].numerator/lat[0].denominator + lat[1].numerator/float(lat[1].denominator) / 60 + lat[2].numerator/lat[2].denominator / 3600.
</pre>
