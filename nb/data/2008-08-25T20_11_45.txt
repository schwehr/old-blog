Trackback: Sean Gillies points out that similar mapping of locations for pubs has been done before: <a href="http://sgillies.net/blog/803/friends-dont-let-friends-use-endnote/">Friends don't let friends use Endnote</a> 
<pre>Kurt, I have in fact seen mapping integrated with Zotero. Shekhar
Krishnan used the GeoNames database to locate items by their place of
publication in a demo at THATCamp.</pre>

I just submitted GeoEndNote as a suggested output format to Thomson
Reuters' <a href="http://endnote.com/">EndNote</a> output style suggestion page.

<img src="http://schwehr.org/blog/attachments/2008-08/geoendnote-submission.png"/>

It would be cool if other tools like <a href="http://www.zotero.org/">zotero</a> (Firefox extension for references), OpenOffice, or <a href="http://jabref.sourceforge.net/">JabRef</a> pick up the same concept.

Also, just ran into <a
href="http://bibtexml.sourceforge.net/">BibTeXML</a>.  Was just
thinking that XML would be more friendly than the straight bibtex
format.

For an overview of many reference mangement programs, check out
wikipedia: <a
href="http://en.wikipedia.org/wiki/Comparison_of_reference_management_software">Comparison
of reference management software</a>.  Note that KML, WKT, Google,
spatial, location, or PostGIS do NOT show up in the document.
