BODY:
We are one month away from Python 2.6.  <a
href="http://docs.python.org/dev/whatsnew/2.6.html">What's New in
Python 2.6</a> is well worth a read.  The "with" functionality is very
cool for all sorts of programming where cleanup on exit is necessary,
but not fun.  C++ programmers often do this by putting an object in a
new stack frame and then when the stack frame goes away, the object
destructor gets called and cleans things up.  I first saw this with 
Ace/Tao by Schmidt for making sure that you release locks.

Read the document for lots of other good features.
