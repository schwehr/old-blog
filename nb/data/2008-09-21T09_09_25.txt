<b>Update 20080926</b>: Thanks to Bror Jonsson for a patch to
matplotlib-basemap-data-py.  How to ask the path to the data files had
changed.  There is still likely troubles with libgeos2 lurking.  If
it is not working, make sure to install <b>libgeos2</b> in addition to
<b>libgeos2-shlibs</b>.  There is some bad version number stuff going
on with libgeos[23]... libgeos did not increment their version numbers
of the dylibs enough in the libgeos2 to 3 update.

I finally got around to updating <a href="http://matplotlib.sourceforge.net/tutorial.html">matplotlib</a> and the basemap in fink to
the latest version.  I really need to spend more time with the package.
It can produce somereally great results.  I always seem to drop back
to the old standby of gnuplot.
