<pre>Relative imports - When you are using a setting file multiple
times, it is nice to be able to define relative variables for your
things.
  import os
  DIRNAME = os.path.dirname(__file__)
  DATABASE_NAME = "%s/dev.db" % DIRNAME
  MEDIA_URL = os.path.join(DIRNAME, 'media')
  TEMPLATE_DIRS = ( DIRNAME + "templates", )
