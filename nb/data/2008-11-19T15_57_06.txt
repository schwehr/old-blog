href="http://www.python.org/doc/lib/module-ctypes.html">ctypes</a>

very satifying.  It's writen in <a
href="http://www.python.org/doc/api/api.html">CPython</a> and is not

I start off the code by pulling in the ctypes library.  One trick
is that the return code for all functions is assumed to be an integer.
That works for everything here accept the <b>magic_file</b> call
that returns a string.  Therefore, I have to tell it that
it <b>restype</b> is a c_char_p (aka a C string).

I did have trouble with #defines for flags.  I can't pull these from
the shared library as they never get defined in the library.  If these
has been <b>const int</b> values, I could have imported them.

Compare this to just a little bit of the CPython code.  Note that I am
sure the CPython code will be slightly faster.
