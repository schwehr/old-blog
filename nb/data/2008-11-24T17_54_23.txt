This has been coming up a lot lately.  Yes, I am still maintaining the
fink install of <a href="http://www.ldeo.columbia.edu/res/pi/MB-System/">MB-System</a>.  It still is there and working (minus the
OpenGL 3D graphics portion).
<ul>
  <li>install XCode</li>
  <li>installed the binary package from http://finkproject.org</li>
  <li>run "fink configure" and activate the "unstable"
  This edits /sw/etc/fink.conf and puts "unstable/main" on your "Trees:" line.</li>
  <li>run "fink selfupdate-rsync"  (after the first time, you should just use "fink selfupdate"</li>
  <li>fink list mbsystem</li>
  <li>fink install mbsystem</li>
  <li>wait a good while as it builds everything</li>
  <li>run "dpkg -L mbsystem | grep bin" to see all the programs it installed.</li>
</ul>
If you want to see how it is packaged and built, take a look at the
fink info file:
<pre>less /sw/fink/10.4/unstable/main/finkinfo/sci/mbsystem.info </pre>
Note that 10.4 and 10.5 use a symbolic link so that the trees are the 
same.
