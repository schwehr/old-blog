I needed a more straightforward example of a pointer to a structure
being returned from a function call to practice ctypes on.  So, I made
one and here is what I did.  There wasn't anything quite like it in
the <a href="http://www.python.org/doc/lib/ctypes-ctypes-tutorial.html">ctypes tutorial</a>.

First the C code.  I didn't want to deal with malloc / free, so I just
put an instance of the structure (sample2) in the scope of the shared object.

<pre><tt><i><font color="#9A1900">// Build like this on the mac: gcc -g -Wall -bundle -undefined dynamic_lookup test_ctypes.c -o _test_ctypes.so</font></i>
<!-- -->
<b><font color="#0000FF">struct</font></b> <font color="#008080">two</font> <font color="#FF0000">{</font>
    <font color="#009900">int</font> g<font color="#990000">;</font>
    <font color="#009900">float</font> h<font color="#990000">;</font>
<font color="#FF0000">}</font><font color="#990000">;</font>
<!-- -->

<b><font color="#0000FF">struct</font></b> <font color="#008080">two</font> sample2<font color="#990000">;</font>

    sample2<font color="#990000">.</font>g <font color="#990000">=</font> <font color="#993399">123</font><font color="#990000">;</font>

And the python ctypes interface.
<pre><tt><i><font color="#9A1900">#!/usr/bin/env python</font></i>
<!-- -->
<b><font color="#000080">import</font></b> ctypes
lib <font color="#990000">=</font> ctypes<font color="#990000">.</font><b><font color="#000000">CDLL</font></b><font color="#990000">(</font><font color="#FF0000">'_test_ctypes.so'</font><font color="#990000">)</font>

    _fields_ <font color="#990000">=</font> <font color="#990000">[</font>
