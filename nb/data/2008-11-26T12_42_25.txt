I got a little to clever for my own good...
<pre>% <b>fink install mbsystem</b>
#!/bin/bash -ve
  # NOTE: do not set -e for bash in the line above.  That will break the grep
  perl -pi.bak -e  's|\@FINKPREFIX\@|/sw|g' install_makefiles
  cpp -dM /dev/null | grep __LITTLE_ENDIAN__
### execution of /var/tmp/tmp.1.TrwYax failed, exit code 1
</pre>
On PPC, the little endian check fails and grep has an exit status of
1.  This is fine, but bash then sees it as an error and quits with
a failure.  Sigh.

Here are some options.  First is 'uname -m' 
<pre>big endian machine % <b>uname -m</b>
Power Macintosh
little endian machine $ <b>uname -m</b>
i386</pre>
That works, but if uname -m ever changes, we are sunk.  Here is my
new, more robust endian check that doesn't require actually compiling
anything.
<pre>big endian ppc machine % <b>cpp -dM /dev/null | grep -i ENDIAN__ | cut -d_ -f 3</b>
BIG
little endian i386 machine % <b>cpp -dM /dev/null | grep -i ENDIAN__ | cut -d_ -f 3</b>
LITTLE
</pre>
