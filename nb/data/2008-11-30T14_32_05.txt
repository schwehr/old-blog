I was going to look at nagios for fink and look into adding checks for
my tide stations, but I figured that since <a
href="http://www.opennms.org">OpenNMS</a> is already in fink and <a href="http://www.ohloh.net/projects/4501/contributors/19331647804578">one
of the fink maintainers also works on OpenNMS</a>, it might be worth
giving it a try on my Mac laptop.
<pre> % <b>fink describe opennms</b>
% <b>less /sw/share/doc/opennms/README.Darwin</b>
% <b>fink install opennms</b>
% <b>fink install tomcat5</b> # Did a really need this one?
% <b>sudo emacs /sw/var/postgresql-8.3/data/pg_hba.conf</b>
# Realize that the file looks to be already configured
% <b>sudo emacs /sw/var/postgresql-8.3/data/postgresql.conf</b>
listen_addresses = 'localhost'		# what IP address(es) to listen on;
max_connections = 192			# (change requires restart)
% <b>sudo daemonic enable postgresql83</b></pre>
This is the Mac OS X 10.5:
<pre>% <b>sudo emacs /etc/sysctl.conf</b>
kern.sysv.shmmax=16777216
kern.sysv.shmmin=1
kern.sysv.shmmni=64
kern.sysv.shmseg=8
kern.sysv.shmall=32768
</pre>
Once the above parameters are set, you need to reboot the mac.
<pre>% #<b>cd /sw/bin && sudo pgsql.sh-8.3 restart</b>  # Not needed with reboot
   # There is something weird with my postgresql setup... 
   # Lots of complaints on restart
% <b>sudo -u postgres createdb -U postgres -E UNICODE opennms</b>
% <b>install_iplike_83.sh</b> 
% <b>sudo /sw/var/opennms/bin/install -dis</b>
% <b>sudo /sw/bin/tomcat5 start</b>
% <b>sudo opennms start</b>
% <b>open http://localhost:8980/opennms/</b>
U: admin, P: admin</pre>
Then, when you are ready to have an OpenNMS service always running, do this:
<pre>% <b>sudo daemonic enable opennms</b></pre>
