but it hides the deb creation, so I don't really know how to make debs
correctly.  

In the past, I've looked through the Ubuntu resources to see if they could help.

<a href="https://wiki.ubuntu.com/PackagingGuide/HandsOn">Hands On Packaging Guide</a> and <a href="https://wiki.ubuntu.com/MOTU/School">Masters of the Universe School</a>

Here is how to see what fink is doing...

First edit /sw/etc/fink.conf and add this line to keep part of the build
process around.  Fink normally deletes these temporary files.  Make sure to
remove the line when done!
<pre>KeepRootDir: true</pre>
Now build something or rebuild it if you already have it installed.
<pre>% <b>fink rebuild pyserial-py6</b></pre>
Now take a look at the deb that was just produced:
<pre>% <b>dpkg-deb --info /sw/fink/debs/pyserial-py26_2.0-12_darwin-i386.deb</b>

Now it is time to see where this stuff came from.
<pre>% <b>cd /sw/src/fink.build/root-pyserial-py26-2.0-12/</b>
% <b>ls -l</b>
total 0
drwxr-xr-x 4 root admin 136 Dec  2 07:34 DEBIAN
drwxr-xr-x 4 root admin 136 Dec  2 07:34 sw</pre>
sw contains the files to be installed as a complete tree.  The DEBIAN 
directory contains the control files.
<pre>% <b>cd DEBIAN</b>
% <b>ls -l</b>
total 8
-rw-r--r-- 1 root admin 1652 Dec  2 07:34 control
-rw-r--r-- 1 root admin 2129 Dec  2 07:34 package.info</pre>

That is a a pretty simple package.  There are not post install or post
removal scripts to run.  To take a look at something more complicated, try
looking at PostgreSQL:
<pre>% <b>fink rebuild postgresql83</b></pre>
Now take a look at the DEBIAN files:
<pre>% <b>/sw/src/fink.build/root-postgresql83-8.3.5-1/DEBIAN</b>
% <b>ls -l</b>
