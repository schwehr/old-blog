Here is what the table schema currently looks like. 
<pre>% <b>sqlite3 200810-bensmith-vosdata.db .schema</b>
CREATE TABLE VOSdata (id TEXT PRIMARY KEY, sqltime TEXT, latitude REAL, longitude REAL, wkt_geographic TEXT, callSign TEXT);</pre>
And some sample data:
<pre>% <b>sqlite3 'SELECT * FROM vosdata LIMIT 5;'</b>

And just how much data is in this test run:
<pre>% <b>sqlite3 200810-bensmith-vosdata.db 'SELECT count(*) FROM VOSdata;'</b>
164234</pre>
Don't forget to create an index on the callsign so that queries go really fast!
<pre>% <b>sqlite3 200810-bensmith-vosdata.db 'CREATE INDEX callsign_idx ON vosdata(callsign);'</b></pre>
Future enhancements might include using a TIMESTAMP type for the time field
and creating timespans for the vessel traffic.
