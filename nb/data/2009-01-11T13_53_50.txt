I've done a bit more with CGI and Python.  This works up to handling a
form with user input.  In my first post on python and cgi, I created
helloworld-py.cgi.  To improve on this, I first wanted to get some
better error handling going.  Python provides this through a cgitb
module.  cgitb (or CGI TraceBack) can be used either just as a
response to the web browser, saved as a log file, or both.  Here I
have both turned on.  I then use the AssertionError to force a
traceback.  cd ~/Sites/test and create <i>demo-py.cgi</i>:
<pre><tt><i><font color="#9A1900">#!/usr/bin/env python</font></i>
<!-- -->
<b><font color="#000080">import</font></b> cgi
<i><font color="#9A1900">#import cgitb; cgitb.enable()</font></i>
<i><font color="#9A1900">#import cgitb; cgitb.enable(display=0, logdir="/tmp") # Only write log file</font></i>
<b><font color="#000080">import</font></b> cgitb<font color="#990000">;</font> cgitb<font color="#990000">.</font><b><font color="#000000">enable</font></b><font color="#990000">(</font>logdir<font color="#990000">=</font><font color="#FF0000">"/tmp"</font><font color="#990000">)</font>
<!-- -->
<b><font color="#0000FF">print</font></b> <font color="#FF0000">'Content-type: text/html\n'</font>
<b><font color="#0000FF">print</font></b> <font color="#FF0000">'Hello, World.'</font>
<b><font color="#0000FF">raise</font></b> <b><font color="#000000">AssertionError</font></b><font color="#990000">(</font><font color="#FF0000">'Test raising some exception'</font><font color="#990000">)</font>
</tt></pre>

You can also look in /tmp for the same results: <b>ls -ltr
/tmp/tmp*.html</b>.  That's much easier to debug than "Internal Server
Error"!  It would also be nice to be able to allow importing these
scripts.  This requires that there are no '-' characters in the CGI
script names and that the file names end in <i>.py</i>.  To handle the
file extention, we need to add it to apache2's mime type hander.
<pre> % <b>sudo emacs /sw/etc/apache2/mods-enabled/mime.conf</b></pre> and
add this line next to <i>AddHandler cgi-script .cgi</i>:
<pre>AddHandler cgi-script .py</pre>
Then restart apache2:
<pre>% <b>sudo apache2ctl restart</b></pre>
Now we are ready to attempt the next demo where we create a html form document
that calls a python cgi when the user presses the submit button.  Save this as
<i>demo2-from.html</i>

<pre>% <b>chmod +x demo2.py</b>

Put <i>test 123</i> in the text field and press submit.  You should see something like this:
<pre>Processing form
Form: FieldStorage(None, None, [MiniFieldStorage('text', 'test 123'), MiniFieldStorage('hiddenname', 'foo')])
<!-- -->
    * text - test 123
    * hiddenname - foo</pre>
FieldStorage works similar to a python dictionary.

A final improvement to the script is to combine the form html and the
form processing script.  <i>cgi.FieldStorage()</i> will return
<i>None</i> if there is no form data.  demo3.py:

    form <font color="#990000">=</font> cgi<font color="#990000">.</font><b><font color="#000000">FieldStorage</font></b><font color="#990000">()</font>

        <b><font color="#0000FF">print</font></b><font color="#FF0000"> '''&lt;html&gt;</font>
<font color="#FF0000">&lt;body&gt;</font>

<!-- -->

    * first - one</pre>
