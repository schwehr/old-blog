I've covered CGI's, so now it is time to explore <a
href="http://modpython.org/">mod_python</a> as I climb up the stack
back towards Django.  Again, this is using fink's apache2 on Mac OSX
10.5.6 (uname -r returns 9.6.0, fink --version gives 0.28.6).  First,
we need to install mod python:
<pre>% <b>fink install libapache2-mod-python-py26</b>
% <b>sudo a2enmod python2.6</b>
% <b>sudo apache2ctl restart</b></pre>
This time, I'm going to use .htaccess in a test directory to control apache2's loading of python.
<pre>% <b>mkdir ~/Sites/test2 && cd ~/Sites/test2</b>
% <b>cat &lt;&lt; EOF &gt; .htaccess</b>
AddHandler mod_python .py
PythonHandler mptest
PythonDebug On
EOF
% <b>cat &lt;&lt; EOF &gt; mptest.py</b>
from mod_python import apache
def handler(req):
    req.content_type = 'text/plain'
    req.write("Hello World!")
    return apache.OK
EOF
% <b>open http://localhost/~$USER/test2/mptest.py</b></pre>
You should now be looking at a <i>Hello World!</i> in your web browser.

Time to switch to a real handler.  The publisher.
<pre>% <b>mkdir ~/Sites/test3 && cd ~/Sites/test3</b>
% <b>cat &lt;&lt; EOF &gt; .htaccess</b>
AddHandler mod_python .py
PythonHandler mod_python.publisher
PythonDebug On
EOF
% <b>cat &lt;&lt; EOF &gt; hello.py</b>
def index():
   s = '''&lt;html&gt;
&lt;body&gt;
&lt;h2&gt;Hello World! mod python publisher&lt;/h2&gt;
&lt;/body&gt;
&lt;/html&gt;
'''
   return s
EOF
% <b>open http://localhost/~$USER/test3/hello.py</b></pre>
You can then add a page indexing into functions in hello.py.  Add this method:
<pre>def another_page():
    return 'yup, another page'</pre>
Then check out this new URL:
<pre>% <b>open http://localhost/~$USER/test3/hello.py/another_page</b></pre>
Or add any object that has a string representation.  Add these strings to hello.py
<pre>foo = 'bar'
_fubar = 'not visible'</pre>
Now try these two URLs:
<pre>% <b>open http://localhost/~$USER/test3/hello.py/foo</b>
% <b>open http://localhost/~$USER/test3/hello.py/fubar</b></pre>
