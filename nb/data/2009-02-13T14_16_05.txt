I keep running into "SEG-Y" files that don't match what I think a
SEG-Y file should be.  Rather than struggle through the error messages
that my code gives when it hits something strange, I created a script
in simplesegy called segy-validate.  This script doesn't check all
that much yet, but so far it range checks about 80% of the binary header
and the first trace header.  This catches most of the things that have
burned me so far.  I am sure I could spend days coming up with checks, but
it is a start.  I hope this will be helpful to people when they are 
inspecting new data streams.

A couple examples...
