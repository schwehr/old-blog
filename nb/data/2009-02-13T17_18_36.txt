I just released simplesegy version 0.7.  segy-metadata can now set the
year and day for segy files that didn't record such information.  It
should get upset on files that cross over days, but I haven't tried
that yet.  WARNING: I picked a random year and Julian day for the testing
here.

Now if someone could generate a good template for the XML metadata
schema that would work for SEG-Y seismic data, we would be all set.

I really have no way of validating the FGDC metadata format here.  The
USGS validator seems to make assumptions that aren't true for
multibeam data.
