<a

site internals, etc (the workbook)</a> points to two presentations
about how the software behind wikipedia works.

<a href="http://dammit.lt/uc/workbook2007.pdf">Wikipedia: Site internals, configuration, code examples and management issues (the workbook)</a> [pdf]

<a href="http://www.nedworks.org/~mark/presentations/san/Wikimedia%20architecture.pdf">Wikimedia Architecture</a>...
<ul>
<li>30 000 HTTP requests/s during peak-time</li>
<li>3 Gbit/s of data traffic</li>
<li>3 data centers: Tampa, Amsterdam, Seoul</li>
<li>350 servers, ranging between 1x P4 to 2x Xeon Quad-Core, 0.5 - 16 GB of memory</li>
<li>managed by ~6 people</li>
</ul>
The above came from a slashdot article: <a
href="http://tech.slashdot.org/article.pl?sid=09/03/02/0231241">Best
Solution For HA and Network Load Balancing?</a>.  The question is
good, but the person asking doesn't sound like they need this.  Some
of the responses are actually helpful.

I've used a couple HA systems in the past.  Things like <a
href="http://www.drbd.org/">DRBD</a> are interesting.
<pre>block devices designed as a building block to form high availability
(HA) clusters. This is done by mirroring a whole block device via an
assigned network.</pre>
