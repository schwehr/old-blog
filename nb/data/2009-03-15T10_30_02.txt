I don't know if this cheat sheet will be helpful to others or not, but
it will help me spend less time looking up SQL syntax.  I hope that
the sections for table one and table two will be accessable to
beginners.  This is a different style than other tutorials I have seen
on the web.  It is done as a big SQL file that you can either run at
once or paste in line by line.  It only runs on SQLite, but I will try 
to alter it to work with PostgreSQL and explain the differences in another
post.  SQLite does some quirky things, but it is a good learning environment.
For example, it allows field types that do not make sense:
<pre>CREATE TABLE foo (a ASDF);</pre>
ASDF is not a valid SQL type, but the command works.

You can run these commands in one of three ways.  The most educational is
way is to just run this command:
<pre>% <b>sqlite3</b></pre>
This will put you into sqlite's shell.  You can paste in commands from the
text and when you are done, quit it like this:
<pre>sqlite&gt; <b>.quit</b></pre>
If you want to quickly see what everything does, try this:
<pre>% <b>sqlite3 < sqlite-tutorial.sql | less</b></pre>
This will let you see both the commands being entered and the results.

The above two examples use an "in memory" database, so when you exit,
everything goes away.  If you want to have a database be saved to disk,
do one of these two:
<pre>% <b>sqlite3 demo.db3</b>
% <b>sqlite3 demo.db3 < sqlite-tutorial.sql </b></pre>

<i><font color="#9A1900">----------------------------------------</font></i>
<i><font color="#9A1900">-- Putting constraints on the database</font></i>
<i><font color="#9A1900">-- and linking tables</font></i>
<!-- -->
<i><font color="#9A1900">-- NOT NULL forces a column to always have a value.</font></i>
<i><font color="#9A1900">--   Inserting without a value causes an error</font></i>
<i><font color="#9A1900">-- UNIQUE enforces that you can not make entries that are the same</font></i>
<i><font color="#9A1900">-- DEFAULT sets the value if you don't give one</font></i>
<i><font color="#9A1900">-- REFERENCES adds a foreign key pointing to another table</font></i>
<b><font color="#0000FF">CREATE</font></b> <b><font color="#0000FF">TABLE</font></b> tbl_three <font color="#990000">(</font>
       a_key     INTEGER <b><font color="#0000FF">PRIMARY</font></b> <b><font color="#0000FF">KEY</font></b><font color="#990000">,</font>
       a_val     REAL    <b><font color="#0000FF">NOT</font></b> <b><font color="#0000FF">NULL</font></b><font color="#990000">,</font>
       a_code    INTEGER <b><font color="#0000FF">UNIQUE</font></b><font color="#990000">,</font>
       a_str     <font color="#009900">TEXT</font>    <b><font color="#0000FF">DEFAULT</font></b> <font color="#FF0000">'I donno'</font><font color="#990000">,</font>
       tbl_two   INTEGER<font color="#990000">,</font>       
       <b><font color="#0000FF">FOREIGN</font></b> <b><font color="#0000FF">KEY</font></b><font color="#990000">(</font>tbl_two<font color="#990000">)</font> <b><font color="#0000FF">REFERENCES</font></b> tbl_two<font color="#990000">(</font>a_key<font color="#990000">)</font>
       <font color="#990000">);</font>
<!-- -->
<i><font color="#9A1900">-- a_key and a_str are automatically given values</font></i>
<b><font color="#0000FF">INSERT</font></b> <b><font color="#0000FF">INTO</font></b> tbl_three <font color="#990000">(</font>a_val<font color="#990000">,</font>a_code<font color="#990000">,</font>tbl_two<font color="#990000">)</font> <b><font color="#0000FF">VALUES</font></b> <font color="#990000">(</font><font color="#993399">11.2</font><font color="#990000">,</font><font color="#993399">2</font><font color="#990000">,</font><font color="#993399">1</font><font color="#990000">);</font>
<b><font color="#0000FF">INSERT</font></b> <b><font color="#0000FF">INTO</font></b> tbl_three <font color="#990000">(</font>a_val<font color="#990000">,</font>a_code<font color="#990000">,</font>tbl_two<font color="#990000">)</font> <b><font color="#0000FF">VALUES</font></b> <font color="#990000">(</font><font color="#993399">12.9</font><font color="#990000">,</font><font color="#993399">4</font><font color="#990000">,</font><font color="#993399">3</font><font color="#990000">);</font>

<i><font color="#9A1900">-- It is not required to have foreign keys for joins</font></i>
<b><font color="#0000FF">SELECT</font></b> tbl_three<font color="#990000">.</font>a_code<font color="#990000">,</font>tbl_two<font color="#990000">.*</font> <b><font color="#0000FF">FROM</font></b> tbl_two<font color="#990000">,</font>tbl_three <b><font color="#0000FF">WHERE</font></b> tbl_two<font color="#990000">.</font>a_key <font color="#990000">==</font> tbl_three<font color="#990000">.</font>tbl_two<font color="#990000">;</font>
