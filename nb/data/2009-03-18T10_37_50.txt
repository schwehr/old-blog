Here is taking a quick look at the mysql database with Django.  This
is using the library database dump from before.  I used the draft
version of the <a href="http://djangobook.com/en/2.0/">2.0 Django
Book</a>.  Turns out this database isn't very interested.  All but
the primary keys are varchar, so I can't show cool foreign key stuff.
You will need fink unstable for this.

Note that the database shown here is not how I would design things.
It needs foreign keys for authors and others, date types for dates, and
a few other things before it would be something I would want to use.
<pre>% <b>fink install django-py26 mysql-python-py26</b></pre>
Now start working on the django project:
<pre>% <b>django-admin.py startproject ccom_library</b>
% <b>cd ccom_library</b>
% <b>python manage.py startapp library</b>
% <b>echo $USER</b></pre>
Now edit settings.py and change these lines:
<pre>DATABASE_ENGINE = 'mysql'
DATABASE_NAME = 'library'
DATABASE_USER = 'YourShortUsernameHere' # what $USER returned</pre>
To the INSTALLED_APPS section, add these lines:
<pre>    'django.contrib.admin',
    'ccom_library.library',</pre>
Now edit urls.py so that it looks like this:
<pre><tt><b><font color="#000080">from</font></b> django<font color="#990000">.</font>conf<font color="#990000">.</font>urls<font color="#990000">.</font>defaults <b><font color="#000080">import</font></b> <font color="#990000">*</font>
