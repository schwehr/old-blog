Here is how you check to see if windows time service is running on
Windows XP.  Thanks to Will F. for showing me this.

Start -&gt; Control Pannels -&gt; Administrative Tools -&gt; Services -&gt; Extended tab.

As it says:
<pre>Services (Local)
<!-- -->
Windows Time
<!-- -->
Description:
Maintains date and tie synchronization
on all clients and servers in the network.
If this service is stopped, date and time
synchronization will be unavailable.  If this
servece is disabled, any services that 
explicitly depend on it will fail to start.</pre>
My recommendation is to install NTP and avoid Windows Time Service.
