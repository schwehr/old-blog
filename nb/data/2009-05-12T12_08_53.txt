I've just got my first draft of bag2kmlbbox working.  This is a script
that reads the metadata in a Bathymetric Attributed Grid and writes
out the bounding box and puts the metadata in a placemark.  Lots more
to do, but it gets the idea across.  Code and improvements will be
forthcoming.
