Remko sent me updated info files for GMT 4.5.0 fink on Mac OSX.  They
are now committed, so if you update fink you will get the latest
version.  There were API changes in GMT's libraries, so I had to 
patch MBSystem for the GMT_grd_setregion and ps_line functions:
<pre>perl -pi.bak -e 's|GMT_grd_setregion \(\&header, xmin,  xmax, ymin, ymax\)\;|GMT_grd_setregion \(\&header, xmin,  xmax, ymin, ymax, BCR_BILINEAR\)\;|g' ./src/mbaux/mb_readgrd.c  ./src/mbview/mbgrdviz_callbacks.c
perl -pi.bak -e 's|GMT_grd_setregion \(\&header, \&bounds\[0\], \&bounds\[1\], \&bounds\[2\], &bounds\[3\]\)\;|GMT_grd_setregion \(\&header, \&bounds\[0\], \&bounds\[1\], \&bounds\[2\], &bounds\[3\], BCR_BILINEAR\)\;|g' src/gmt/mbgrdtiff.c
perl -pi.bak -e 's|ps_line\(xl,yl,4,3,0,0\)\;|ps_line\(xl,yl,4,3,0\)\;|g' src/utilities/mbps.c</pre>
<b>IMPORTANT for Mac OSX 10.4 users:</b>

As of today, I've removed mbsystem from fink for mac osx 10.4.  I've
got no way to support it.  If you want the old info file, I've
archived it here:

<a href="http://vislab-ccom.unh.edu/~schwehr/software/fink/mbsystem-10.4.info">http://vislab-ccom.unh.edu/~schwehr/software/fink/mbsystem-10.4.info</a>
