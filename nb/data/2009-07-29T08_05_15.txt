Last night, the Django project released a security update to fix the
development webserver.  You should be using a production webserver if
you are on an untrusted network (e.g. the internet).  Either way, if
you are using django through fink, you should do:
<pre>% <b>fink selfupdate</b>
% <b>fink install django-py26</b> # Or which ever version of python you are using</pre>
I've updated both the stable and unstable trees.  The unstable tree also got bumped up to Django 1.1.
