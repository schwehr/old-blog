TITLE: LTE as an extra channel for AIS and related data
AUTHOR: Kurt
DATE: 09.19.2009 18:40
DESC: other methods
-----
BODY:
There has been a lot of talk lately about <a
href="http://en.wikipedia.org/wiki/Wimax">WiMAX</a> being a possible
additional channel or replacement for AIS.  I had not looked at
another upcoming technology that could possibly provide additional
functionality above the two existing AIS channels: <a
href="http://en.wikipedia.org/wiki/3GPP_Long_Term_Evolution">3GPP Long
Term Evolition</a>.  In terms of adding functionality over standard
VHF AIS, both of these technologies have orders of magnitude more
bandwidth.  The question really is how can these address the needs of
vessels in remote areas.  If these systems could handle mesh
networking using ships as nodes, then it would be a big win for the
maritime community.  I haven't heard much positive from some initial
WiMAX trials, but we shall see.

I still think what we need is a true mesh system with proper ACKs and
authentication, but that can be done without any fixed station
infrastructure if need be.
