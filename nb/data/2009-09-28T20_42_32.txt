BODY:
It is fairly common for ships to broadcast sensor data on the internal
science network using UDP text messages.  The Langseth does this, but
I didn't see any details about which computers were broadcasting and
on what ports.  To figure this out, I fired up wireshark on my mac
when it was attached to the ship's science network via wireless.
<pre>fink install wireshark-ssl
sudo wireshark &</pre>
<img title="Wireshark on the Langseth" withgrayborder="True" src="http://schwehr.org/blog/attachments/2009-09/langseth-wireshark-udp.png"/>

I let it run for a while and paused the stream and scanned through for
broadcast udp (Destination: 255.255.255.255 and Protocol: UDP).  Here,
you can see that I found packet number 5024 from host 192.168.3.21.  I
then noted that the machine is sending to port 33103.  Selecting the
packet, wireshark shows the contents of the packet, which looks like a
"$GPGGA" NMEA string from a computer called cnav.  <a
href="http://www.cctechnol.com/site47.php">C-NAV</a> is the payed
subscription GPS service that the ship uses for positioning.

Based on that information, I wrote a little UDP logging client that is
about as simple as possible:
<pre><tt><i><font color="#9A1900">#!/usr/bin/env python</font></i>
<b><font color="#000080">import</font></b> socket
<b><font color="#000080">import</font></b> time
<!-- -->
host<font color="#990000">=</font><font color="#FF0000">'0.0.0.0'</font> <i><font color="#9A1900"># All interfaces</font></i>
port<font color="#990000">=</font><font color="#993399">33103</font>
buffer <font color="#990000">=</font> <font color="#993399">10000</font>
<!-- -->
sock <font color="#990000">=</font> socket<font color="#990000">.</font><b><font color="#000000">socket</font></b><font color="#990000">(</font>socket<font color="#990000">.</font>AF_INET<font color="#990000">,</font>socket<font color="#990000">.</font>SOCK_DGRAM<font color="#990000">)</font>

<!-- -->

<b><font color="#0000FF">while</font></b> <font color="#993399">1</font><font color="#990000">:</font>

</tt></pre>
