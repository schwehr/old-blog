I tried running this to see if xmllint would handle the XSD schema:
<pre>xmllint --noout multibeam_line0001_metadata.xml</pre>
If runs and return 0 if you run "echo $?" to see what exit code it gave.
xmllint requires that you tell it the name of the schema file.  So I tried
this:
<pre>xmllint --noout --schema http://ngdc.noaa.gov/metadata/published/xsd/ngdcSchema/schema.xsd multibeam_line0001_metadata.xml</pre>
