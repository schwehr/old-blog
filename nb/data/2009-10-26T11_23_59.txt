I finally setup Boot Camp on my Mac now that I have 10.6.  It took me
a long time because I was trying to get it to let me do a triple boot
with Linux, but if it doesn't fit with what Apple was thinking, then
it just doesn't work.  I also assumed that Fat32 would be okay, but it
is not.  You MUST use NTFS.

Having a Time Machine backup that you can restore from is a real help
with this process.

<img title="" withgrayborder="True" src="http://schwehr.org/blog/attachments/2009-10/timemachine-restore.jpg"/>

<img title="" withgrayborder="True" src="http://schwehr.org/blog/attachments/2009-10/timemachine-restore-2.jpg"/>

Make sure to format as NTFS.  Don't just use the default that comes up.

<img title="" withgrayborder="True" src="http://schwehr.org/blog/attachments/2009-10/must-format-to-ntfs.jpg"/>

I tried to make some extra partitions, but Bootcamp would have none of
it and Windows got confused by the partitions.  I have heard of triple
booting, but it appears to be a lot easier with two or just ignore
bootcamp and go it alone.

<img title="Don't try it this way" withgrayborder="True" src="http://schwehr.org/blog/attachments/2009-10/trying-to-make-another-partition.jpg"/>
