Dale and I (with lots of help from #fink IRC) are working on autoconf
for MB-System.  We are starting with just the mbio subdirectory to see
if we can build libmbio.a.  I started out with this little autogen.sh
script:
<pre><tt><i><font color="#9A1900">#!/bin/bash</font></i>
rm -rf aclocal<font color="#990000">.</font>m4 autom4te<font color="#990000">.</font>cache configure
<b><font color="#0000FF">set</font></b> -x <i><font color="#9A1900"># Turn on Debugging</font></i>
<!-- -->
aclocal
autoconf
automake --add-missing</tt></pre>
I was quickly told that I don't need that and that I can just do:
<pre>autoreconf -fvi</pre>
Then I went to the mbio subdirectory and ran
<pre>autoscan</pre>
This generates a basic template to start working with:
<pre><tt><i><font color="#9A1900">#                                               -*- Autoconf -*-</font></i>
<i><font color="#9A1900"># Process this file with autoconf to produce a configure script.</font></i>

AC_OUTPUT</tt></pre>
Copy that file to configure.ac (configure.in is a less prefered name,
but will work too).  With the help of fangism and pogma, we made these changes:
<ul>
<li>Edit AC_INIT to have the name of the package, version number, and an email address</li>
<li>Comment out the AC_CONFIG_SRCDIR... don't know what that line does</li>
<li>Add AM_INIT_AUTOMAKE([foreign]) to tell it to build a makefile</li>
<li>Same boes for the AC_CONFIG_FILES([Makefile])</li>
<li>I was trying to build a library, and it needs to know about RANLIB, so tell it to go look for ranlib</li>
<li>AC_PROB_LIBTOOL is old.  Use LT_INIT to tell it to use libtool so we can build libraries</li>
<li>Turn off the MALLOC lines as those are not helpful.  We don't care what malloc(0) does</li>
</ul>

Now we need a Makefile.am to build our makefile:
<pre><tt><font color="#009900">lib_LIBRARIES =</font> libmbio.a 
<font color="#009900">libmbio_a_SOURCES =</font> <font color="#990000">*</font>.c</tt></pre>
This tells it that we want to build libmbio.a, a static library (not a shared lib) and that all the C source files in this directory go into the shared library.
