But to get a sense of how that compares to another machine, I pulled
the logs from my new quad core xeon 3GHz desktop that runs on the CCOM
network.  This time, I am plotting the days since I got the machine up
and running.  There were a lot of reboots during the first couple of
days, but then it seems to settle down to under 15 ms:

<img title="NTP loopstats for CCOM Mac desktop over the last month" withgrayborder="True"

It appeards that my desktop occasionally does as well as the logging
computer, but the Mar 26 timing is pretty darn good.

It wouldn't be fair to leave you without the code that I used to
create these plots.  It's pretty simple:
<pre><tt><i><font color="#9A1900">#!/bin/bash</font></i>
<!-- -->
<b><font color="#0000FF">declare</font></b> -ar <font color="#009900">field_names</font><font color="#990000">=(</font> <font color="#FF0000">"0"</font> day second offset drift_compensation estimated_error stability polling_interval <font color="#990000">)</font>
<b><font color="#0000FF">declare</font></b> -ar <font color="#009900">field_label</font><font color="#990000">=(</font> <font color="#FF0000">"0"</font> <font color="#FF0000">"day (MJD)"</font> <font color="#FF0000">"time past midnight (s)"</font> <font color="#FF0000">"clock offset (s)"</font> <font color="#FF0000">"freq offset (PPM)"</font> <font color="#FF0000">"RMS jitter (s)"</font> <font color="#FF0000">"RMS freq jitter/wander (PPM)"</font> <font color="#FF0000">"clock discipline loop time const (log_2 s)"</font> <font color="#990000">)</font> 
<!-- -->
<b><font color="#0000FF">for</font></b> col <b><font color="#0000FF">in</font></b> <font color="#993399">3</font> <font color="#993399">4</font> <font color="#993399">5</font> <font color="#993399">6</font> <font color="#990000">;</font> <b><font color="#0000FF">do</font></b>
echo Column <font color="#009900">$col</font> <font color="#FF0000">"..."</font> <font color="#009900">${field_names[$col]}</font> <font color="#FF0000">"..."</font> <font color="#009900">${field_label[$col]}</font>
gnuplot <font color="#990000">&lt;&lt;</font>EOF
<b><font color="#0000FF">set</font></b> term png
<b><font color="#0000FF">set</font></b> output <font color="#FF0000">"$col-${field_names[$col]}.png"</font>
<b><font color="#0000FF">set</font></b> title <font color="#FF0000">"${field_names[$col]}"</font>
<b><font color="#0000FF">set</font></b> xlabel <font color="#FF0000">"${field_names[2]}"</font>
<b><font color="#0000FF">set</font></b> ylabel <font color="#FF0000">"${field_label[$col]}"</font>
plot <font color="#FF0000">"$1"</font> using <font color="#993399">2</font><font color="#990000">:</font><font color="#009900">$col</font> with lp
EOF
<b><font color="#0000FF">done</font></b></tt></pre>
The above script builds 4 plots against seconds of the day past
midnight.  To plot agains the day, I wrote this little python script
to make the first column be decimal days and changed the above gnuplot
command's using statement to be "using 1:$col".
<pre><tt><i><font color="#9A1900">#!/usr/bin/env python</font></i>
<b><font color="#000080">import</font></b> sys
baseday <font color="#990000">=</font> None
<b><font color="#0000FF">for</font></b> line <b><font color="#0000FF">in</font></b> <b><font color="#000000">file</font></b><font color="#990000">(</font>sys<font color="#990000">.</font>argv<font color="#990000">[</font><font color="#993399">1</font><font color="#990000">]):</font>
    day <font color="#990000">=</font> <b><font color="#000000">int</font></b><font color="#990000">(</font>line<font color="#990000">.</font><b><font color="#000000">split</font></b><font color="#990000">()[</font><font color="#993399">0</font><font color="#990000">])</font>
    <b><font color="#0000FF">if</font></b> baseday <b><font color="#0000FF">is</font></b> None<font color="#990000">:</font>
        baseday <font color="#990000">=</font> day
    <b><font color="#0000FF">if</font></b> baseday <font color="#990000">&gt;</font> day<font color="#990000">:</font>
        baseday <font color="#990000">=</font> day
<b><font color="#0000FF">for</font></b> line <b><font color="#0000FF">in</font></b> <b><font color="#000000">file</font></b><font color="#990000">(</font>sys<font color="#990000">.</font>argv<font color="#990000">[</font><font color="#993399">1</font><font color="#990000">]):</font>
    fields <font color="#990000">=</font> line<font color="#990000">.</font><b><font color="#000000">split</font></b><font color="#990000">()</font>
    day <font color="#990000">=</font> <b><font color="#000000">int</font></b><font color="#990000">(</font>fields<font color="#990000">[</font><font color="#993399">0</font><font color="#990000">])</font>
    day <font color="#990000">=</font> <font color="#990000">(</font>day<font color="#990000">-</font>baseday<font color="#990000">)</font> <font color="#990000">+</font> <b><font color="#000000">float</font></b><font color="#990000">(</font>fields<font color="#990000">[</font><font color="#993399">1</font><font color="#990000">])</font> <font color="#990000">/</font> <font color="#990000">(</font><font color="#993399">24</font><font color="#990000">*</font><font color="#993399">3600</font><font color="#990000">.)</font>
    fields<font color="#990000">[</font><font color="#993399">0</font><font color="#990000">]</font> <font color="#990000">=</font> <b><font color="#000000">str</font></b><font color="#990000">(</font>day<font color="#990000">)</font>
    <b><font color="#0000FF">print</font></b> <font color="#FF0000">' '</font><font color="#990000">.</font><b><font color="#000000">join</font></b><font color="#990000">(</font>fields<font color="#990000">)</font></tt></pre>
Not fancy, but it gets the job done.  There is a <a href="http://www.opensource.apple.com/source/ntp/ntp-12/ntp/scripts/plot_summary.pl">summary_plot.pl</a>
script around on the net, but not being a heavy duty perl user, I am
