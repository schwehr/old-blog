I'm not sure how I missed Dale's blog posts about these two topics and
his links to the Dr.Dobb's articles... 

The first, Dale's <a
href="http://ilab.ldeo.columbia.edu/node/45">Linux time keeping</a>
points to an article on NTP: <a
href="http://www.drdobbs.com/embedded-systems/223000197;jsessionid=HCTFDTPZU4DHLQE1GHPSKH4ATMY32JVN?pgno=1">Testing

no mention of iburst in the article, which would have likely caused
the system to get the systems syncronized much quicker.  Would have
been nice if he had posted the code he used for the article.

The second is Dale's <a
href="http://ilab.ldeo.columbia.edu/node/44">OMG Real-time Data
Distribution Service (DDS)</a>.  I spent a number of years in the late
90's working on the parent to this standard called Network Data
Delivers Service (NDDS) by <a href="http://rti.com/">RTI</a>.  Dale
points to this Dr.Dobbs article: <a
href="http://www.drdobbs.com/embedded-systems/222900238">The Data
Distribution Service for Real-Time Systems: Part 1 - DDS is the
standard for real-time data distribution</a>.  DDS is pretty powerful
stuff.
