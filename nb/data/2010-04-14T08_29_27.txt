If anyone is interested in a fun dataset to make visualizations from,
I've put a copy of <a
href="http://vislab-ccom.unh.edu/~schwehr/healy/20100417-healy-sqlite.db3.bz2">20100417-healy-sqlite.db3.bz2</a>.
There are 2756 summary reports in the database from 2009-04-28 through to today (with a big hole for the time in dry dock).  I would be really excited if someone would create code to produce a visualization using <a href="http://www.simile-widgets.org/timeplot/">SIMILE Timeplot</a>.
Hopefully, I will get a chance to convert my code to using spatialite
now that BABA has packaged it for fink!
