I still don't feel like I have a handle on <a
href="http://www.artima.com/weblogs/viewpost.jsp?thread=240808">python
decorators</a>.  The seem pretty interesting, but I have no sense of
when and how in my code to use them.  Here is an interesting example
that actually seems to make sense to me: <a
href="http://djangosnippets.org/snippets/2029/">Capture Stack Trace
Decorator</a>.  I've wrapped it in an example program that works with
both python 2.6 and 3.x (hence the from __future__ ... yeah time
travel).  If you call this function and it barfs, your program keeps
running and leaves you a stack trace.  Sometimes, you just can't
afford to have a program fail.  It's time to log the error and keep
moving forward.
