Thanks to Monica's post on SQLite Manager, <a
href="http://the-moni-blog.blogspot.com/2010/05/free-sqlite-manager-for-mac-os.html">Free
SQLite Manager for Mac OS</a>, I am now a happy user of <a
href="http://code.google.com/p/sqlite-manager/">sqlite-manager</a>.
Note that this tool should run on any platform if you have firefox.
And thanks to Myche back in early 2004 for pushing me into trying
sqlite for my thesis work.

First install it by opening Firefox and Going to Tools -&gt; Add-ons
-&gt; Get Add-ons.  Search on sqlite and install sqlite manager.
After firefox restarts, byou are good to go.  Then It's pretty easy to
get a table up and going, especially if you don't do this kind of
thing very often.
