Then I ran file on it and it turns out that this is yet another zip
based format:
<pre><b>file *.docx</b>
Agenda.docx: Zip archive data, at least v2.0 to extract</pre>
So it really is not that exciting, but now I know I can pull an image of the
first page of a word document if I am on a machine without Word.

This makes me wonder is pptx is the same... and it is.  This is great
news for the ideas that Steve L and I were contemplating during the
Phx mission for IPRW.  We had thoughts about suffering through some
Microsoft OS machine running a service to make PPTs, but that was no
fun.  We were also thinking about creating Keynote directory tree, but
that was Mac specific.  It shouldn't be too hard to write out a
working pptx that MS Office 2007+, OpenOffice, or Keynote can read.
