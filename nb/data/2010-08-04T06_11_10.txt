My tip of the day:

When you you get iPhone example code from older projects, it often has
an xcode setup that points to an older version of the iPhone OS that
is not on my dev machines.  I'm sure there is a way to set the build
to use iOS 4.x, but till then, here is a perl one liner that will make
the change.  
<pre><b>find . -name \*.pbxproj | xargs egrep -h 'iphoneos[0-9]+\.' | sort -u</b>
				SDKROOT = iphoneos2.0;
				SDKROOT = iphoneos2.2.1;
				SDKROOT = iphoneos4.0;
<b>perl -pi -e 's|iphoneos2.0|iphoneos4.0|g' project.pbxproj 
perl -pi -e 's|iphoneos2.2.1|iphoneos4.0|g' project.pbxproj</b></pre>
