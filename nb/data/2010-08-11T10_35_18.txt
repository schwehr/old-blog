to create iterators.  I'm trying to do something that was really
simple for me in C++ and Python: create an iterator over a file that
is a factory returning objects decoded from the binary multibeam file
(in this case a Simrad/Kongsberg <a
href="http://www.km.kongsberg.com/ks/web/nokbg0240.nsf/AllWeb/E875530A90163597C1256CF00052435D?OpenDocument">EM
3002</a>).  I've been trying to read documentation on NSEnumerator and
NSFastEnumerator, but there are very few complete examples (e.g. I can
compile, run and step through them with the debugger).  I have been
looking at Matt Gallagher's post, <a
href="http://cocoawithlove.com/2008/05/implementing-countbyenumeratingwithstat.html">Implementing
countByEnumeratingWithState:objects:count:</a> and finally have
