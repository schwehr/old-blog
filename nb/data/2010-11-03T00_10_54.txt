All this year, I've been wanting to work on an emacs org-mode addition
that would let you automatically add your location to entries.  I've
been thinking that your .emacs could contain a configuration that would let you pick from:
<ul>
<li>Fixed address or lon,lat for desktop machines</li>
<li>GPS attached via serial, TCP/IP, or GPSD for those with a GPS or on a ship with a network GPS</li>
<li>Google Maps click (e.g. extending jd's <a href="http://julien.danjou.info/google-maps-el.html">Google Maps for Emacs</a>)  </li>
<li>Through an IP lookup service that handles everything on the server side</li>
</ul>
That last entry is suddenly looking more possible now that I've found
<a href="http://www.hostip.info">hostip.info</a>.  Most of the other
sites that I've found have a bunch of JavaScript that I'm not going to
run inside of emacs.  This one is just a simple URL.  I ran this from work:
<pre><b>curl http://api.hostip.info/ &gt; where.xml</b></pre>
