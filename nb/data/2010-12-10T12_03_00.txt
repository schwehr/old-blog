Often, it is really hard to start into GMT.  It is a super powerful
mapping tool box, but it is difficult for beginners.  In the past,
I've often used MB System's mbm_grdplot to get myself started, but
NGDC has recently released a beta version of a web site called <a
href="http://www.ngdc.noaa.gov/autochart/">AutoChart</a>.  It lets you
pick a region and then goes into the ngdc data store and builds you a
custom map.  It will email when it's done with a tar archive to
download that contains PDF and PNG (among other types) versions of the
map, the GMT grd file that it produced and a sample script that
produces the plot.  You can then edit that script to make the map work 
for your needs.  Very cool!
