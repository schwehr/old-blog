I'm setting up one of my Dad's computers with the latest version of
Ubuntu so that he has a dual boot machine.  I gave the <a
href="http://processing.org/">processing language</a> a try.  I first had to make the processing script executable.  That was weird!  A properly done package
wouldn't need that do be done.  
<pre><b>cd processing-1.2.1; chmod +x processing</b></pre>
I tried to run processing, but it didn't find java.  I installed java
through ubuntu.  It ran but got some really strange errors, so I
should have known there would be more trouble.  I couldn't figure out
was up for a while till I realized that it comes with java, but when I set
the path, it didn't find java.  I finally realized that everything in the java/bin directory was not executable.  Crazy.
<pre><b>chmod +x java/bin/*</b></pre>
Now it ran.  They definitely need to fix their Linux package.  It looks like
older versions of Ubuntu had processing as a package.  It's a bummer that
there is no package for 10.10.  I also had X11 crash on me.  I'm not sure
what caused the crash... processing or something else.

I tried it on my Mac and it just worked.
