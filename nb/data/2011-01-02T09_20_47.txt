The first bummer that I notice is that the comment character for lisp
is the ";" character, so the shebang ("#!") is not going to co-exist
well with a loadable lisp file that can be used either as a library or a script, which is a typical use in python.

I think the trouble with lisp is that I've spent too much time with <A href="http://en.wikipedia.org/wiki/ALGOL">ALGOL</a> influenced programming languages (Pascal, C, C++, Java, Python) and the command line.
