Emacs uses the Meta and Ctrl keys all the time.  I've been staring at
my capslock key and wondering what bonehead used up that much space
for such a useless key.  I just saw Xah Lee mention <a
href="http://xahlee.org/emacs/osx_keybinding.html">Creating Keyboard
Layout in Mac OS X</a>.  That seems a little over the top, but it is
possible to do a simple tweak using System Preferences -&gt; Keyboard
-&gt; Modifier Keys.  You can pick the CapsLock key to be Meta or
Ctrl.  I'm going with Ctrl for now... can I make myself use it?
