NOAA just announced the <a
href="http://coastalmanagement.noaa.gov/inyourstate/">OCRM in your
State</a> web map.  OCRM = Office of Ocean and Coastal Resource
Management.  The press release:
<a href="http://www.noaanews.noaa.gov/stories2011/20110307_ocrminyourstate.html">New Website Tracks Coastal, Ocean Investments and Successes by State</a>
<pre>...
Using the latest GIS/web technology, OCRM in Your State lets users
click on a state to see current federal funding and state matching
funds for coastal programs administered by OCRM. It also has thumbnail
descriptions of results from those investments in every state and
territory and links to more information about each state's coastal
programs.
...</pre>
I guess this is a <a href="http://cmsp.noaa.gov/">Coastal and Marine Spatial Planning (CMSP)</a> targeted web map?  A lot of the acronyms on the web page are new to me, so I'm not totally following.

If the web map doesn't load for you, try reloading it a couple times.  It hung for me the first two times I tried to view the web map.
