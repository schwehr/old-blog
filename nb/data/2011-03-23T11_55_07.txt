Tom Milliman just pointed a bunch of us to <a
href="http://marinemap.org/">MarineMAP.org</a>.  There is a <a
href="http://marinemap.org/poster.pdf">Marine Map Technology Stack</a>
poster (PDF) that talks about how they built the system using
OpenLoayers, ExtJS, jQuery, GeoDjango, GeoServer, MapServer, Grass,
PostGIS and ArcSDE.  Even better, the code is available <a
href="http://code.google.com/p/marinemap/">on Google Code</a> and they
have a public IRC.
