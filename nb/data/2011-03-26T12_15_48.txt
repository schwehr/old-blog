Matlab has a feature much like <a
href="http://www.gnu.org/software/emacs/">emacs</a> <a
href="http://orgmode.org/">org-mode</a> and <a href="http://orgmode.org/worg/org-contrib/babel/">org-babel</a> that lets
you create a nice document from your matlab script.  However, it has
some serious flaws the way it is implemented right now.  Tables have
to be specified only in html or latex so that tables don't show up in
all reports and you can't reference variables in the workspace in the
text and have the values dropped into the text.  First here is a document
I created that shows off most of the markup features in the current
implementation.  By using "<b>%%</b>" to mark sections, this also lets
you execute sections of code as you work on them (Command-Enter on the
Mac). 

This is a great way to aim for <a
href="http://www.reproducibleresearch.net/">Reproducable Research</a>
where your end document and your code live together, which is not really
that different from Knuth's <a
href="http://en.wikipedia.org/wiki/Literate_programming">Literate
Programming</a>.  Matlab done this way would be flagged as [<b>CR</b>]
(having Conditional Reproducibility)
by <a
href="http://sepwww.stanford.edu/data/media/public/sep/jon/repropreface.html">Claerbout's tagging
rr scheme</a>.  For Students: If you are turning in homework that is not
reproducable, you might be loosing points or have a hard time arguing
a regrade. 

This publish language is basically a <a
href="http://en.wikipedia.org/wiki/Category:Lightweight_markup_languages">lightwight
markup language</a>.

This is just a template of things to try.  I will not attempt to
document what they do here beyond giving a link to a pdf and html
version of the publish.  Note: Word Doc exporting does not work on
non-Windows computers.

I put in a request to the Mathworks to improve the markup to really
allow this publish mode to really take off.  If you are a windows
user, you can use the <b>notebook</b> functionality in Microsoft Word,
but I really don't like that it takes you far away from your
programming environment and without Mac and Linux support, I'm not
going to use notebook.
