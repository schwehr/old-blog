Val sent me a SEGY file that was a combination of parameters that I
had not run into before and triggered a bug or two in my code from a
Benthos Chirp III AUV SBP.  I did a quick fix and used that as an
opportunity to kick simplesegy over to github.  In the docs directory
is my unix <b>file</b> command magic definitions... always looking for
more contributions of either definition entries or sample files.

<a href="https://github.com/schwehr/simplesegy">https://github.com/schwehr/simplesegy</a>

See OceanBytes <a
href="http://www.oceanbytes.org/2011/04/01/sub-bottom-profiling-using-an-auv/">Sub-Bottom
Profiling using an AUV</a> and <a href="http://udcshel.blogspot.com/2011/03/auv-configured-with-both-sub-bottom.html">AUV configured with both sub-bottom profiler and swath bathymetry</a>.  The AUV is getting longer and longer!
