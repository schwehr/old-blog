I was just looking at the UC Berkeley <a
href="http://ccrm.berkeley.edu/">Center for Catastrophic Risk
Management (CCRM)</a> <a
href="http://ccrm.berkeley.edu/deepwaterhorizonstudygroup/">Deepwater
Horizon Study Group (DHSG)</a> final report and saw their reference to
their document archive.  1405 entries is lot of information... to much
for me to really deal with.  They have a <a
href="http://calmap.gisc.berkeley.edu/dwh_parse.html">database
search</a> and a link for <a
href="http://calmap.gisc.berkeley.edu/cgi-bin/dwh_parse.pl?alldocs=select+docpath%2C+filename+from+dwh_doc_lib+order+by+filename">all
the entries</a>.  You can see the files <a href="http://calmap.gisc.berkeley.edu/dwh_doc_link/">in apache generated indexes of directories</a>.

<img title="Deepwater Horizon Study Group (DHSG) document database"
withgrayborder="True"
src="http://schwehr.org/blog/attachments/2011-04/dhsg-db-all.png"/>

This was a chance for me to breakout BeautifulSoup, which I've never
used before.  It is a tool designed to handle the goo that is normal
HTML web pages.  It certainly did the trick here.  My goal was to
create a BibTex file that would get me started looking through the
documents and to be able to pull down all of the files with one
script.  For each file, there is also a text file, so I would go crazy
trying to download everything.  Before I dig into the code, here are
the results.

I made two bib files.  If I could download the document successfully,
I put it in a <a
href="http://vislab-ccom.unh.edu/~schwehr/dwh/dhsg/dhsg.bib.bz2">dhsg.bib.bz2</a>
(938 entries) and if I couldn't, it went in <a
href="http://vislab-ccom.unh.edu/~schwehr/dwh/dhsg/dhsg-bad.bib.bz2">dhsg-bad.bib.bz2</a>
(467 entries).  I loaded the dhsg.bib into JabRef and did an html
export: <a
href="http://vislab-ccom.unh.edu/~schwehr/dwh/dhsg/dhsg-bibtec.html">dhsg-bibtex.html</a>

<img title="DHSG document database - BibTex in html"
withgrayborder="True"
src="http://schwehr.org/blog/attachments/2011-04/dhsg-bibtex.png"/>

Clearly this is not great, but hopefully someone with the time can
take it and look through the documents quickly and turn this into a
bibtex with years, real titles, and abstracts.  I have uploaded the
zip of all the pdf, doc, and txt files.  I probably won't leave this
online for too long as it is 694MB compressed.

<a href="http://vislab-ccom.unh.edu/~schwehr/dwh/dhsg/dhsg.zip">dhsg.zip</a>

After using BeautifulSoup for a little bit, I think it is a very handy
tool.  It took me a few minutes to figure out that I could just access
child tags with the dot notation and that if the node was not there, I
would get back a None.  I'm now thinking about parsing my blog entries
from nano blogger this way and extracting all the text for keyword
indexing so that I can build myself a nice bibtex database for all my
4100 entries and my 1850 delicious bookmarks.  I have 187 Deepwater
Horizon bookmarks and a lot of them are intended for use in writing
papers.  Delicious entries are not proper XML entires.  For example:
