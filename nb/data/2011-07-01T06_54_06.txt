I just recently heard of <a
href="http://www.asascience.com/software/oilmap/">ASA's OilMap</a> for
the first time... I heard about it from Daniel Martin.  Looking at
their web page it looks to be a lot like ERMA.  It's hard to tell the
lineage of this software from the little info they provide.  If they
got ideas from ERMA, I think that's great!

<a href="http://www.asascience.com/software/PDF/OILMAP_brochure.pdf">OILMAP_brochure.pdf</a>

ASA also has an AIS plugin in beta for ArcGIS.  It's likely based on
Brian C. Lane's <a href="https://github.com/bcl/aisparser">AIS
Parser</a> [github].  I have been helping ASA via email occasionally
on how to decode AIS messages.  AIS parsing has been available in
ArcGIS ever since ESRI added python support as you can just use
<a href="https://github.com/schwehr/noaadata">noaadata</a> (and now <a href="https://github.com/schwehr/libais">libais</a>) from within Arc or GPSD via the Python interface, but I'm sure the ASA
software is a polished GUI type application, whereas noaadata and
libais are more like aisparser - focused more on just being
decoding/processing libraries.  I don't really use Windows and the
last time I really used Arc is was 1995 with Arc/Info 6.x on Solaris,
so I can't comment on what the software is like.
