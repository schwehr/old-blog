I've got a midsized database (for me at least) and I'm doing some
basic queries again and again that are slow even with indexes.  I
figured I should be able to knock out a little python function that
checks to see if that query has been done before and if so, reuse the
old results.  This could be a lot fancier... I could hash the query
string and use that rather than making the caller remember a name for
the query, but this is what I could get done in a couple minutes and
the results are awesome.  The function checks for a python pickle
file.  If it successfully loads the pickle, it returns the data.  If
it fails, it does the query, saves a pickle to disk, and returns a
list of rows with each row as a dictionary.

You could use stat to check the age of the database and the pickle if
you were worried that the database might change.
