I have just put the audio of lecture 2 online.  This class covers
using ChatZilla in Firefox to sign into an Internet Relay Chat (IRC)
channel, Mediawiki / the CCOM wiki, and using Putty to ssh into a
Ubuntu 11.04 Linux server (a vmware instance) inside CCOM and running 
a couple very simple shell commands.  The lecture notes to go along with
this material are still in progress.
