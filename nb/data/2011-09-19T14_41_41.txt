is a bummer that the source code is not available.  I saw a news
article implying that the source code was available, but couldn't find
anything on the NOAA site.  I grabbed the latest zip from <a
href="http://vdatum.noaa.gov/download/software/">http://vdatum.noaa.gov/download/software/</a>
and gave a look to see if I was just missing something.
