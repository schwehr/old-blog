TITLE: If you stop vmware
AUTHOR: Kurt
DATE: 10.27.2011 08:02
DESC: yick
-----
BODY:
Yesterday, I was trying to debug some serial-to-wifi bridge devices.
The vmware network interfaces kept being distracting, so I ran
<pre>sudo /Library/Application\ Support/VMware\ Fusion/boot.sh --stop</pre>
This morning, when I tried to connect to my ubuntu 11.04 virtual machine,
I got strange messages like "Cannot find a valid peer process to connect to"
and some missing /dev/vmmon (?  forgot to write down what the error was).
I restarted the vmware infastructure like this:
<pre>sudo /Library/Application\ Support/VMware\ Fusion/boot.sh --start</pre>
I then rebooted the virtual machine for good measure.  It all seems
to work fine again, but those error messages in VMWare Fusion 3.1.3 were
not the most helpful to remind me how to get back on track.
