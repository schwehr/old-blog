In this class, we do our first mercurial pull of changes.  We then add
helper functions to our sbet.py module to give us the number of
datagrams in an sbet file, tell us at what offset any particular
datagram is located and add a <b>generator</b> function allowing
cleaner for loops over sbet files.

Remember that at this point, you should be getting the org mode
formatted class notes via mercurial (hg).  To get set up:
<pre>mkdir ~/projects
cd ~/projects
sudo apt-get install mercurial # Install hg on ubuntu &amp; debian linux
hg clone https://bitbucket.org/schwehr/researchtools</pre>
And every time you start working on the class, do a pull and update to get the latest versions.
<pre>cd ~/projects/researchtools
hg pull   # Bring the changes down to the local "repo"
hg update # Change the working files to have the latest changes</pre>
