This is my first attempt at a tutorial for Google Cloud Storage.

Using <a href="https://developers.google.com/storage/">Google Cloud Storage</a> to store data objects (a blob of data of what ever type you want).  Right now, 
you get 5GB of storage for free and you can transfer 20 GB per month.
Beyond that, you'll have to check the <a href="https://developers.google.com/storage/docs/pricingandterms">pricing</a>.

This is pretty much what is on
<a href="https://developers.google.com/storage/docs/getting-started">https://developers.google.com/storage/docs/getting-started</a> and 
<a href="https://developers.google.com/storage/docs/hellogooglestorage">https://developers.google.com/storage/docs/hellogooglestorage</a>
I've tweaked it a bit to fit my style.  I'm doing this on a mac with fink
and splitting between two acounts.  I want to end up with a way to
transfer files from one group to another.  I started off by watching 
this 2011 Google IO video:

<a href="https://developers.google.com/storage/docs/pricingandterms">Google I/O 2011: Storing Your Application's Data in the Google Cloud</a>

First setting up a virtual env in python to isolate us from messing up
any existing python installs.
<pre>cd ~/Desktop
mkdir try-gs
<span style="color: lightsteelblue; font-weight: bold;">cd</span> try-gs
fink install virtualenv-py27
virtualenv ve
<span style="color: lightsteelblue; font-weight: bold;">source</span> ve/bin/activate
wget http://commondatastorage.googleapis.com/pub/gsutil.tar.gz
tar xf gsutil.tar.gz
<span style="color: lightsteelblue; font-weight: bold;">pushd</span> gsutil
<!-- -->
<span style="color: red; font-style: italic;"># </span><span style="color: red; font-style: italic;">gsutil does not have a proper setup.py that will work with virtualenv</span>
<span style="color: red; font-style: italic;"># </span><span style="color: red; font-style: italic;">so force it to play along</span>
perl -pi -e "s|/usr|`pwd`/../ve|g" setup.py
<!-- -->
python setup.py install
popd</pre>
You should now have a working virtualenv with gsutil installed in it.
Your normal python will not be effective.  You will have to rerun the
&lt;b&gt;activate&lt;/b&gt; from any other shell that you want to have access to
gsutil.  The virtualenv named "ve" will change your prompt:
<pre>$ pwd
/Users/schwehr/Desktop/try-gs
(ve)
$</pre>
