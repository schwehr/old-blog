TITLE: Sonar Generic Sensor Format is not open source licensed
AUTHOR: Kurt
DATE: 05.09.2012 17:38
DESC: annoying
-----
BODY:
Just a reminder to the community that the SAIC Generic Sensor Format
(GSF) is not open source licensed code.  You might be able to download the
source, but nowhere does it give you any permission to use this code.

<pre>mkdir gsf
cd gsf
wget http://www.saic.com/maritime/gsf/download/gsf_0303.zip
unzip gsf_0303.zip
egrep -i 'copyright|license|gpl|apache|unclassified' *
gsf.c: * Classification : Unclassified

gsf.h: * Classification : Unclassified

That pdf that matches has no copyright or license information.  While the web
page <b>implies</b> that it is okay to use the code, in my feeble understanding of
copyright law (I AM NOT A LAWYER), I see nothing that actually gives
anyone rights to use the code.  I wish SAIC would just pick something like the
Apache, BSD or MIT licenses to make sure GSF gets as much use as possible.
I first brought this issue up at the GSF workshop at Shallow Survey in 2008.
