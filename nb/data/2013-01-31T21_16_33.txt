I just had a little bit of fun with OpenCV's python interface and an
IPython notebook.  I haven't posted much this month, so why not share?  It seems like an excellent way to
create tutorials.  This notebook shows working through two of Abid
Rahman's OpenCV blog posts on contours: <a
href="http://www.opencvpython.blogspot.com/2012/06/hi-this-article-is-tutorial-which-try.html">Contours
- 1: Getting Started</a> and <a
href="http://www.opencvpython.blogspot.com/2012/06/contours-2-brotherhood.html">Contours
- 2: Brotherhood</a>.  Be warned... I have never used OpenCV before
today and I'm working hard on making myself use NumPy array slicing.

First, download the notebook, uncompress it and then start ipython like this in the same directory:
<pre>ipython notebook --pylab=inline</pre>
<a href="http://schwehr.org/blog/attachments/2013-01/opencv-learning.ipynb.bz2">opencv-learning.ipynb.bz2</a>

Also available on <a href="http://nbviewer.ipython.org/">nbviewer.ipython.org</a> as <a href="http://nbviewer.ipython.org/4694308/">nbviewer.ipython.org/4694308/</a>, which I created from <a href="https://gist.github.com/4694343">https://gist.github.com/4694343</a>.  Sadly, I it doesn't let you say that the contents are JSON when you give a filename of opencv-learning.ipynb.
