I just fell in love with a fancy new hammer called IPython Notebook
and the world looks like a bunch of nails that need pounding.  Even if
using mbsystem to process multibeam sonar data does not need python,
it sure makes a nice subject for a notebook.

It's a little clunky in that I have to put a ! in front of each command to bash and the images are super small, but it was fun to 

<a href="https://gist.github.com/4698869">https://gist.github.com/4698869</a>

The notebook can be viewed here:

<a href="http://nbviewer.ipython.org/4698869/">http://nbviewer.ipython.org/4698869/</a>

Setup (because there are definitely a few things that ended up being system specific):
<ul>
<li>bash</li>
<li>mac osx 10.8</li>
<li>fink install mbsystem  # version 5.3.2012</li>
<li>fink install graphicsmagick-imagemagic</li>
<li>fink install ipython-py27 # version 0.13.1</li>
<li>fink install matplotlib-py27 # version 1.2.0</li>
</ul>
